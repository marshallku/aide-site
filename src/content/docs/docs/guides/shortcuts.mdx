AIDE on the Mac and Linux has the same shortcuts, with <kbd>⌘</kbd> on the Mac where Linux uses
<kbd>Ctrl</kbd>. On the Mac each one is also in the menu bar, and every command is in the command
palette with its shortcut.

## Window and navigation

| Action | Mac | Linux |
|---|---|---|
| Settings | <kbd>⌘</kbd><kbd>,</kbd> | <kbd>Ctrl</kbd><kbd>,</kbd> |
| Command palette | <kbd>⌘</kbd><kbd>P</kbd> | <kbd>Ctrl</kbd><kbd>P</kbd> |
| Open quickly (find a note by title, then in text) | <kbd>⌘</kbd><kbd>O</kbd> | <kbd>Ctrl</kbd><kbd>O</kbd> |
| Search notes | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>F</kbd> | <kbd>Ctrl</kbd><kbd>Shift</kbd><kbd>F</kbd> |
| Find in note | <kbd>⌘</kbd><kbd>F</kbd> | <kbd>Ctrl</kbd><kbd>F</kbd> |
| New scratch note | <kbd>⌘</kbd><kbd>N</kbd> | <kbd>Ctrl</kbd><kbd>N</kbd> |
| Today's daily note | <kbd>⌘</kbd><kbd>T</kbd> | <kbd>Ctrl</kbd><kbd>T</kbd> |
| New window | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>N</kbd> | — |
| Close tab (the last tab: an empty tab; an empty last tab: the window on the Mac) | <kbd>⌘</kbd><kbd>W</kbd> | <kbd>Ctrl</kbd><kbd>W</kbd> |
| Next tab | <kbd>⌃</kbd><kbd>Tab</kbd> | <kbd>Ctrl</kbd><kbd>Tab</kbd> or <kbd>Ctrl</kbd><kbd>Page Down</kbd> |
| Previous tab | <kbd>⌃</kbd><kbd>⇧</kbd><kbd>Tab</kbd> | <kbd>Ctrl</kbd><kbd>Shift</kbd><kbd>Tab</kbd> or <kbd>Ctrl</kbd><kbd>Page Up</kbd> |
| Back | <kbd>⌘</kbd><kbd>[</kbd> | <kbd>Alt</kbd><kbd>←</kbd> or <kbd>Ctrl</kbd><kbd>[</kbd> |
| Forward | <kbd>⌘</kbd><kbd>]</kbd> | <kbd>Alt</kbd><kbd>→</kbd> or <kbd>Ctrl</kbd><kbd>]</kbd> |
| Go to a section of the sidebar | <kbd>⌘</kbd><kbd>1</kbd> to <kbd>⌘</kbd><kbd>9</kbd> | <kbd>Alt</kbd><kbd>1</kbd> to <kbd>Alt</kbd><kbd>7</kbd> |
| Show or hide the panel | <kbd>⌘</kbd><kbd>\\</kbd> | <kbd>Ctrl</kbd><kbd>\\</kbd> |
| Show or hide the right panel | <kbd>⌥</kbd><kbd>⌘</kbd><kbd>\\</kbd> | <kbd>Ctrl</kbd><kbd>Alt</kbd><kbd>\\</kbd> |
| Browse plugins | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>P</kbd> | <kbd>Ctrl</kbd><kbd>Shift</kbd><kbd>P</kbd> |
| Show or hide the assistant on the desktop | <kbd>⌥</kbd><kbd>⌘</kbd><kbd>A</kbd> | <kbd>Ctrl</kbd><kbd>Alt</kbd><kbd>A</kbd> |
| New meeting (and start recording) | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>R</kbd> | — (command palette) |

The section numbers follow the sidebar from the top. On the Mac: <kbd>⌘</kbd><kbd>1</kbd> Scratch,
<kbd>⌘</kbd><kbd>2</kbd> Wiki, <kbd>⌘</kbd><kbd>3</kbd> Todos, <kbd>⌘</kbd><kbd>4</kbd> Graph, then
Terminal and the plugins' tabs in their order. On Linux: <kbd>Alt</kbd><kbd>1</kbd> Scratch,
<kbd>Alt</kbd><kbd>2</kbd> Wiki, <kbd>Alt</kbd><kbd>3</kbd> Todos, <kbd>Alt</kbd><kbd>4</kbd> Graph,
<kbd>Alt</kbd><kbd>5</kbd> Terminal, <kbd>Alt</kbd><kbd>6</kbd> Feed, <kbd>Alt</kbd><kbd>7</kbd>
Calendar.

The mouse's back and forward buttons also go back and forward. A note opened with <kbd>⌘</kbd>-click
(<kbd>Ctrl</kbd>-click on Linux) or the middle button opens in a new tab.

## Open quickly and the command palette

| Action | Mac | Linux |
|---|---|---|
| Move through the results | <kbd>↑</kbd> <kbd>↓</kbd> | <kbd>↑</kbd> <kbd>↓</kbd> |
| Open the chosen note or command | <kbd>Return</kbd> | <kbd>Enter</kbd> |
| Open the chosen note in a new tab | <kbd>⌘</kbd><kbd>Return</kbd> | <kbd>Ctrl</kbd><kbd>Enter</kbd> |

## Editor

The editor is the same on the Mac, Linux and iPhone.

| Action | Keys |
|---|---|
| Undo / redo | <kbd>⌘</kbd><kbd>Z</kbd> / <kbd>⇧</kbd><kbd>⌘</kbd><kbd>Z</kbd> (Linux: <kbd>Ctrl</kbd><kbd>Z</kbd> / <kbd>Ctrl</kbd><kbd>Shift</kbd><kbd>Z</kbd>) |
| Indent / outdent a line or list item | <kbd>Tab</kbd> / <kbd>Shift</kbd><kbd>Tab</kbd> |
| Continue a list or todo on the next line | <kbd>Return</kbd> |

In a table edited as a grid:

| Action | Keys |
|---|---|
| Next cell (a new row after the last cell) | <kbd>Tab</kbd> |
| Previous cell | <kbd>Shift</kbd><kbd>Tab</kbd> |
| Cell below (a new row after the last row) | <kbd>Return</kbd> |
| Cell above / below, leaving the table at its edge | <kbd>↑</kbd> / <kbd>↓</kbd> |
| Leave the table | <kbd>Esc</kbd> |

## Assistant

| Action | Mac | Linux |
|---|---|---|
| Send | <kbd>Return</kbd> or <kbd>⌘</kbd><kbd>Return</kbd> | <kbd>Enter</kbd> |
| New line | — | <kbd>Shift</kbd><kbd>Enter</kbd> |
| Start or stop talking | The **Hold to talk** shortcut you set in **Settings › Assistant › Voice** (works in any app) | <kbd>Ctrl</kbd><kbd>Shift</kbd><kbd>Space</kbd> in AIDE |
| Throw a recording away | <kbd>Esc</kbd> | <kbd>Esc</kbd> |

On Linux, for a voice shortcut anywhere on the desktop, bind the command `aide-desktop --voice` in
your desktop's keyboard settings.

## Quick capture

On the Mac, a global shortcut opens a small window over any app to jot something into Scratch:
<kbd>⌥</kbd><kbd>Space</kbd> by default. Change or turn it off in **Settings › Quick capture**
(**Quick capture shortcut**, **Shortcut**). In the window:

| Action | Keys |
|---|---|
| Save to Scratch | <kbd>Return</kbd> |
| New line | <kbd>⇧</kbd><kbd>Return</kbd> |
| Close | <kbd>Esc</kbd> |

The menu bar icon (**Show AIDE in the menu bar**) has **Quick capture…** too.

On Linux, bind a shortcut in your desktop or compositor to `aidectl capture`, which adds its text
(its arguments, or standard input with `-`) as a scratch note. See [aidectl](/docs/developers/aidectl/).

## Terminal

While a terminal has the keyboard, these act on its tabs:

| Action | Mac | Linux |
|---|---|---|
| New tab | <kbd>⌘</kbd><kbd>T</kbd> | <kbd>Ctrl</kbd><kbd>Shift</kbd><kbd>T</kbd> |
| Close tab | <kbd>⌘</kbd><kbd>W</kbd> | <kbd>Ctrl</kbd><kbd>Shift</kbd><kbd>W</kbd> |
| Previous / next tab | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>[</kbd> / <kbd>⇧</kbd><kbd>⌘</kbd><kbd>]</kbd> | <kbd>Ctrl</kbd><kbd>Page Up</kbd> / <kbd>Ctrl</kbd><kbd>Page Down</kbd> |
| Go to tab 1–9 | <kbd>⌘</kbd><kbd>1</kbd>–<kbd>9</kbd> | <kbd>Alt</kbd><kbd>1</kbd>–<kbd>9</kbd> |
| Find in terminal | <kbd>⌘</kbd><kbd>F</kbd> | <kbd>Ctrl</kbd><kbd>Shift</kbd><kbd>F</kbd> |
| Copy / paste | <kbd>⌘</kbd><kbd>C</kbd> / <kbd>⌘</kbd><kbd>V</kbd> (the Edit menu) | <kbd>Ctrl</kbd><kbd>Shift</kbd><kbd>C</kbd> / <kbd>Ctrl</kbd><kbd>Shift</kbd><kbd>V</kbd> |
| Bigger / smaller text | <kbd>⌘</kbd><kbd>=</kbd> / <kbd>⌘</kbd><kbd>-</kbd> | <kbd>Ctrl</kbd><kbd>=</kbd> / <kbd>Ctrl</kbd><kbd>-</kbd> |
| Text size back to the setting | <kbd>⌘</kbd><kbd>0</kbd> | <kbd>Ctrl</kbd><kbd>0</kbd> |

On the Mac, a terminal with the keyboard keeps <kbd>⌘</kbd><kbd>T</kbd>, <kbd>⌘</kbd><kbd>W</kbd>,
<kbd>⌘</kbd><kbd>1</kbd>–<kbd>9</kbd>, <kbd>⇧</kbd><kbd>⌘</kbd><kbd>[</kbd> <kbd>⇧</kbd><kbd>⌘</kbd><kbd>]</kbd>
and <kbd>⌘</kbd><kbd>F</kbd> for its tabs; anywhere else they do what the first table says.

<Aside type="note" title="Shortcuts that step aside in a terminal on Linux">
These app shortcuts are also keys a shell uses, so they're off while the keyboard is in a
terminal and reach the shell instead: <kbd>Ctrl</kbd><kbd>P</kbd>, <kbd>Ctrl</kbd><kbd>\\</kbd>,
<kbd>Alt</kbd><kbd>←</kbd> <kbd>Alt</kbd><kbd>→</kbd>, <kbd>Ctrl</kbd><kbd>[</kbd>
<kbd>Ctrl</kbd><kbd>]</kbd>, <kbd>Ctrl</kbd><kbd>N</kbd>, <kbd>Ctrl</kbd><kbd>T</kbd>,
<kbd>Ctrl</kbd><kbd>O</kbd>, <kbd>Ctrl</kbd><kbd>F</kbd>, <kbd>Ctrl</kbd><kbd>Shift</kbd><kbd>F</kbd>,
<kbd>Ctrl</kbd><kbd>W</kbd> and the tab-switching keys. The rest, <kbd>Ctrl</kbd><kbd>,</kbd>
included, keep working. Click outside the terminal to use them again.
</Aside>
