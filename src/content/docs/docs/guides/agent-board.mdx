When Claude Code, Codex or Grok works on a task with more than one step, it writes its plan into your notes as a card: a short title, its steps, and a line that says what it's doing now. You see the work in your notes without reading the agent's terminal, and you can tick a step yourself at any time.

## What a card looks like

Cards are todos in the `board` folder, one note per project: an agent working in the `aide` repository writes to `board/aide.md`.

```markdown
- [/] Agent board plan [project:: aide] [agent:: claude] [card:: k7f2q] ➕ 2026-11-10
    > Codex review, round 2
    - [x] Survey Todos, editor, agents
    - [/] Codex plan review
    - [ ] Send to the owner
```

- The card's status is the agent's: `[ ]` to do, `[/]` doing, `[x]` done, `[-]` cancelled. A card waiting for you is open and tagged with your waiting tag (`#waiting`), with the agent's question on its status line. In an AIDE terminal pane, moving a card to waiting also marks that pane's agent as needing you, so you get the terminal's notification without looking at the board.
- Its steps are the todos right under it. A step the agent drops from its plan before starting it is cancelled, never deleted. A step that was started or finished, by you or the agent, stays as it is.
- The agent can mark the card done only once no step under it is open: it finishes them, or cancels what's left on purpose. If you tick the card done yourself while steps are still open, they stay open.
- When the work lands, the agent adds what landed under the card: a commit or a URL such as a pull request, each on a `- ref:: …` line. A finished card says which pull request or commit closed it, and Details on the Board lists them as links.
- The fields and the rules for cards (only the `board` folder counts, a card's id is unique, a card always gets its completion date and never repeats) are in [Agent cards](/docs/guides/todos/#agent-cards).

You can edit the note as usual. An agent's change is always made on the note as it is now, so a tick you made a moment ago is kept.

## How agents learn it

The `aide-board` skill tells an agent when to add a card, how to keep its steps and status line current, when to move it to waiting, and how to finish it with a one-line outcome. On the Mac and Linux, AIDE gives it to your coding agents with the other [plugin skills](/docs/guides/terminal/#plugin-skills) once **Give plugins' skills to your coding agents** is on. Claude Code and Codex started in a terminal pane learn it for that session without that setting, while **Give agents AIDE's context** is on: Claude Code gets the skill itself, and Codex is told to read it with `aidectl guide board` (see [AIDE's context for agents](/docs/guides/terminal/#aides-context-for-agents)).

In an AIDE terminal pane, the card is linked to the agent's pane, and its link `aide://card/<vault>/<card>` opens that pane (see [Cards linked to panes](/docs/guides/terminal/#cards-linked-to-panes)). The agents use `aidectl board`; the [aidectl reference](/docs/developers/aidectl/#board) lists its commands. In a pane they need no flag or token: `aidectl` uses the pane's window's notes, and read-only agents can still use the board. Elsewhere on the same computer they need no token either: with the vault's window in front, or with `aidectl --vault <folder>`; **Settings › Agents on this computer** gives Claude Code and Codex in any terminal AIDE's tools for the vault ([MCP](/docs/developers/mcp/)). Run `aidectl board list` to see the open cards yourself, or `aidectl board show <card>` for one card and its steps.

An agent tells you about its card with the card's link, which `aidectl board add` and `aidectl board show` print. In a terminal pane, <kbd>⌘</kbd>-click it on the Mac, <kbd>Ctrl</kbd>-click it on Linux, or tap it on the iPhone, and the card opens on the Board. In the Agents list, a row whose pane works on a card says **on:** with the card's title, and **Open card** in its menu shows the card on the Board (see [The Agents list](/docs/guides/terminal/#the-agents-list)).

## Where you see it

Cards show on **Todos › Board**, in columns with a lane per project, each with what its agent's terminal pane is doing right now: see [The Board](/docs/guides/todos/#the-board). **Agents** on the Board, and the terminal's agent overview, list the agents themselves: what each asks, a card's question while it waits in **Waiting**, which have made no progress for a while, what each checkout changed and the card's steps. See [Agent overview](/docs/guides/terminal/#agent-overview). Agents' work stays off **Today** and **All**. A card's link opens its pane when one is open in this window, else the board with the card selected. When the board is off, or the card isn't on it (one finished long ago, say), the link opens the card's note instead.

## Giving work to an agent

To hand one of your todos to a coding agent, choose **Give to an agent** in its menu in **Today** or **All**, or in a card's menu on the Board. It becomes a card in its project's board note with the agent `agent`, in the column its status gives it: **To do** for a todo you haven't started. Ask an agent in a terminal pane to pick up the work you handed over: with the skill it finds those cards with `aidectl board list`, links its pane with `aidectl board link` and moves the card to **Doing** as it starts. An agent you ask to take one of your todos directly can make it a card itself with `aidectl board adopt`. You move cards yourself too: see [The Board](/docs/guides/todos/#the-board).

## A worktree for a card

On the Mac and Linux, **Start in a worktree…** in a card's menu on the Board (or in its details) gives the card its own branch, `<project>/<card>-<title>`, in a git worktree beside the repository, and a terminal space working there. Start an agent in that space: its shells have `AIDE_BOARD_CARD`, so `aidectl board add` puts the agent's plan on this card instead of adding another, and `aidectl board link` with no card links its pane to it. AIDE doesn't link the card for the agent. When you end the space with **Also remove the worktree**, AIDE asks whether to move the card to **Waiting**, where you review it, or leave it. An agent can start one too, with `aidectl board start <card> --worktree`. See [Worktrees](/docs/guides/terminal/#worktrees).

## Turning it off

The board is on. Turn it off with **Settings › Todos › Agent board**. While the board is off, an agent's changes to cards are refused, AIDE doesn't give agents the skill, there's no **Board** in **Todos**, and agents' todos show in **All** like any other; reading cards still works.
