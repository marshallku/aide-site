AIDE를 실행하는 방법은 세 가지예요. 나중에 마음이 바뀌어도 노트를 잃지 않고 바꿀 수 있어요. 어떤
방식이든 노트는 폴더 안의 Markdown 파일이에요. 달라지는 건 그 옆에서 AIDE 서버가 돌아가느냐예요. 피드,
알림, 피드용 AI, 서버 플러그인에는 서버가 필요해요.

| | 로컬 모드 | 데스크톱 호스트 | 내 서버 |
| --- | --- | --- | --- |
| 노트가 있는 곳 | 이 기기의 폴더 | Mac이나 Linux 컴퓨터의 폴더 | 서버의 폴더 |
| 실행되는 것 | 앱만 | 앱과 AIDE 서버, 데이터베이스, 플러그인 러너가 모두 내 컴퓨터에서 | 항상 켜져 있는 기기의 AIDE 서버와 데이터베이스 |
| 다른 기기 | 없음: 보관소는 이 기기 전용이에요 | 페어링한 휴대폰과 컴퓨터, Tailscale이나 로컬 네트워크로 | 페어링한 모든 기기, HTTPS로 |
| 지원 플랫폼 | Mac, iPhone, Linux | Mac, Linux(iPhone은 여기에 연결해요) | 모든 기기가 여기에 연결해요 |

## 방식별로 되는 것

| 기능 | 로컬 모드 | 데스크톱 호스트 | 내 서버 |
| --- | --- | --- | --- |
| 편집기, 위키, 데일리 노트, 검색, 그래프, 리뷰 | 돼요 | 돼요 | 돼요 |
| 할 일과 할 일 보기 프리셋 | 돼요 | 돼요 | 돼요 |
| 스크래치와 정리 | 돼요: Anthropic API 키로, 또는 규칙으로 | 돼요 | 돼요 |
| 어시스턴트 | 돼요: Mac과 Linux에서는 Claude Code나 Codex, 또는 API 키로 | 돼요, 서버의 AI도 함께 | 돼요, 서버의 AI도 함께 |
| 회의(녹음, 받아쓰기) | 돼요 | 돼요 | 돼요 |
| 캘린더 | 이 기기의 캘린더, 읽기 전용(Linux에서는 웹 주소나 파일로 추가한 캘린더) | Google Calendar 플러그인으로 | Google Calendar 플러그인으로 |
| 기기 플러그인 | 돼요 | 돼요 | 돼요 |
| `aidectl` | 돼요 | 돼요 | 돼요 |
| 피드와 분류 | 안 돼요 | 돼요 | 돼요 |
| 알림 | 안 돼요 | 돼요 | 돼요 |
| 서버 플러그인(브리핑, 저녁 정리, Slack, 레이더…) | 안 돼요 | 돼요 | 돼요 |
| 서버용 **설정 › AI**(규칙, Anthropic API 키, 내 게이트웨이) | 안 돼요 | 돼요 | 돼요 |
| MCP를 통한 Claude | 안 돼요 | 호스팅하는 컴퓨터의 Claude Code(`aidectl mcp`) | Claude Code, 그리고 **설정 › Claude 앱**을 통한 Claude 앱 |
| 앱에서 백업 | 안 돼요(폴더를 복사하세요) | 호스트 설정의 **백업…** | 서버 자체 백업 |

로컬 모드에서는 설정에 "피드, 알림, AI, 서버 플러그인에는 서버가 필요해요."라고 표시돼요. 피드와 서버
플러그인 탭(레이더 등)은 나타나지 않고, **설정**에는 **기기** 페이지와 서버 플러그인이 없어요.

<Badge text="다음 릴리스" /> 로컬 모드에서도 **설정 › 플러그인**에 서버 플러그인 목록이 보이고, Mac과
Linux에서는 그 옆에 <strong>이 보관소 호스팅…</strong>이 나타날 예정이에요.

## 고르는 법

- **한 컴퓨터에서 노트와 할 일만 쓰고 싶거나, AIDE를 먼저 써 보고 싶다면:** 로컬 모드예요. 다른 건 아무것도
  돌지 않고, 나중에 같은 폴더를 호스팅할 수 있어요.
- **피드, 아침 브리핑, Slack이나 레이더를 쓰고 싶거나, 휴대폰에서도 같은 노트를 보고 싶다면:** 데스크톱
  호스트예요. 서버도, Docker도, 도메인도 필요 없어요. 호스트는 AIDE가 열려 있는 동안 돌아가고, **로그인한
  동안 계속 실행**을 켜면 로그인해 있는 내내 돌아가요. 기기들은 그 컴퓨터가 깨어 있는 동안 접속할 수 있어요.
- **컴퓨터가 잠자는 동안에도 플러그인이 돌아가야 하거나, claude.ai의 Claude 앱이 노트에 접근해야 한다면:**
  내 서버예요. AIDE 서버는 아직 공개 배포되지 않아서, 지금은 데스크톱 호스트로 서버 기능을 쓸 수 있어요.
  [내 서버 운영하기](/ko/docs/self-hosting/own-server/)를 보세요.

## 시작하기

AIDE를 처음 열면 **시작하기** 화면에서 노트를 둘 곳을 물어봐요. 이 기기에서 AIDE를 쓴 적이 있다면
**내 보관소**도 함께 보여 줘요.

**Mac과 iPhone:**

- **서버 없이**
    - **이 기기에 노트 보관**: AIDE 전용 폴더에 Markdown 파일로 둬요(iPhone에서는
      **파일 › 나의 iPhone › AIDE**).
    - **Open a folder…**: Obsidian 보관소처럼 이미 가진 폴더를 열어요. AIDE가 그 자리에서 편집하고, 다른
      앱의 편집도 지켜 줘요. iPhone에서는 파일 앱이나 iCloud Drive의 폴더를 골라요.
    - **백업 복원…**(Mac): 호스팅한 보관소의 백업을 새 폴더에 복원하고 이 Mac에서 호스팅해요.
- **내 AIDE 서버**: **서버**(주소)와 **페어링 코드**를 입력하고 **연결**을 눌러요.
- **호스트에 연결**: **페어링 링크**를 입력하고 **호스트에 연결**을 눌러요.

**Linux:**

- **이 컴퓨터에 노트 보관**
    - **새 보관소**: AIDE가 대신 관리하는 폴더예요.
    - **폴더 열기…**: Obsidian 보관소처럼 이미 가진 Markdown 노트 폴더예요.
    - **백업 복원…**: 호스팅한 보관소의 백업을 새 폴더에 복원하고 이 컴퓨터에서 호스팅해요.
- **서버에 연결**: **서버**와 **페어링 코드**를 입력하고 **연결**을 눌러요.
- **호스트에 연결**: **페어링 링크**를 입력하고 **호스트에 연결**을 눌러요.

맨 아래의 <strong>고급: 고정 토큰(개발용)</strong>은 개발용 서버를 위한 거라 쓸 일이 없어요.

데스크톱 호스트를 쓰려면 호스팅할 컴퓨터에서 로컬 모드로 시작한 다음, 그 보관소를 호스팅하세요(아래 참고).
페어링은 [기기 연결하기](/ko/docs/getting-started/connect-devices/)에서 다뤄요.

## 나중에 바꾸기

### 로컬 보관소 호스팅하기

<Steps>

1. Mac에서는 <strong>설정 › 노트 › 이 보관소 호스팅…</strong>을 열어요. Linux에서는 **설정 › 일반**을 열고 **노트**
   아래의 <strong>이 보관소 호스팅…</strong>을 골라요.
2. **호스팅 시작**을 눌러요. 시작하는 동안 창에 "호스트 시작 중…"이 표시돼요.

</Steps>

노트는 같은 폴더에 Markdown 파일로 그대로 남아요. 처음에는 이 컴퓨터의 나만 호스트에 접속할 수 있어요.
<strong>네트워크로 연결할 기기…</strong>를 켜기 전까지는 네트워크에서 아무것도 연결을 기다리지 않아요. 설정의 **노트**
섹션은 **호스트**로 바뀌고, 호스트 로그, **백업…**, **로그인한 동안 계속 실행**, <strong>호스팅 중지…</strong>가
들어가요. 자세한 내용은 [데스크톱에서 호스팅하기](/ko/docs/self-hosting/desktop-host/)에 있어요.

### 호스팅 중지하기

<strong>호스팅 중지…</strong>에 이어 **호스팅 중지**를 누르면 쓰던 내용을 저장하고, 호스트를 멈추고, 보관소를 이
컴퓨터 전용 노트로 열어요. 다시 호스팅하기 전까지 서버 플러그인, 피드, Claude는 멈춰요. 호스트는 그때를
위해 설정을 간직해 둬요. 호스트에 보관소의 끝나지 않은 작업(나를 기다리는 정리, 아직 전달하지 않은 변경)이
남아 있으면 **호스팅 중지**가 거부되고, **무시하고 중지**를 누르면 그 작업을 버려요.

### 서버로 노트 옮기기

로컬 모드에서 **설정 › 노트 › 서버로 노트 이동**(Linux에서는 **설정 › 일반 › 서버로 노트 이동…**)을
누르면 이 기기의 모든 노트를 서버의 빈 계정으로 옮기고, 그때부터 서버를 써요. 기기에는 백업 사본이 남아요.

### 노트를 이 기기로 되돌리기

서버에 연결된 상태에서 **설정 › 노트 › 이 기기에만 노트 보관**(Linux에서는 **설정 › 일반 › 이 기기에만
노트 보관…**)을 누르면 서버의 모든 노트를 AIDE 전용 폴더나 직접 고른 빈 폴더로 복사해요. 직접 고른 폴더는
Obsidian 같은 다른 앱에서도 열 수 있어요.

### 여러 보관소

보관소를 여러 개 두고 **설정 › 보관소**나 데스크톱 패널 아래쪽의 보관소 메뉴(iPhone에서는 스크래치의 도구
막대 메뉴)에서 전환할 수 있어요. 로그인한 서버도 여기에 함께 나와요.
[보관소와 파일](/ko/docs/guides/vaults/)을 보세요.

<Aside>
보관소에는 한 번에 한 곳만 쓸 수 있어요. AIDE(또는 호스트)가 폴더를 열고 있는 동안에는 다른 AIDE가 같은
폴더를 열 수 없어요. Obsidian 같은 다른 편집기는 열 수 있고, AIDE는 그 변경을 지켜 줘요.
</Aside>
