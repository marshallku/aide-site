AIDE는 직접 운영하는 노트 앱이자 개인 어시스턴트예요. 할 일과 스크래치패드가 있는 Markdown 편집기에서
글을 써요. AIDE는 스크래치 노트를 위키에 정리해 주고, 함께 하루를 계획하고, 다른 곳에서 일어난 일(캘린더,
메일, Slack, 이벤트를 보낼 수 있는 모든 것)을 하나의 피드에 모아 내가 챙겨야 할 순서대로 정렬해 줘요.

## 해결하려는 문제

남의 제품을 엮어 만든 개인 어시스턴트는 이음새에서 망가져요. 한 번은 채팅 앱을 화면으로, Git 위키나
Obsidian 보관소를 기억으로, 휴대폰 단축어를 입력으로 썼어요. 조각마다 한계가 있었고, 조각이 만나는
곳마다 무언가가 사라졌어요.

AIDE는 대신 전체를 직접 가져요. 자체 앱과 자체 서버로요. 앱은 창이고, 서버는 두뇌이자 기억이자
스케줄러예요. 노트는 폴더 안의 평범한 Markdown 파일로 남아서 다른 편집기로도 열 수 있어요. AI는 직접
가져오는 거예요. 내 Anthropic API 키, 컴퓨터에 이미 있는 Claude Code나 Codex를 쓰거나, AI를 아예 쓰지
않아도 돼요.

AIDE에는 데스크톱용 터미널([터미널과 SSH](/ko/docs/guides/terminal/)), 명령줄 도구 `aidectl`

## 세 가지 앱

| 앱 | 요구 사항 | 상태 |
| --- | --- | --- |
| Mac | macOS 14 Sonoma 이상, Apple silicon 또는 Intel | 정식 배포, 서명 및 공증 완료 |
| Linux | x86_64, GTK 4와 libadwaita | 정식 배포 |
| iPhone | iOS 17 이상 | TestFlight 베타, 아직 공개 전 <Badge text="베타" variant="caution" /> |

<Badge text="다음 릴리스" /> iPhone 앱은 iPad(iPadOS 17 이상)에서도 돌아가요. 전체 화면에서는 Mac 앱처럼
리본, 패널, 노트 탭, 오른쪽 패널로 보여요. Split View의 좁은 쪽이나 Slide Over에서는 iPhone의 탭으로
바뀌고, 보고 있던 노트는 바뀐 화면에서도 그대로 열려 있어요. 터미널은 Mac과 Linux에만 있고, iPad의
리본에는 그 자리에 SSH가 있어요.

세 앱은 같은 디자인과 같은 노트 형식을 써요. 플랫폼마다 다른 점은 각 페이지에 적어 두었어요.
[설치](/ko/docs/getting-started/install/)에서 Mac과 Linux를 다뤄요.

## 세 가지 실행 방식

1. **로컬 모드.** 서버 없이 한 기기의 폴더에 노트를 둬요. 편집기, 할 일, 스크래치, 위키, 캘린더,
   어시스턴트, 회의는 모두 동작하지만 피드, 알림, 서버 플러그인은 동작하지 않아요.
2. **데스크톱 호스트.** Mac이나 Linux 컴퓨터가 보관소 하나를 위한 AIDE 서버를 돌려요. 자체 데이터베이스와
   플러그인 러너가 앱에 함께 들어 있어요. 휴대폰과 다른 컴퓨터는 이 컴퓨터와 페어링해요.
3. **내 서버.** 같은 서버를 항상 켜져 있는 기기에서 돌려요.

[AIDE 실행 방식](/ko/docs/getting-started/ways-to-run/)에서 셋을 비교하고 고르는 걸 도와드려요.

## AIDE가 아닌 것

- **클라우드 서비스가 아니에요.** 누구도 대신 서버를 돌려 주지 않아요. 데스크톱 호스트나 내 서버가 없으면
  AIDE는 한 기기의 노트 앱이에요.
- **App Store에 없어요.** iPhone 앱은 TestFlight 베타이고 아직 공개되지 않았어요. iPhone으로 푸시 알림을
  보내려면 푸시 릴레이가 필요한데, 공개된 릴레이는 아직 없어요.
- **바로 쓰는 서버 이미지가 아니에요.** 서버의 Docker 이미지는 아직 배포되지 않았어요. 지금은 데스크톱
  호스트로 서버 기능을 쓸 수 있어요.
- **여러 사람이 쓰는 앱이 아니에요.** 서버 하나는 한 사람의 것이에요. 다른 사람과 보관소를 공유하는 기능은
  없어요.
- **AI 구독 상품이 아니에요.** AIDE는 모델 사용권을 팔지 않아요. 내 키나 CLI를 가져오거나, AI 없이 동작하는
  규칙을 쓰세요.
