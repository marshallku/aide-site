AIDE의 모든 화면은 몇 가지 개념 위에 만들어져 있어요. 이 개념들을 알면 나머지 매뉴얼을 더 빨리 읽을 수
있어요.

## 구성 요소

```text
  iPhone · Mac · Linux apps          aidectl · Claude (MCP)
             │                               │
             │ paired devices                │ this computer
             ▼                               ▼
  ┌──────────────────────── AIDE server ────────────────────────┐
  │  notes · todos · Organize · Feed + triage · AI · push       │
  │                                                             │
  │  database: the event log, settings, note metadata           │
  └───────┬──────────────────────────────┬──────────────────────┘
          │                              │ scoped tokens
          ▼                              ▼
  your vault: Markdown files     plugin runner: briefing, recap,
  in a folder                    Google Calendar, Slack, Radar…
```

로컬 모드에는 서버 상자가 없어요. 앱이 보관소 폴더를 직접 열고, `aidectl`은 실행 중인 앱을 통해 보관소에
접근해요. 데스크톱 호스트에서는 서버, 데이터베이스, 플러그인 러너가 앱의 일부로 내 컴퓨터에서 돌아가요.
[AIDE 실행 방식](/ko/docs/getting-started/ways-to-run/)에서 세 가지 구성을 비교해요.

## 보관소와 노트

**보관소**는 Markdown 파일이 담긴 폴더예요. 모든 `.md` 파일이 노트이고, 이미지와 다른 파일은
`attachments/`에 들어가요. AIDE는 자기 관리용 정보를 숨김 폴더 `.aide/`에 둬요. 내보내기 단계는 없어요.
파일이 곧 노트이고, Obsidian 같은 다른 편집기도 같은 폴더를 열 수 있어요. AIDE는 그 편집을 반영하고 절대
덮어쓰지 않아요.

노트는 `[[wikilinks]]`로 서로 연결되고, 이미지와 그림을 임베드할 수 있고, 프런트매터 속성을 가질 수 있어요.
노트를 삭제하면 **설정 › 최근 삭제된 항목**으로 옮겨져요. 영구히 삭제되는 건 없어요.
[노트와 편집기](/ko/docs/guides/editor/)와 [보관소와 파일](/ko/docs/guides/vaults/)을 보세요.

## 스크래치에서 위키로

노트는 두 곳에 있어요.

- **스크래치**는 어디에 둘지 정하지 않고 쓰는 곳이에요. 데스크톱에서는 빈 탭에 입력하면 스크래치 노트가
  만들어져요.
- **위키**는 정리된 노트예요. 주제, 프로젝트, 주기 노트(일간, 주간, 월간, 분기, 연간)가 여기에 있어요.

**정리**는 스크래치를 위키로 옮겨요. 스크래치 노트를 골라 **제안받기**를 누르면, AIDE가 노트마다 새 페이지나
기존 페이지에 덧붙일 섹션 같은 자리를 제안해요. 제안을 확인하고 **적용**하기 전까지는 아무것도 바뀌지 않아요.
적용한 노트는 스크래치에서 삭제되지 않고 보관돼요. [스크래치와 정리](/ko/docs/guides/scratch/)를 보세요.

## 할 일은 노트 안에 있어요

할 일만 따로 모아 두는 데이터베이스는 없어요. 어느 노트에 있든 모든 `- [ ]` 줄이 할 일이고, **할 일** 화면이
보관소 전체에서 이를 모아 보여 줘요. 할 일에는 Obsidian Tasks나 Dataview 문법으로 날짜, 우선순위, 시간
블록, 태그, 예상 소요 시간을 달 수 있어요.

```markdown
- [ ] Send the invoice 📅 2026-10-24 ⏫ #work
- [/] 09:00 - 10:30 Write the quarterly plan [estimate:: 90m]
```

할 일 화면에서 완료로 체크하면 해당 노트의 그 줄이 수정돼요. [할 일](/ko/docs/guides/todos/)을 보세요.

## 피드

**피드**는 노트 밖에서 일어나는 모든 일을 담는 하나의 이벤트 로그예요. 플러그인, 스크립트, 다른 서비스가
토픽에 이벤트를 보내면, 기기들이 로그를 읽고 어디까지 읽었는지 기억해요. 각 이벤트는 다음 중 하나로
**분류**돼요.

| 분류 | 들어가는 것 | 알림 |
| --- | --- | --- |
| **조치 필요** | 내가 무언가 해야 하는 일: 마감, 신청, 결제 | 항상 |
| **알아둘 내용** | 할 일은 없어도 중요한 것 | 끄지 않는 한 |
| **관심 있을 만한 내용** | 내 위키의 주제와 맞는 것 | 없음 |
| **나머지** | 그 밖의 것, 접힌 채로 | 없음 |

피드에는 서버나 데스크톱 호스트가 필요해요. [피드](/ko/docs/guides/feed/)와
[피드에 이벤트 보내기](/ko/docs/developers/events/)를 보세요.

## 플러그인

플러그인은 두 종류예요.

- **서버 플러그인**은 AIDE 플러그인 러너에서 서버 옆에 돌아가고, 각자 권한이 제한된 토큰을 가져요. 기기가
  꺼져 있어도 동작해요. 아침 브리핑, 저녁 정리, Google Calendar, Gmail, Slack, 레이더 등이 있어요.
  **설정 › 코어 플러그인**에 나오고, 직접 켜기 전까지는 꺼져 있어요. 데스크톱 호스트나 내 서버가
  필요해요.
- **기기 플러그인**은 앱 안의 샌드박스에서 돌아가고, 설치할 때 승인한 권한만 가져요. 뽀모도로 타이머,
  Excalidraw 그림, 글자 수 세기 등이 있어요. 로컬 모드에서도 동작해요.

플러그인은 **슬롯**을 통해 노트에 내용을 써요. 템플릿에 `{{slot todo-carry.open}}` 같은 줄을 넣으면 그
플러그인이 계속 최신으로 유지하는 블록이 돼요. [플러그인의 동작 방식](/ko/docs/plugins/overview/)을 보세요.

## 어시스턴트

**어시스턴트**는 채팅으로 함께 하루를 계획해요. 열린 할 일, 오늘 캘린더, 비어 있는 시간을 보고 제안으로
답해요(이건 일정에 넣고, 저건 소요 시간을 잡고, 이건 내일로 미루기). 제안은 하나하나 내가 받아들이거나
버릴 때까지 기다려요. 받아들인 제안은 무엇이 바뀌었는지 기록과 함께 노트에 반영돼요.
[어시스턴트](/ko/docs/guides/assistant/)를 보세요.

## AI를 쓰는 곳

AI는 어디서든 선택 사항이에요. 모델이 어디서 돌지는 직접 골라요.

- **내 컴퓨터에서:** Claude Code나 Codex가 설치되어 있다면 그걸 써요(Mac과 Linux). 도구 없이 빈 임시
  폴더에서 실행돼요. 프롬프트가 들어가고 답이 나올 뿐이에요.
- **내 Anthropic API 키로:** 기기에 두거나, 서버에 암호화해서 저장해요.
- **내 서버에서:** **설정 › AI**에서 **규칙(AI 미사용)**, **Anthropic API 키**, **내 게이트웨이**(내 Claude
  로그인으로 직접 운영하는 게이트웨이) 중에서 골라요.

모델의 출력은 그대로 믿지 않아요. AIDE가 요청한 형식에 맞지 않는 답은 거부하고, 노트를 바꾸는 일은 내 승인을
기다려요.

| 기능 | AI를 쓸 때 | AI 없이 |
| --- | --- | --- |
| 정리 | 노트 내용과 위키 페이지 이름을 보고 스크래치 노트마다 자리를 제안해요 | 규칙으로: 노트의 첫 `#tag`는 `topics/<tag>`로, 할 일이 있는 노트는 오늘 데일리 노트로, 나머지는 `inbox`로 가요 |
| 피드 분류 | 모델이 이유와 함께 이벤트마다 분류해요 | 규칙으로: 마감을 뜻하는 단어("due", "deadline", "apply by"…)가 있으면 조치 필요, 보낸 쪽이 심각도 높음으로 표시한 이벤트는 알아둘 내용, 위키의 주제를 언급하는 이벤트는 관심 있을 만한 내용이에요 |
| 어시스턴트 | 함께 계획해요 | 쓸 수 없어요 |
| 회의 | 요약, 결정 사항, 할 일 항목 | 녹음과 받아쓰기는 그대로 돼요. 받아쓰기는 기기에서 돌아가요 |
| 브리핑, 저녁 정리, 지난 작업 정리 등 AI 플러그인 | 노트를 써 줘요 | 쓸 수 없어요 |

그 밖의 모든 것(편집기, 할 일, 검색, 그래프, 리뷰, 캘린더, 기기 플러그인)은 AI를 전혀 쓰지 않아요.
[AI와 모델](/ko/docs/guides/ai/)을 보세요.
