Google 캘린더 플러그인은 Google 캘린더를 AIDE로 가져와요. 캘린더 섹션에 일정이 보이고, 오늘 일정이 데일리 노트에 들어가고, 회의 몇 분 전에 알림과 준비할 내용을 받아요.

<PluginFacts id="gcal" />

## 하는 일

**캘린더를 AIDE에 보여 줘요.** 5분마다 캘린더 목록과 7일 전부터 6주 뒤까지의 일정(캘린더마다 최대 300개)을 읽고, [캘린더](/ko/docs/guides/calendar/) 섹션에 보여 줘요. 읽지 못한 캘린더는 마지막으로 읽은 일정을 그대로 두고, **동기화하지 못했어요**와 함께 이유를 보여 줘요.

**오늘 일정을 써요.** `{{slot gcal.today}}`가 있는 템플릿으로 만든 데일리 노트에, 보이도록 설정한 캘린더의 그날 일정을 종일 일정부터 나열해요.

```markdown
- All day Team offsite
- 09:30–10:00 Standup (Room 4)
- 14:00–15:00 Design review
```

일정이 없는 날에는 `- 일정 없음`이라고 써요. 목록은 데일리 노트가 만들어질 때 쓰이고 동기화할 때마다 갱신돼요. 그래서 하루 중에 추가하거나 옮긴 일정도 5분 안에 반영돼요.

**일정 전에 알려 줘요.** 알림을 켠 캘린더를 매분 확인해요. 시간이 정해진 일정이 알림 시간(기본 10분) 안에 시작하면 피드에 알림을 올려요. 제목은 "10분 후: Design review" 같은 형태이고, 시간, 장소, 일정 링크, 화상 회의 링크가 함께 들어가요. 이 알림은 항상 알림을 보내요. 종일 일정은 알리지 않아요. 일정마다 한 번만 알려요.

**준비 노트를 써요.** 알림 직후 AI에 무엇을 준비할지 물어봐요. AI는 일정과 제목이 맞는 노트를 받아서, 회의 주제, 관련된 미완료 할 일이나 결정 사항, 해야 할 일 한 가지에서 세 가지를 답해요. 답은 하루 노트(`briefings/{date}`)의 `#### 14:00 Design review 준비` 같은 제목 아래에 들어가요. **준비할 내용이 있으면 알려주기**를 켜면, AI가 구체적인 것(읽을 문서, 남은 결정, 챙길 물건)을 찾았는지도 판단해서, 찾았을 때만 "14:00 Design review 준비"라는 알림으로 보내요. 준비 노트는 한 번에 일정 하나씩, 최대 90초 동안 만들어요. 기다리는 일정이 8개를 넘으면 넘는 만큼은 건너뛰어요.

**회의 노트를 채워요.** 일정으로 만든 [회의 노트](/ko/docs/guides/meetings/)에 캘린더가 아는 내용을 담은 섹션을 유지해요. 시간, 장소, 화상 회의 링크, 다른 참석자, 일정 링크와 설명이 들어가고, 일정이 취소되면 취소됐다고 표시해요.

<Badge text="다음 릴리스" /> 제목이 없는 일정은 일정 목록, 알림, 준비 노트, 앱의 캘린더에 "(제목 없음)"으로 보여요. 플러그인이 쓰는 언어가 영어면 "(No title)"이에요.

## 시작하기 전에

- [데스크톱 호스트](/ko/docs/self-hosting/desktop-host/)나 직접 운영하는 서버가 필요해요. 플러그인은 거기서 실행되고, 그 컴퓨터에서 Google을 읽어요.
- Google 계정이 필요해요. <Badge text="다음 릴리스" /> 앱에서 플러그인 설정을 열고 로그인하면 되고, 직접 만든 OAuth 클라이언트는 필요 없어요. 이번 릴리스까지는 직접 만든 `credentials.json`과 토큰 파일이 있어야 했어요([내 OAuth 파일 쓰기](#내-oauth-파일-쓰기) 참고).
- 준비 노트를 쓰려면 **설정 › AI**에 AI(**Anthropic API 키** 또는 **내 게이트웨이**)가 설정돼 있어야 해요.

## 설정하기

<Steps>

1. 플러그인을 켜요. **설정 › 코어 플러그인**에서 **캘린더**를 고르고 **활성화됨**을 켜요(Linux에서는 설정의 **코어 플러그인** 페이지에서 해당 행의 스위치). [플러그인 켜기](/ko/docs/plugins/overview/#플러그인-켜기)를 참고하세요.
2. <Badge text="다음 릴리스" /> 1분 안에 플러그인 설정 아래의 상태에 "캘린더를 읽으려면 로그인해 주세요…"와 **Google로 로그인** 버튼이 나와요. 버튼을 누르고 Google 계정을 고른 뒤 AIDE가 캘린더를 보도록 허용해요.
    - **플러그인을 실행하는 컴퓨터에서**(데스크톱 호스트의 앱): 브라우저가 알아서 AIDE로 돌아오고 "AIDE is signed in to Google. You can close this tab."라고 나와요.
    - **휴대폰이나 다른 컴퓨터에서**: 브라우저가 `http://127.0.0.1`로 시작하는 주소에서 열리지 않는 페이지로 끝나요. 그 주소 전체를 복사해 플러그인의 **로그인 링크** 설정에 붙여 넣고 저장해요. 몇 초 안에 플러그인이 가져가요.

    그러면 상태가 "Google 캘린더에 연결됐어요"로 바뀌어요. 로그인 링크는 10분 동안 한 번만 쓸 수 있고, 그 뒤에는 버튼이 새 링크를 열어요.
3. 1~2분 안에 캘린더 섹션에 캘린더가 나타나요.
4. 플러그인 아래의 <strong>캘린더…</strong>를 눌러 보여 줄 캘린더, 알림을 받을 캘린더, 색상을 골라요.
5. 데일리 노트에 일정을 넣으려면 데일리 템플릿에 `{{slot gcal.today}}`를 추가해요([데일리 노트와 템플릿](/ko/docs/guides/periodic-notes/) 참고).

</Steps>

<Aside type="caution" title="Google이 AIDE를 확인하지 않은 앱이라고 경고할 수 있어요">
Google이 AIDE의 로그인 검토를 마치기 전까지는 동의 화면에 **Google에서 확인하지 않은 앱**이라는 경고가 나올 수 있어요. 계속하려면 **고급**을 누른 뒤 **AIDE(으)로 이동(안전하지 않음)**을 골라요. AIDE는 읽기 권한만 요청하고, 토큰은 플러그인을 실행하는 컴퓨터에만 있어요. 검토가 끝나기 전에는 AIDE의 클라이언트로 로그인할 수 있는 사람 수도 Google이 제한해요. 로그인이 거절되면 [내 OAuth 파일 쓰기](#내-oauth-파일-쓰기)를 참고하세요.
</Aside>

토큰은 플러그인을 실행하는 컴퓨터의 플러그인 상태 폴더에 남아요. [아침 브리핑](/ko/docs/plugins/briefing/)도 이 로그인으로 캘린더를 읽어요.

캘린더는 Google 캘린더처럼 **내 캘린더**와 **다른 캘린더**로 묶여 있어요.

### 로컬 키

데스크톱 호스트의 `plugins.json`([로컬 설정](/ko/docs/plugins/overview/#로컬-설정) 참고)에서 `"gcal"` 아래에 적어요.

| 키                | 하는 일                                                                                                  |
| ----------------- | -------------------------------------------------------------------------------------------------------- |
| `credentials`     | 직접 만든 OAuth 클라이언트 파일 경로(아래 참고). 비우면 AIDE의 클라이언트를 써요.                         |
| `tokenFile`       | 직접 만든 토큰 파일 경로(아래 참고). 비우면 앱에서 로그인한 계정을 써요.                                  |
| `note`            | 준비 노트를 쓸 곳: `{date}`가 들어간 노트 경로, 또는 데일리 노트에 쓰려면 `daily`. 기본값 `briefings/{date}`. |
| `reminderMinutes` | 시트에서 고르기 전까지 쓸 알림 시간. 기본값 `10`.                                                        |
| `prep`            | 시트에서 고르기 전까지 준비 노트 켜기/끄기. 기본값 `true`.                                               |
| `prepNotify`      | 시트에서 고르기 전까지 **준비할 내용이 있으면 알려주기** 켜기/끄기. 기본값 `false`.                       |

```json
{
    "plugins": {
        "gcal": {
            "credentials": "~/secrets/google/credentials.json",
            "tokenFile": "~/secrets/google/calendar-token.json",
            "note": "daily"
        }
    }
}
```

### 내 OAuth 파일 쓰기

Google로 로그인이 생기기 전의 설정도 그대로 작동해요. 플러그인은 다음 순서로 써요.

1. `tokenFile`에 적은 토큰 파일과 `credentials`에 적은 클라이언트.
2. <Badge text="다음 릴리스" /> 앱에서 로그인한 계정.
3. 이번 릴리스 전에 읽던 파일이 있으면 그 파일: `~/.config/life-assistant/google-token.json`과 `~/.config/life-assistant/credentials.json`의 클라이언트.

토큰 파일은 같은 클라이언트로 캘린더 읽기 전용 범위(`https://www.googleapis.com/auth/calendar.readonly`)를 받은 것이어야 해요. Google이 토큰을 갱신하면 플러그인은 새 토큰을 자기 상태 폴더에 저장하고, 내 토큰 파일에는 쓰지 않아요. 나중에 다시 로그인해서 토큰 파일을 바꾸면 더 새로운 파일을 써요. 이런 파일을 쓰는 동안에는 **Google로 로그인** 버튼이 나오지 않아요. 단, Google이 예전 파일의 토큰을 거부하면 버튼이 나와요([캘린더가 다시 로그인하라고 해요](#캘린더가-다시-로그인하라고-해요) 참고).

## 문제 해결

### 캘린더가 보이지 않아요

- <Badge text="다음 릴리스" /> 플러그인 설정 아래의 상태를 보세요. "캘린더를 읽으려면 로그인해 주세요…"라면 아직 로그인을 기다리고 있어요.
- "오래됐거나 이미 쓴 로그인 링크예요. 다시 로그인해 주세요": 붙여 넣은 주소가 이전 시도의 것이에요. **Google로 로그인**을 다시 누르고 새 주소를 붙여 넣으세요.
- "이 빌드는 Google에 로그인할 수 없어요. 플러그인 설정 파일에 credentials를 적어 주세요": 이 AIDE에는 Google 클라이언트가 들어 있지 않아요. [내 OAuth 파일](#내-oauth-파일-쓰기)을 쓰세요.
- 내 파일을 쓸 때는 파일을 읽을 수 있어야 플러그인이 시작돼요. 플러그인은 30초마다 다시 시도하고, 호스트 로그(경로는 설정 › 호스트의 **로그**에 있어요)에 읽지 못한 파일이 나와요. 경로를 확인하고, 토큰이 `credentials.json`과 같은 OAuth 클라이언트로 발급됐는지 확인하세요.

### 캘린더가 다시 로그인하라고 해요

<Badge text="다음 릴리스" /> Google이 플러그인의 접근을 더 받지 않아요([myaccount.google.com/permissions](https://myaccount.google.com/permissions)에서 권한을 없앴거나 비밀번호를 바꿨을 때). 플러그인이 거부된 토큰을 치워 두고 **Google로 로그인** 버튼을 다시 보여 줘요. 앱에서 한 로그인도, 이번 릴리스 전에 읽던 파일(`~/.config/life-assistant/google-token.json`)도 마찬가지예요. 그런 파일은 바뀔 때까지 건너뛰고, 지우지는 않아요. `tokenFile`로 적은 내 토큰 파일은 치워 두지 않으니, 직접 다시 로그인해서 파일을 바꿔 주세요.

### google: no refresh token came back

Google이 오래가는 토큰을 주지 않았어요. 보통 AIDE를 전에 허용한 적이 있을 때예요. [myaccount.google.com/permissions](https://myaccount.google.com/permissions)에서 AIDE의 접근 권한을 없앤 뒤 다시 로그인하세요.

### 준비 노트가 데일리 노트에 없어요

`plugins.json`의 `note`가 `daily`가 아니면 준비 노트는 하루 노트 `briefings/{date}`에 들어가요. 준비 노트를 쓰려면 **설정 › AI**에 AI도 설정돼 있어야 해요.

### 잠자기 중이던 일정의 알림이 오지 않았어요

컴퓨터가 잠자기 중일 때 시간이 된 알림은 깨어날 때 건너뛰어요. 일정이 시작된 뒤에 도착하기 때문이에요.

### 데일리 노트 일정에 "일부 캘린더를 읽지 못했어요"라고 나와요

그날 다른 캘린더는 읽었지만 한 캘린더를 읽지 못했어요. 보통 접근 권한을 잃은 캘린더예요. <strong>캘린더…</strong>에서 그 캘린더의 스위치를 꺼 주세요.

## 개인정보

플러그인은 플러그인을 실행하는 컴퓨터에서 읽기 전용 권한으로 Google Calendar API와 통신하고, 캘린더를 바꾸지 않아요. Google 토큰은 그 컴퓨터의 플러그인 상태 폴더에 남아요. 지난 1주와 앞으로 6주의 일정은 앱에서 보여 주기 위해 호스트나 서버에 플러그인 상태로 저장돼요(설명은 300자까지만). 준비 노트를 쓸 때는 일정의 제목, 시간, 장소와 제목이 맞는 노트가 **설정 › AI**에서 정한 AI로 전달돼요.
