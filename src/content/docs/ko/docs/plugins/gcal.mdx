Google 캘린더 플러그인은 Google 캘린더를 AIDE로 가져와요. 캘린더 섹션에 일정이 보이고, 오늘 일정이 데일리 노트에 들어가고, 회의 몇 분 전에 알림과 준비할 내용을 받아요.

<PluginFacts id="gcal" />

<Aside type="caution" title="아직 로그인 안내가 없어요">
이 플러그인은 직접 준비한 OAuth 토큰 파일로 Google을 읽어요([시작하기 전에](#시작하기-전에) 참고). AIDE는 아직 Google 캘린더용 토큰 파일을 만들어 주지 못해요. 내장된 Google 로그인(`aide-plugins google-auth`)은 Gmail만 지원하고, Gmail 토큰으로는 캘린더를 읽을 수 없어요. Google 캘린더 토큰이 없다면 지금은 이 플러그인을 쓸 수 없어요.
</Aside>

## 하는 일

**캘린더를 AIDE에 보여 줘요.** 5분마다 캘린더 목록과 7일 전부터 6주 뒤까지의 일정(캘린더마다 최대 300개)을 읽고, [캘린더](/ko/docs/guides/calendar/) 섹션에 보여 줘요. 읽지 못한 캘린더는 마지막으로 읽은 일정을 그대로 두고, **동기화하지 못했어요**와 함께 이유를 보여 줘요.

**오늘 일정을 써요.** `{{slot gcal.today}}`가 있는 템플릿으로 만든 데일리 노트에, 보이도록 설정한 캘린더의 그날 일정을 종일 일정부터 나열해요.

```markdown
- All day Team offsite
- 09:30–10:00 Standup (Room 4)
- 14:00–15:00 Design review
```

일정이 없는 날에는 `- 일정 없음`이라고 써요. 목록은 데일리 노트가 만들어질 때 쓰이고 동기화할 때마다 갱신돼요. 그래서 하루 중에 추가하거나 옮긴 일정도 5분 안에 반영돼요.

**일정 전에 알려 줘요.** 알림을 켠 캘린더를 매분 확인해요. 시간이 정해진 일정이 알림 시간(기본 10분) 안에 시작하면 피드에 알림을 올려요. 제목은 "10분 후: Design review" 같은 형태이고, 시간, 장소, 일정 링크, 화상 회의 링크가 함께 들어가요. 이 알림은 항상 알림을 보내요. 종일 일정은 알리지 않아요. 일정마다 한 번만 알려요.

**준비 노트를 써요.** 알림 직후 AI에 무엇을 준비할지 물어봐요. AI는 일정과 제목이 맞는 노트를 받아서, 회의 주제, 관련된 미완료 할 일이나 결정 사항, 해야 할 일 한 가지에서 세 가지를 답해요. 답은 하루 노트(`briefings/{date}`)의 `#### 14:00 Design review 준비` 같은 제목 아래에 들어가요. **준비할 내용이 있으면 알려주기**를 켜면, AI가 구체적인 것(읽을 문서, 남은 결정, 챙길 물건)을 찾았는지도 판단해서, 찾았을 때만 "14:00 Design review 준비"라는 알림으로 보내요. 준비 노트는 한 번에 일정 하나씩, 최대 90초 동안 만들어요. 기다리는 일정이 8개를 넘으면 넘는 만큼은 건너뛰어요.

**회의 노트를 채워요.** 일정으로 만든 [회의 노트](/ko/docs/guides/meetings/)에 캘린더가 아는 내용을 담은 섹션을 유지해요. 시간, 장소, 화상 회의 링크, 다른 참석자, 일정 링크와 설명이 들어가고, 일정이 취소되면 취소됐다고 표시해요.

## 시작하기 전에

- [데스크톱 호스트](/ko/docs/self-hosting/desktop-host/)나 직접 운영하는 서버가 필요해요. 플러그인은 거기서 실행되고, 그 컴퓨터에서 Google을 읽어요.
- 준비 노트를 쓰려면 **설정 › AI**에 AI(**Anthropic API 키** 또는 **내 게이트웨이**)가 설정돼 있어야 해요.
- 플러그인을 실행하는 컴퓨터에 파일 두 개가 필요해요.
    - `credentials.json`: 내 Google Cloud 콘솔 프로젝트에서 **Desktop app**으로 만든 OAuth 클라이언트예요. Google Calendar API를 켜 둬야 해요.
    - 그 클라이언트의 토큰 파일: 캘린더 읽기 전용 범위(`https://www.googleapis.com/auth/calendar.readonly`)를 받은 토큰이에요. `access_token`, `token_type`, `refresh_token`, `expiry`가 담긴 JSON이에요.

플러그인은 기본으로 `~/.config/life-assistant/credentials.json`과 `~/.config/life-assistant/google-token.json`에서 찾아요. 다른 곳에 두려면 `plugins.json`에 경로를 적어요(아래 참고).

## 설정하기

<Steps>

1. `credentials.json`과 토큰 파일을 기본 경로나 `plugins.json`에 적은 경로에 둬요.
2. 플러그인을 켜요. 설정의 **서버에 저장** 아래에서 **캘린더**를 고르고 **활성화됨**을 켜요(Linux에서는 **설정 › 플러그인**에서 해당 행의 스위치). [플러그인 켜기](/ko/docs/plugins/overview/#플러그인-켜기)를 참고하세요.
3. 1~2분 안에 캘린더 섹션에 캘린더가 나타나요.
4. 플러그인 아래의 <strong>캘린더…</strong>를 눌러 보여 줄 캘린더, 알림을 받을 캘린더, 색상을 골라요.
5. 데일리 노트에 일정을 넣으려면 데일리 템플릿에 `{{slot gcal.today}}`를 추가해요([데일리 노트와 템플릿](/ko/docs/guides/periodic-notes/) 참고).

</Steps>

## 설정

이 플러그인에는 설정 표가 없어요. 설정은 설정의 플러그인 아래에 있는 **캘린더…** 시트에 있어요(Linux에서는 펼친 행의 **캘린더…** 행).

| 시트 항목                                            | 하는 일                                                                                           | 기본값  |
| ---------------------------------------------------- | ------------------------------------------------------------------------------------------------- | ------- |
| 캘린더별 스위치                                      | AIDE와 데일리 노트 일정에 그 캘린더를 보여 줘요                                                    | Google 캘린더 목록에 보이는 대로 |
| 캘린더별 종 아이콘                                   | 그 캘린더 일정의 알림                                                                              | 모든 캘린더에서 켬 |
| 캘린더별 색상 점                                     | AIDE에서 쓸 색상: Google 팔레트, 직접 고른 색, 또는 **Google 색상 사용**                           | Google 색상 |
| **일정 전 리마인더**                                 | 모든 캘린더의 알림을 켜고 꺼요                                                                     | 켬 |
| **시점**                                             | 얼마나 전에 알릴지: **5분 전**, **10분 전**, **15분 전**, **30분 전**, **60분 전**                                                     | 10분 전 |
| **데일리 노트에 AI 회의 준비 노트 작성**             | 알림마다 준비 노트를 써요                                                                          | 켬 |
| **준비할 내용이 있으면 알려주기**                    | AI가 구체적으로 준비할 것을 찾으면 알림도 보내요                                                   | 끔 |

캘린더는 Google 캘린더처럼 **내 캘린더**와 **다른 캘린더**로 묶여 있어요.

### 로컬 키

데스크톱 호스트의 `plugins.json`([로컬 설정](/ko/docs/plugins/overview/#로컬-설정) 참고)에서 `"gcal"` 아래에 적어요.

| 키                | 하는 일                                                                                                  |
| ----------------- | -------------------------------------------------------------------------------------------------------- |
| `credentials`     | OAuth 클라이언트 파일 경로. 기본값 `~/.config/life-assistant/credentials.json`.                          |
| `tokenFile`       | 토큰 파일 경로. 기본값 `~/.config/life-assistant/google-token.json`.                                     |
| `note`            | 준비 노트를 쓸 곳: `{date}`가 들어간 노트 경로, 또는 데일리 노트에 쓰려면 `daily`. 기본값 `briefings/{date}`. |
| `reminderMinutes` | 시트에서 고르기 전까지 쓸 알림 시간. 기본값 `10`.                                                        |
| `prep`            | 시트에서 고르기 전까지 준비 노트 켜기/끄기. 기본값 `true`.                                               |
| `prepNotify`      | 시트에서 고르기 전까지 **준비할 내용이 있으면 알려주기** 켜기/끄기. 기본값 `false`.                       |

```json
{
    "plugins": {
        "gcal": {
            "credentials": "~/secrets/google/credentials.json",
            "tokenFile": "~/secrets/google/calendar-token.json",
            "note": "daily"
        }
    }
}
```

Google이 토큰을 갱신하면 플러그인은 새 토큰을 자기 상태 폴더에 저장하고, 내 토큰 파일에는 쓰지 않아요. 나중에 다시 로그인해서 토큰 파일을 바꾸면 더 새로운 파일을 써요.

## 문제 해결

### 캘린더가 보이지 않아요

Google 파일 두 개가 모두 있어야 플러그인이 시작돼요. 플러그인은 30초마다 다시 시도하고, 호스트 로그(경로는 설정 › 호스트의 **로그**에 있어요)에 읽지 못한 파일이 나와요. 경로를 확인하고, 토큰이 `credentials.json`과 같은 OAuth 클라이언트로 발급됐는지 확인하세요.

### 준비 노트가 데일리 노트에 없어요

`plugins.json`의 `note`가 `daily`가 아니면 준비 노트는 하루 노트 `briefings/{date}`에 들어가요. 준비 노트를 쓰려면 **설정 › AI**에 AI도 설정돼 있어야 해요.

### 잠자기 중이던 일정의 알림이 오지 않았어요

컴퓨터가 잠자기 중일 때 시간이 된 알림은 깨어날 때 건너뛰어요. 일정이 시작된 뒤에 도착하기 때문이에요.

### 데일리 노트 일정에 "일부 캘린더를 읽지 못했어요"라고 나와요

그날 다른 캘린더는 읽었지만 한 캘린더를 읽지 못했어요. 보통 접근 권한을 잃은 캘린더예요. <strong>캘린더…</strong>에서 그 캘린더의 스위치를 꺼 주세요.

## 개인정보

플러그인은 플러그인을 실행하는 컴퓨터에서 읽기 전용 권한으로 Google Calendar API와 통신하고, 캘린더를 바꾸지 않아요. 지난 1주와 앞으로 6주의 일정은 앱에서 보여 주기 위해 호스트나 서버에 플러그인 상태로 저장돼요(설명은 300자까지만). 준비 노트를 쓸 때는 일정의 제목, 시간, 장소와 제목이 맞는 노트가 **설정 › AI**에서 정한 AI로 전달돼요.
