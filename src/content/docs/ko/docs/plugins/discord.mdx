Discord 플러그인은 내가 만든 Discord 봇을 AIDE에 연결해요. 팔로우한 채널의 메시지, 멘션, DM이 피드에 오고,
메시지에 🔖 반응을 달면 그 메시지를 노트로 저장해요.

<PluginFacts id="discord" />

## 하는 일

### 피드에 오는 메시지

봇은 내가 초대한 서버를 읽어요. 본 것은 피드로 가요.

| 피드 항목                            | 언제                                                                                      | 푸시   |
| ------------------------------------ | ----------------------------------------------------------------------------------------- | ------ |
| **&lt;이름&gt;님의 Discord 메시지**  | **팔로우할 채널**에 있는 채널에 누군가 글을 써요.                                         | 없음   |
| **&lt;이름&gt;님이 나를 멘션했어요** | 봇이 읽는 어느 채널에서든 메시지가 봇을, 또는 **내 사용자 ID**를 정했다면 나를 멘션해요.   | 있음   |
| **&lt;이름&gt;님이 DM을 보냈어요**   | **허용할 사용자**에 있는 사람(또는 나)이 봇에게 DM을 보내요.                              | 있음   |
| **&lt;이름&gt;님이 … 반응을 달았어요** | 팔로우한 채널의 메시지에 누군가 반응을 달거나, 허용된 사용자가 봇과의 DM에서 반응을 달아요. | 없음   |

항목마다 Discord의 해당 메시지로 가는 링크가 있어요. 봇이 보낸 메시지(이 플러그인의 봇 포함)와 시스템
메시지(참여, 고정)는 빼요. 허용되지 않은 사람의 DM은 무시해요.

### 메시지를 노트로 저장하기

메시지에 **저장 이모지**(바꾸지 않았다면 🔖)로 반응하면 플러그인이 그 메시지를 노트로 저장해요. 팔로우한
채널이나 봇과의 DM에서, 나 또는 허용된 사용자가 단 반응일 때만 저장해요. 노트는 여기에 생겨요.

```text
inbox/discord/<channel>/<date>-<first line>
```

날짜는 메시지를 쓴 날이고, 이름은 첫 줄에서 따와요. DM은 `inbox/discord/dm/` 아래로 가요. 피드에
**Discord에서 저장했어요** 항목이 생겨요(푸시 알림은 없어요).

저장된 노트는 이렇게 생겼어요.

```markdown
---
source: discord
discord: 1029384756/1122334455/1234567890
channel: "#general"
link: https://discord.com/channels/1029384756/1122334455/1234567890
saved: 2026-11-07
tags: [discord]
---
# Shall we ship the beta on Friday?

<!-- aide:slot discord.message -->
**Mina** · 2026-11-07 14:05
> Shall we ship the beta on Friday?
> 📎 [notes.pdf](https://cdn.discordapp.com/…)
<!-- /aide:slot discord.message -->
```

메시지는 작성자와 시간, 인용한 본문이에요. 멘션은 이름으로, 첨부 파일은 링크로 바뀌어요. 메시지는 한 번만
저장해요. 다시 반응을 달거나 다른 사람이 반응을 달아도 다시 저장하지 않아서, 노트에 쓴 내용은 그대로 남아요.

플러그인은 저장을 끝내기 전에 먼저 보관해 두기 때문에 다시 시작해도 잃어버리지 않아요. Discord가 속도를 늦추라고
하면 Discord가 말한 만큼 기다려요. 다른 실패는 1분마다 최대 6번 다시 시도하고, 사라진 메시지나 봇이 읽을 수
없는 메시지는 다시 시도하지 않아요. 끝내 저장하지 못하면 피드에 이유와 함께 **Discord 메시지를 저장하지
못했어요** 항목이 생겨요.

### 연결이 끊긴 뒤

플러그인은 Discord와 연결을 유지하고, 다시 연결되면 끊긴 곳부터 이어 가요. Discord가 연결을 이어 가지 못하면
팔로우한 채널마다 마지막으로 본 메시지 다음부터 최근 100개까지 다시 읽어요. Discord가 답하지 않았거나 메시지가
100개보다 많이 올라와서 다 읽지 못하면, 피드에 채널 이름과 함께 **일부 Discord 메시지를 다시 읽지 못했어요**
항목이 생겨요. 연결이 끊긴 동안 달린 반응은 보지 못하기 때문에, 그때 단 🔖로는 저장되지 않아요. 다시 반응을
다세요.

## 시작하기 전에

- **서버 플러그인을 실행하는 데스크톱 호스트나 서버.** 플러그인은 실행 중인 컴퓨터에서 Discord로 연결을 열어
  두고, 그 컴퓨터가 깨어 있고 호스트가 실행 중일 때만 메시지를 봐요([데스크톱에서
  호스팅하기](/ko/docs/self-hosting/desktop-host/)).
- **봇을 초대할 수 있는 Discord 서버.**

플러그인이 Discord로 나가는 연결을 만들기 때문에 인터넷에서 내 컴퓨터로 들어올 필요가 없어요. Discord를 내가
아니라 봇으로서 읽어서, 봇이 들어갈 수 있는 채널만 보고 그 밖은 보지 않아요.

## 설정하기

봇이 있는 내 Discord 애플리케이션을 직접 만들고, 플러그인에 봇 토큰을 넣어요.

<Steps>

1. AIDE에서 **설정**을 열고 **코어 플러그인** 아래의 **Discord**를 선택해요(Linux에서는 설정의 **코어 플러그인**
   페이지에 있는 **Discord** 행). 설정 아래 상태에 **봇 토큰을 넣어 주세요**라고 나와요.
2. **봇 토큰** 옆의 **Discord 개발자 포털**을 선택하고 새 애플리케이션을 만들어요.
3. 애플리케이션의 **Bot** 페이지에서 **Reset Token**을 선택하고 토큰을 복사해요. 같은 페이지에서 **Message
   Content Intent**를 켜요.
4. AIDE에서 **봇 토큰**에 토큰을 붙여 넣고 **저장**을 선택해요.
5. 개발자 포털에서 **OAuth2 › URL Generator**를 열고 scope `bot`과 권한 **View Channels**, **Read Message
   History**를 골라요. 만들어진 URL을 열어 봇을 내 서버에 추가해요.
6. Discord에서 **개발자 모드**를 켜요(**설정 › 고급**). 채널을 오른쪽 클릭해 **채널 ID 복사**를 고르고 **팔로우할
   채널**에 넣어요. 내 사용자 ID도 같은 방법으로 복사해 **내 사용자 ID**에, 다른 사람의 ID는 **허용할
   사용자**에 넣어요.
7. **활성화됨**을 켜요. 1분 안에 상태가 **&lt;봇&gt;(으)로 연결됐어요**로 바뀌어요.
8. 팔로우한 채널의 메시지에 🔖 반응을 달아요.

</Steps>

토큰은 비밀 설정이에요. AIDE가 서버에서 봉인하고, Discord 플러그인만 읽을 수 있으며, 앱은 다시 보여 주지
않아요. 저장된 토큰은 **AIDE에 저장됨**으로 보이고 **바꾸기**와 **제거**가 있어요.

- **팔로우할 채널**, **허용할 사용자**, **내 사용자 ID**에는 긴 숫자로 된 Discord ID를 넣어요. `<@123…>`이나
  `<#123…>`처럼 멘션을 붙여 넣어도 돼요. 그 밖의 값이 있으면 고칠 때까지 플러그인이 **Discord ID가 아니에요:
  …**라고 하고 멈춰요.
- **내 사용자 ID**는 **허용할 사용자**에 있는 사람처럼 허용되고, 나를 멘션한 메시지는 봇 멘션처럼 피드에 와요.
- **저장 이모지**: 커스텀 이모지는 콜론 없이 이름으로 적어요(예: `save`). 비우면 🔖로 돌아가요.
- **저장할 폴더**: 안에 채널마다 채널 이름으로 된 폴더가 생겨요. DM은 `dm`으로 가요. 비우면 `inbox/discord`로
  돌아가요.

## 상태

플러그인 설정 아래 줄에 플러그인 상태가 나와요.

| 상태                                                          | 뜻                                                                                  |
| ------------------------------------------------------------- | ----------------------------------------------------------------------------------- |
| **…(으)로 연결됐어요**                                        | 그 봇으로 Discord에 연결됐어요.                                                     |
| **봇 토큰을 넣어 주세요**                                     | 저장된 토큰이 없어요. 토큰이 저장될 때까지 기다려요.                                |
| **Discord ID가 아니에요: …**                                  | 채널이나 사용자 설정에 ID가 아닌 값이 있어요. 바꿀 때까지 기다려요.                  |
| **Discord에 다시 연결하는 중…**                               | 연결이 끊겼고, 플러그인이 알아서 다시 연결하고 있어요.                              |
| **Discord가 봇 토큰을 거부했어요**                            | 토큰이 틀렸거나 다시 발급됐어요. 바꿀 때까지 기다려요.                              |
| **봇의 Message Content Intent를 켜 주세요(개발자 포털 › Bot)** | 이게 없으면 Discord가 연결을 받지 않아요. 설정이 바뀔 때까지 기다려요.              |
| **Discord가 연결을 끊었어요: …**                              | Discord가 다른 이유로 연결을 거부했고, 코드가 함께 나와요. 설정이 바뀔 때까지 기다려요. |

## 문제 해결

### Discord가 봇 토큰을 거부했어요

토큰을 잘못 붙여 넣었거나, 그 뒤에 개발자 포털에서 토큰을 다시 발급했어요. **Bot** 페이지에서 **Reset Token**을
다시 선택하고 새 토큰을 **바꾸기**로 저장하세요.

### Message Content Intent를 켜 주세요

개발자 포털에서 애플리케이션의 **Bot** 페이지를 열고 **Message Content Intent**를 켠 뒤 저장하세요. 그다음 AIDE에서
아무 설정이나 바꾸거나 플러그인을 껐다 켜면 다시 연결해요.

### 채널의 메시지가 피드에 오지 않아요

- **팔로우할 채널**에 채널 이름이 아니라 ID가 들어 있는지 확인하세요.
- 봇이 그 채널을 볼 수 있어야 해요. 그 채널에서 **View Channels**와 **Read Message History** 권한이 필요하고,
  비공개 채널은 봇에게 이 권한을 주지 않을 수 있어요.
- 멘션은 팔로우 여부와 상관없이 봇이 읽는 모든 채널에서 와요.

### 🔖 반응을 달았는데 저장되지 않았어요

- 나(**내 사용자 ID**)와 **허용할 사용자**에 있는 사람만 저장할 수 있어요.
- 메시지가 팔로우한 채널이나 봇과의 DM에 있어야 해요.
- 플러그인 연결이 끊긴 동안 단 반응은 보지 못해요. 반응을 지우고 다시 다세요.
- 메시지는 한 번만 저장해요. 노트를 지웠다면 다시 반응을 달아도 두 번째로 저장하지 않아요.

### Discord 메시지를 저장하지 못했어요

뒤에 이유가 붙어요. Discord가 메시지가 사라졌거나 봇이 읽을 수 없다고 답했거나, 6번 연달아 실패했어요. 봇이 그
채널에 접근할 수 있는지 확인하세요.

## 제한

- 봇은 읽기만 해요. Discord에 메시지를 보내거나 답하지 않아요.

## 개인정보

- 플러그인은 내 컴퓨터에서 Discord로 연결해요. 안으로 들어오는 연결은 없어요.
- 내가 초대한 서버에서 봇이 볼 수 있는 것만 읽어요.
- 피드 항목에는 메시지 본문, 작성자, 메시지 링크가 담겨요. 저장한 메시지는 노트가 되어 다른 노트처럼 저장되고
  동기화돼요. AI로 가는 것은 없어요.
- 토큰은 서버에서 봉인되고, 이 플러그인만 읽을 수 있으며, 앱에 표시되지 않아요.
