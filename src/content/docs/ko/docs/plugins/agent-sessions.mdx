에이전트 세션은 코딩 에이전트와 함께 알아낸 것을 노트로 만들어요.
Claude Code, Codex, Grok이 이 컴퓨터에 남긴 세션을 최신순으로 보여 주고, 고른 세션으로 무엇을 만들지
말하면("lifetime에 대해 배운 것, 예시 포함") AIDE의 어시스턴트가 노트를 쓰고, 저장하기 전에 확인할 수
있어요.

<PluginFacts id="agent-sessions" kind="device" />

## 하는 일

- **에이전트 세션 패널**: 데스크톱 오른쪽 패널(Mac, Linux)에서 `~/.claude/projects`,
  `~/.codex/sessions`, `~/.grok/sessions`의 세션을 최신순으로, 에이전트·프로젝트·마지막 사용 시간과
  함께 보여 줘요. 프로그램이 실행한 것(`claude -p`, `codex exec`)은 나오지 않아요. **모든 에이전트**에서
  한 에이전트만 고를 수 있고, **새로고침**은 다시 읽어요.
- **`/session`**: 빠른 메모(<kbd>⌥</kbd><kbd>Space</kbd>)와 Scratch 입력란에서 `/session lifetime에 대해
  배운 것`이라고 쓰면 그 내용을 지시로 해서 패널이 열려요. 세션만 고르면 돼요. 앱 명령과 함께 `/` 목록에
  나와요.
- 명령 팔레트의 **에이전트 세션에서 가져오기**도 패널을 열어요.

세션을 고르면 무엇을 요청할지 보여 줘요. **무엇을 만들까요**(`/session`에 쓴 내용, 없으면 기본 지시)와
노트가 들어갈 **폴더**예요. **노트 만들기**는 세션에서 내가 쓴 것과 에이전트의 답을 읽고(도구 실행과
그 출력은 빼요. 긴 세션은 첫 질문과 최근 대화를 남기고, 몇 개를 뺐는지 알려 줘요) 어시스턴트에게 노트를
부탁해요. 노트는 제목과 Markdown으로 보여서 고칠 수 있고, **저장**하면 속성에 `source: "claude:<세션>"`을
담아 쓰고, **열기**로 열어요. **다시 요청**은 한 번 더 부탁하고, **버리기**는 지워요. **저장** 전에는
아무것도 쓰지 않고, 패널을 숨겨도 고치던 내용은 남아요.

## 설정

<Steps>

1. 이 컴퓨터에서 [어시스턴트](/ko/docs/guides/assistant/)가 동작하는지 확인하세요(**설정 › 어시스턴트**,
   **테스트**). 노트를 쓰는 건 어시스턴트예요.
2. **커뮤니티 플러그인 둘러보기**를 열고 **에이전트 세션**을 고르세요.
3. 접근을 허용하세요. 이 컴퓨터의 에이전트 세션 읽기, 이 기기의 어시스턴트에게 묻기, 노트 바꾸기(말한
   곳에 노트를 써요), 자체 데이터 보관이에요. 그다음 **설치**.
4. 빠른 메모나 Scratch에 `/session`과 원하는 내용을 쓰거나, 오른쪽 패널에서 **에이전트 세션**을 여세요.

</Steps>

**설정 › 커뮤니티 플러그인 › 에이전트 세션**에서 기본 **새 노트 폴더**(`topics`)와 **세션으로 만들 것**을
정해요.

<Aside>
세션은 Mac이나 Linux 컴퓨터에서 읽어요. iPhone에는 세션이 없고, App Store판 Mac AIDE는 다른 앱의 폴더를
읽을 수 없어요. 그곳에서는 `/session`이 그렇게 알려 줘요.
</Aside>

## 개인 정보

플러그인은 에이전트가 세션을 둔 곳에서 읽기만 하고 바꾸지 않아요. 고른 세션(내가 쓴 것과 에이전트의 답,
최대 200KB)은 **설정 › 어시스턴트**에 정한 어시스턴트(다른 모든 일에 쓰는 Claude Code, Codex, Anthropic
API 또는 서버, 도구는 끈 채)로만 가요. 플러그인 스스로는 네트워크 요청을 하지 않아요.
