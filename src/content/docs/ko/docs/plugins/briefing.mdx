아침 브리핑은 오늘 하루가 어떤 모습일지 모아서, AI가 짧은 한 페이지로 정리해 줘요. 일어나면 이미 준비돼 있어요.

<PluginFacts id="briefing" />

## 하는 일

07:00(또는 정한 시간)이 되면 플러그인은 다음을 해요.

1. 오늘 데일리 노트가 없으면 만들어요. 그래서 새 데일리 노트를 채우는 플러그인, 예를 들어 [할 일 이월](/ko/docs/plugins/todo-carry/)과 [Google 캘린더](/ko/docs/plugins/gcal/)의 일정이 확인할 때쯤 이미 실행돼 있어요.
2. 오늘의 자료를 모아요.
    - **날씨**: 기상청의 동네 예보, 또는 직접 지정한 예보 URL.
    - **일정**: Google 캘린더의 오늘 일정과 이후 이틀의 일정.
    - **미완료 할 일**: AI가 고를 수 있도록 최상위 미완료 할 일.
    - **어제**: 어제의 데일리 노트.
    - **건강**: 건강 데이터 내보내기 폴더를 지정했다면 그중 가장 최근 파일 세 개.
3. AI에 그 자료만으로 브리핑을 쓰게 해요. 날씨(오전과 오후, 최저와 최고 기온, 강수 확률, 옷차림), 오늘 일정의 자세한 내용과 이후 이틀 미리 보기, 오늘 현실적으로 할 수 있는 할 일 최대 세 개(각각 "[노트] 할 일" 형태로, 부담이 아닌 제안으로), 어제의 걸음 수·수면·운동과 사흘간의 추세, 어제 눈에 띈 일과 해결되지 않은 일, 그리고 하루를 여는 다정한 한 줄이에요. 자료가 없는 항목은 빼요.
4. 하루 노트 `briefings/{date}`(예: `briefings/2026-10-22`, 제목 "2026-10-22 (목) 브리핑")의 자기 섹션에 `## ☀️ 아침 브리핑` 아래로 써요. 같은 날 다시 실행하면 그 섹션만 바꿔요.
5. 피드에 브리핑 내용과 함께 "☀️ 오늘의 브리핑"을 올리고 알림을 보내요.

읽을 수 없는 자료는 건너뛰어요. 날씨 설정이 없으면 날씨 문단이 없고, Google 파일이 없으면 일정이 없어요. AI 요청이 실패하면 성공하거나 다음 날 아침이 될 때까지 10분마다 다시 시도해요. 컴퓨터가 꺼져 있거나 잠자기 중이어서 놓친 아침은 3시간 안에 깨어나면 다시 실행해요.

## 시작하기 전에

- [데스크톱 호스트](/ko/docs/self-hosting/desktop-host/)나 직접 운영하는 서버가 필요해요.
- **설정 › AI**에 AI(**Anthropic API 키** 또는 **내 게이트웨이**)가 필요해요. 브리핑은 AI 없이는 만들 수 없어요.
- 선택 사항, 일정용: [Google 캘린더](/ko/docs/plugins/gcal/#시작하기-전에) 플러그인과 같은 Google 파일. 브리핑이 직접 읽기 때문에 Google 캘린더 플러그인을 켜지 않아도 돼요.
- 선택 사항, 날씨용: 한국의 동네(기상청은 한국만 다뤄요), 또는 그 밖의 지역이라면 예보 URL.

## 설정하기

<Steps>

1. 날씨나 건강 데이터를 쓰려면 호스트 데이터 폴더의 `plugins.json`([폴더 위치](/ko/docs/plugins/overview/#로컬-설정))에 추가하고 호스트를 다시 시작해요. [로컬 키](#로컬-키)를 참고하세요.
2. 플러그인을 켜요. 설정의 **서버에 저장** 아래에서 **아침 브리핑**을 고르고 **활성화됨**을 켜요(Linux에서는 **설정 › 플러그인**에서 해당 행의 스위치). [플러그인 켜기](/ko/docs/plugins/overview/#플러그인-켜기)를 참고하세요.
3. 07:00이 맞지 않으면 **시간**을 바꿔요.
4. 데일리 노트에서 브리핑을 읽으려면 데일리 템플릿에 하루 노트 링크를 넣거나, **쓸 노트**를 `daily`로 정해요.

</Steps>

## 설정

<PluginSettings id="briefing" defaults={{ at: "07:00", push: "force (항상 알림)", note: "briefings/{date}", prompt: "" }} />

**알림.** 따로 고르기 전까지는 선택 목록에 **자동**이 보여도 `force`처럼 매일 아침 알림을 보내요. 피드에서만 읽으려면 `never`(**알림 안 함**)를 골라요. **자동**을 직접 고르면 피드의 분류가 알림을 보낼지 정해요.

**쓸 노트.** `daily`로 정하면 오늘 데일리 노트의 끝에 있는 자기 섹션(또는 템플릿에서 `{{slot briefing.morning}}`을 둔 곳)에 브리핑을 써요. 그 밖의 값은 노트 경로이고, `{date}`는 `YYYY-MM-DD` 형식의 날짜로 바뀌어요.

**프롬프트.** 직접 쓴 지침이 기본 지침을 완전히 대신해요. 플러그인은 그 뒤에 날짜와 모은 자료를 모두 붙이니까, 자료로 무엇을 할지 적어 주세요. 예를 들면 "글머리표 세 개: 날씨, 첫 회의, 할 일 하나."처럼요.

### 로컬 키

`plugins.json`의 `"briefing"` 아래에 적어요.

| 키            | 하는 일                                                                                                             |
| ------------- | ------------------------------------------------------------------------------------------------------------------- |
| `weather`     | 기상청 예보 위치: `code`는 동네(동)의 10자리 행정 코드, `lat`과 `lon`은 그 좌표예요. 한국만 지원해요.               |
| `weatherUrl`  | `weather` 대신 쓰는, 예보를 텍스트나 JSON으로 돌려주는 URL. 플러그인은 응답의 처음 6 KiB를 그대로 AI에 넘겨요.      |
| `healthDir`   | 건강 데이터 내보내기(걸음 수, 수면, 운동) 폴더. 하루에 파일 하나이고 파일 이름에 날짜가 들어가요. 이름순으로 가장 최근 파일 세 개를 써요. |
| `credentials` | Google OAuth 클라이언트 파일. 기본값 `~/.config/life-assistant/credentials.json`.                                   |
| `tokenFile`   | Google 토큰 파일. 기본값 `~/.config/life-assistant/google-token.json`.                                              |

```json
{
    "timezone": "Asia/Seoul",
    "plugins": {
        "briefing": {
            "weather": { "code": "1111056000", "lat": "37.613", "lon": "126.9623" },
            "healthDir": "~/Health/daily"
        }
    }
}
```

위의 위치는 서울 종로구의 한 동네예요. 기상청 예보는 API 키 없이 읽어요.

<Aside>
일정은 AIDE의 **캘린더…** 시트에 있는 **표시** 스위치가 아니라, Google 캘린더 자체 목록에서 체크한 캘린더에서 가져와요.
</Aside>

## 문제 해결

### 브리핑이 오지 않았어요

- 플러그인이 켜져 있는지, **설정 › AI**가 <strong>규칙(AI 미사용)</strong>이 아닌지 확인하세요.
- 브리핑 시간에 호스트가 실행 중이거나, 그 뒤 3시간 안에 깨어나야 해요. 아침 내내 잠자기 상태였던 Mac은 그날 브리핑을 건너뛰어요.
- 호스트 로그(경로는 설정 › 호스트의 **로그**에 있어요)에서 `daily task failed`와 그 뒤의 이유를 찾아보세요.

### 날씨 문단이 없거나 예보를 가져오지 못했다고 나와요

`weather`나 `weatherUrl`이 없으면 날씨도 없어요. 기상청 페이지가 응답하지 않으면 AI에 조회가 실패했다고 알리고, AI는 날씨를 빼요. `code`, `lat`, `lon`을 확인하세요.

### 일정이 없어요

플러그인이 Google 파일을 읽지 못했어요. 호스트 로그에 `calendar unavailable; briefing without it`과 이유가 나와요.

### 다른 언어로 쓰여 있어요

플러그인은 **설정 › 언어**의 언어로 써요(한국어, 그 밖에는 영어). 오늘 쓴 브리핑은 그 언어로 남고, 내일 브리핑부터 바뀐 언어를 따라요.

## 개인정보

날씨 요청은 플러그인을 실행하는 컴퓨터에서 기상청 웹사이트(또는 `weatherUrl`)로 가고, 위치만 담겨요. Google은 캘린더 읽기 전용 권한으로 읽어요. 모은 자료(예보, 사흘치 일정, 미완료 할 일, 어제의 데일리 노트, 가장 최근 건강 파일 세 개)는 항목마다 6 KiB로 잘라서 **설정 › AI**에서 정한 AI로 보내요. 브리핑은 호스트나 서버에 노트로 저장돼요.
