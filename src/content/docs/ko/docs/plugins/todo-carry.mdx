할 일 이월은 마지막 데일리 노트에서 끝내지 못한 할 일을 새 데일리 노트로 옮겨 줘요. 어제 페이지에 두고 온 일이 없게요.

<PluginFacts id="todo-carry" />

## 하는 일

AIDE가 `todo-carry.open` 슬롯이 있는 데일리 노트를 만들면 플러그인은 다음을 해요.

1. 그보다 앞선 가장 최근 데일리 노트를 찾아요(어제의 노트, 또는 데일리 노트가 있는 마지막 날).
2. 그 노트에서 최상위 미완료 할 일을 가져와요. `- [ ] `로 시작하고 들여쓰지 않은 줄이에요. 완료, 취소, 진행 중인 할 일과 하위 할 일은 그대로 둬요.
3. 각 할 일을 새 노트의 이월 섹션에 `- [ ] <text>`로 추가해요. 이미 있는 할 일은 두 번 추가하지 않고, 섹션에 직접 쓴 내용은 그대로 남아요.
4. 옛 노트에서 이월한 할 일에 **미완료 할 일 이월** 설정대로 표시해요.

| 설정                            | 옛 줄은 이렇게 바뀌어요 |
| ------------------------------- | ---------------------- |
| **이동 후 원본에 [>] 표시**     | `- [>] Call the bank`  |
| **이동 후 취소선 표시(이월)**   | `- [x] ~~Call the bank~~ (이월)` |
| **끔**                          | 아무것도 이월하지 않아요 |

옛 줄은 할 일이 새 노트에 들어간 뒤에만 표시돼요. 그래서 두 노트 사이에서 할 일이 사라지는 일이 없어요. 플러그인이 중간에 멈추면 다시 시작할 때 마저 옮겨요.

오늘이나 내일 데일리 노트로만 이월해요. 옛 데일리 노트나 한참 뒤의 데일리 노트를 열어도 할 일을 가져오지 않아요.

그사이 [어시스턴트](/ko/docs/guides/assistant/)가 옛 노트에서 할 일을 옮겼다면, 플러그인은 그 할 일을 또 이월하지 않고 이미 만든 사본도 거둬들여요.

## 시작하기 전에

- [데스크톱 호스트](/ko/docs/self-hosting/desktop-host/)나 직접 운영하는 서버가 필요해요. 로컬 모드로 한 기기에서만 쓴다면 이 플러그인이 필요 없어요. 새 데일리 노트를 열 때 앱이 직접 할 일을 이월해요.
- 슬롯이 있는 데일리 템플릿이 필요해요. `{{slot todo-carry.open}}`이 들어 있는 템플릿으로 만든 데일리 노트에서만 이월해요.

## 설정하기

<Steps>

1. 이월한 할 일이 들어갈 자리에 데일리 템플릿의 슬롯을 추가해요([데일리 노트와 템플릿](/ko/docs/guides/periodic-notes/) 참고).

    ```markdown
    ## Todo
    {{slot todo-carry.open}}
    ```

2. **설정 › 할 일**을 열고 **미완료 할 일 이월**을 **이동 후 원본에 [>] 표시**나 <strong>이동 후 취소선 표시(이월)</strong>로 정해요. 고르기 전까지는 **끔**이에요.
3. 플러그인을 켜요. **설정 › 코어 플러그인**에서 **할 일 이월**을 고르고 **활성화됨**을 켜요(Linux에서는 설정의 **코어 플러그인** 페이지에서 해당 행의 스위치). [플러그인 켜기](/ko/docs/plugins/overview/#플러그인-켜기)를 참고하세요.
4. 다음에 템플릿으로 데일리 노트가 만들어질 때(오늘을 열 때, 또는 07:00에 아침 브리핑이 만들 때) 미완료 할 일이 들어와요.

</Steps>

## 설정

이 플러그인에는 자체 설정이 없어요. 읽는 설정은 위에서 설명한 **설정 › 할 일**의 **미완료 할 일 이월** 하나예요.

## 문제 해결

### 오늘 데일리 노트에 어제 할 일이 없어요

- **미완료 할 일 이월**이 **끔**이 아닌지 확인하세요.
- 오늘 데일리 노트에 슬롯이 있는지 확인하세요. 템플릿에 `{{slot todo-carry.open}}`을 추가하기 전에 만든 데일리 노트에는 슬롯이 없어요. 플러그인은 데일리 노트가 만들어질 때만 작동해요.
- 할 일은 최상위이고 미완료여야 해요. 줄 맨 앞이 `- [ ] text`여야 해요. 들여쓴 할 일은 옛 노트에 남아요.
- 데일리 노트가 만들어질 때 플러그인이 켜져 있어야 해요. 노트가 만들어지는 순간에 반응하기 때문에, 나중에 켜도 이미 있는 데일리 노트는 채우지 않아요.

### 몇 주 뒤의 데일리 노트에 할 일이 나타났어요

그럴 수 없어요. 플러그인은 오늘과 내일 데일리 노트로만 이월해요.

## 개인정보

할 일 이월은 호스트나 서버의 데일리 노트만 읽고 써요. AI를 쓰지 않고, 어디로도 아무것도 보내지 않아요.
