아이젠하워 매트릭스는 열린 할 일을 얼마나 중요하고 얼마나 급한지에 따라 네 칸에 나눠 보여 줘요. 무엇부터
할지 한눈에 알 수 있어요.

<PluginFacts id="eisenhower" kind="device" />

## 하는 일

**매트릭스** 탭이 생기고, 그 안에 네 칸이 있어요.

| 칸              | 담기는 할 일        |
| --------------- | ------------------- |
| **지금 하기**   | 긴급 · 중요         |
| **일정 잡기**   | 중요하지만 급하지 않음 |
| **위임하기**    | 급하지만 중요하지 않음 |
| **나중에**      | 둘 다 아님          |

- **중요**는 할 일의 우선순위가 높음이나 가장 높음이라는 뜻이에요(`⏫`, `🔺` 또는 `[priority:: high]`).
- **긴급**은 마감일이나 예정일이 이틀 안이거나 이미 지났다는 뜻이에요(`📅 2026-10-22`, `⏳ …`).

할 일마다 날짜가 함께 보여요. 앞의 버튼을 누르면 완료 처리돼요. 노트에서는 그 할 일 줄만 완료로 바뀌고 나머지는
그대로예요. 탭으로 돌아올 때마다 매트릭스를 다시 불러와요. 우선순위와 날짜를 쓰는 방법은
[할 일](/ko/docs/guides/todos/)에 있어요.

## 설정하기

<Steps>

1. **플러그인 둘러보기**를 열고(**설정**의 **이 기기에 저장** 아래, Linux에서는 **설정 › 기기 플러그인**)
   **아이젠하워 매트릭스**를 선택해요.
2. **모든 노트에서 미완료 및 완료된 할 일 읽기**와 **모든 노트에서 할 일 완료 및 추가**를 허용하고 **설치**를
   선택해요.
3. **매트릭스** 탭을 열어요. 플러그인은 그대로 두고 탭만 숨기려면 플러그인 설정에서 **탭으로 표시**를 꺼요.

</Steps>

설정은 없어요. 설치, 업데이트, 제거는 [기기 플러그인 설치하기](/ko/docs/plugins/device-plugins/)에 자세히
나와 있어요.

## 개인정보

플러그인은 할 일(텍스트와 필드만, 노트의 나머지는 아니에요)을 읽고, 완료 처리한 할 일 줄만 바꿔요. 네트워크
요청을 하지 않고 자체 데이터도 보관하지 않아요.
