생활 혜택은 내 상황에 맞는 정부 지원, 세액공제, 주거 지원 제도를 살펴보고, 챙길 만한 것을 일주일에 한 번 알려 줘요. 한국 생활에 맞춰 만들어져서, 혜택 목록과 뉴스 출처가 모두 한국 것이에요.

<PluginFacts id="benefits" />

## 하는 일

매주 월요일 09:00에 플러그인은 다음을 해요.

1. **생활 프로필**을 읽어요. 내 상황을 적어 둔 노트(기본값 `profile/life`)의 frontmatter예요.
2. 내장된 한국 생애주기별 혜택 12가지와 맞춰 봐요. 네 묶음으로 나뉘어요.
    - **신혼부부**: 혼인 증여재산 공제.
    - **주거**: 신혼부부 전세자금대출(버팀목), 신혼부부 특별공급, 디딤돌 대출, 신생아 특별공급 / 특례대출.
    - **세금**: 연금저축과 IRP 세액공제, ISA 계좌, 연말정산 점검, 월세 세액공제.
    - **자녀**: 첫만남이용권, 부모급여와 아동수당, 자녀 세액공제 / 자녀장려금, 산모·신생아 건강관리 지원.

    혜택은 필요한 조건을 모두 만족할 때만 맞는 것으로 봐요(예: 7년 안에 결혼했고 **그리고** 전세로 사는 경우). 시기도 맞아야 해요. 특정 달에만 챙길 혜택도 있고, 결혼일로부터 몇 년 안에만 해당하는 혜택도 있어요. 한 번 알려 준 혜택은 45일 동안 다시 알리지 않아요.
3. 최근 뉴스를 읽어요. 기획재정부 보도자료와, 프로필에 맞춰 고른 Google 뉴스 검색이에요. 약혼했거나 결혼했다면 신혼부부 지원과 증여세 변경, 자녀가 있거나 계획 중이라면 출산 지원, 직장인이라면 연말정산 변경, 관심사(`current_focus`)에 사업이나 창업이 있다면 창업 지원 사업, 그리고 사는 지역의 지원을 검색해요. 최근 14일 안의 기사를 출처마다 최대 4개, 모두 합쳐 최대 15개까지 남기고, 같은 기사를 두 번 보여 주지 않아요.
4. AI에 나에게 해당하는 것을 골라 브리핑 하나로 쓰게 해요. 지금 할 일(신청 방법, 마감일, 예상 금액)과 알아볼 일이 들어가요. 출산, 혼인신고, 이직처럼 상황이 바뀌어야 의미가 생기는 소식은 대신 **지켜볼 것** 목록에 들어가요.
5. 이벤트 하나를 올려요. 제목은 "🎁 이번 주 생활 혜택"이고, 브리핑과 함께 **👀 지켜볼 것** 아래에 지켜볼 항목의 링크와 해당 시점이 들어가요.

알릴 만한 것이 없으면 그 주에는 이벤트가 없어요. 컴퓨터가 꺼져 있어서 놓친 주는 72시간 안에 다시 실행해요. 실패한 실행은 다음 월요일까지 10분마다 다시 시도해요.

<Aside type="caution" title="신청하기 전에 확인하세요">
혜택 목록의 금액, 조건, 마감일은 플러그인에 적어 둔 대략적인 값이고, AI는 이를 검증할 수 없어요. 브리핑은 이 값들을 목록상의 수치로 표시하고, 혜택이 "해당할 수 있다"고 말하며, 공식 페이지를 확인하라고 안내해요. 모든 수치를 확인이 필요한 단서로 보세요.
</Aside>

## 시작하기 전에

- [데스크톱 호스트](/ko/docs/self-hosting/desktop-host/)나 직접 운영하는 서버가 필요해요.
- **설정 › AI**에 AI(**Anthropic API 키** 또는 **내 게이트웨이**)가 필요해요.
- YAML frontmatter가 있는 생활 프로필 노트가 필요해요(아래 참고). 노트가 없으면 플러그인은 조용히 그 주를 건너뛰어요.

## 설정하기

<Steps>

1. `profile/life`에 노트를 만들고 frontmatter에 내 상황을 적어요.

    ```markdown
    ---
    marital_status: married
    marriage_date: 2025-05-17
    residence:
      region: 서울 강서구
      tenure: jeonse
    tax_filing: employee
    child_plan: planning
    interests: [재테크, 창업]
    current_focus: 사업 준비
    extra_tags: []
    ---

    Free-form notes about your situation. The scout reads only the frontmatter.
    ```

2. 플러그인을 켜요. 설정의 **서버에 저장** 아래에서 **생활 혜택**을 고르고 **활성화됨**을 켜요(Linux에서는 **설정 › 플러그인**에서 해당 행의 스위치). [플러그인 켜기](/ko/docs/plugins/overview/#플러그인-켜기)를 참고하세요.
3. 월요일 09:00까지 기다려요. 바로 해 보려면 [로컬 키](#로컬-키)의 `run-now`를 참고하세요.

</Steps>

### 프로필 항목

모든 항목은 선택 사항이에요. 해당하지 않는 것은 빼세요. 플러그인은 `household`(`size`, `members`), `age`, `occupation`도 받지만 아직 쓰지는 않아요.

| 항목             | 값                                                             | 바뀌는 것       |
| ---------------- | -------------------------------------------------------------- | --------------- |
| `marital_status` | `single`, `engaged`, `married`                                 | 신혼부부 혜택과 결혼 시기 혜택, 결혼 관련 뉴스 |
| `marriage_date`  | `YYYY-MM-DD`, 지난 날짜나 다가올 날짜                          | 결혼 7년 이내면 신혼부부로 봐요. 결혼 전후 몇 년에 묶인 혜택 |
| `residence`      | `region`(한국어로 쓰는 그대로, 예: `서울 강서구`)과 `tenure`: `owned`, `jeonse`, `wolse` | 주거와 월세 혜택, 지역 뉴스 |
| `tax_filing`     | `employee`, `freelancer`, `none`                               | `employee`면 연말정산 혜택과 뉴스를 켜요 |
| `child_plan`     | `none`, `planning`, `expecting`, `parenting`                   | 출산·육아 혜택과 뉴스 |
| `interests`, `current_focus` | 목록, 텍스트                                       | AI에 전달돼요. 사업이나 창업이 들어 있으면 창업 지원 사업 뉴스가 추가돼요 |
| `extra_tags`     | 목록의 태그: `married`, `engaged`, `newlywed`, `marriage-window`, `employee`, `child`, `jeonse`, `wolse`, `renter`, `home-owner` | 다른 항목으로 나타낼 수 없는 조건을 직접 추가해요 |

## 설정

<PluginSettings id="benefits" defaults={{ profileNote: "profile/life" }} />

**프로필 노트**는 노트 경로예요. 비워 두면 `profile/life`를 써요.

### 로컬 키

데스크톱 호스트의 `plugins.json`([폴더 위치](/ko/docs/plugins/overview/#로컬-설정))에서 `"benefits"` 아래에 적어요.

| 키        | 하는 일                                                                                            |
| --------- | -------------------------------------------------------------------------------------------------- |
| `sources` | 피드 목록 `{"name": "…", "url": "…"}`. 프로필에 맞춰 고른 뉴스 출처를 대신해요.                    |
| `run-now` | `true`면 월요일 일정과 별도로, 플러그인이 시작될 때 이번 주를 한 번 실행해요.                      |

```json
{
    "plugins": {
        "benefits": { "run-now": true }
    }
}
```

이미 끝난 주는 `run-now`가 있어도 두 번 실행하지 않아요. 브리핑을 한 번 확인했다면 `run-now`를 지우세요.

## 문제 해결

### 월요일에 브리핑이 오지 않았어요

- 맞는 혜택도, 알릴 만한 것도 없는 주에는 이벤트가 없어요. 대부분 이 경우예요.
- 프로필 노트가 없으면 그 주를 건너뛰어요. **프로필 노트**의 경로를 확인하세요.
- frontmatter 블록(맨 위의 `---` 줄)이 없는 프로필 노트는 읽을 수 없어요. 플러그인이 일주일 내내 10분마다 다시 시도하고, 호스트 로그에 `life profile has no YAML frontmatter`가 나와요.
- **설정 › AI**가 <strong>규칙(AI 미사용)</strong>이 아닌지 확인하세요.

### 브리핑의 링크를 누를 수 없어요

플러그인이 확인한 기사나 한국 정부 사이트(`gov.kr`, `go.kr`, `korea.kr`)를 가리키는 링크만 누를 수 있게 남겨요. 그 밖의 주소는 일반 코드로 보여 줘서, 지어내거나 심어 둔 링크를 실수로 열지 않게 해요.

## 개인정보

플러그인은 플러그인을 실행하는 컴퓨터에서 기획재정부 보도자료 피드와 Google 뉴스 검색을 가져와요. 사는 지역은 그중 한 검색에 텍스트로 들어가요. 결혼 여부와 결혼일, 지역과 거주 형태, 소득 신고 유형, 자녀 계획, 관심사와 현재 관심 분야, 맞는 혜택 항목, 확인한 기사의 제목과 요약이 **설정 › AI**에서 정한 AI로 전달돼요. 지켜볼 것 목록과, 이미 보여 준 혜택과 기사는 호스트나 서버에 플러그인 상태로 저장돼요.
