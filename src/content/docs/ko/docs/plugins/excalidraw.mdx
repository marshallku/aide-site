Excalidraw로 노트 안에서 바로 다이어그램을 그리고 나중에 다시 고칠 수 있어요. 그림은 보관소에 이미지로
저장되기 때문에 노트가 보이는 곳이면 어디서나 보여요.

<PluginFacts id="excalidraw" kind="device" />

## 하는 일

탭은 생기지 않아요. 대신 노트 편집기에 **그림** 시트가 생기고, 노트 속 그림에 **편집** 버튼이 붙어요.

- **새 그림.** 저장된 노트에서 편집기의 **플러그인** 메뉴(iPhone에서는 더 보기 메뉴 안)를 열고 **그림**을
  선택해요. 그린 다음 **저장**을 선택하면 그림이
  `drawings/drawing-<date>-<time>-<tag>.excalidraw.svg`로 저장되고, 노트 끝에 `![drawing](…)` 줄이 추가돼요.
- **그림 편집.** 노트 속 그림마다 편집기에서도, 읽을 때도 **편집** 버튼이 있어요. 마지막 모습 그대로 그림이
  열려요. **저장**하면 기존 파일 옆에 새 파일을 쓰고, 노트의 참조가 새 파일을 가리키게 바꿔요.
- **플러그인이 없어도** 그림은 평범한 SVG 이미지예요. 모든 기기의 AIDE, 다른 Markdown 앱, 브라우저에서 다
  보여요. Excalidraw 장면이 SVG 안에 들어 있어서 계속 편집할 수 있어요.

AIDE의 첨부 파일은 한 번 저장되면 바뀌지 않아요. 그래서 그림을 저장할 때마다 새 파일이 생기고, 이전 버전은
`drawings/`에 남아요.

그리는 동안 노트가 바뀌었다면 플러그인이 저장 전에 노트를 다시 읽어요. 그사이 노트에서 그림 참조가
지워졌다면 **노트에 이 그림이 더 이상 없어요**라고 알리고 아무것도 저장하지 않아요.

## 설정하기

<Aside>
Excalidraw는 아직 공개 플러그인 목록에 없어서 **커뮤니티 플러그인 둘러보기**에 나오지 않아요. 목록에 올라오면 아래처럼
거기서 설치하면 돼요.
</Aside>

<Steps>

1. **커뮤니티 플러그인 둘러보기**를 열고(**설정**의 **커뮤니티 플러그인** 아래, Linux에서는 설정의 **커뮤니티 플러그인** 페이지)
   **Excalidraw**를 선택해요.
2. **모든 노트 읽기, 변경 및 보관**(그림 참조를 추가하고 고치기 위해)과 **노트에 이미지와 문서 추가**(그림을
   저장하기 위해)를 허용하고 **설치**를 선택해요.
3. 노트를 열고 **플러그인** 메뉴에서 **그림**을 선택해요.

</Steps>

설정은 없어요. 설치, 업데이트, 제거는 [기기 플러그인 설치하기](/ko/docs/plugins/device-plugins/)에 자세히
나와 있어요.

## 제한

- 그림은 저장된 노트에서만 열려요. 새 노트라면 먼저 무언가를 입력하세요.
- 플러그인 안에서는 글꼴을 불러올 수 없어서, 그림 속 글자는 Excalidraw의 손글씨 글꼴 대신 시스템 글꼴로
  보여요.

## 개인정보

플러그인은 그림을 `drawings/`에 쓰고, 그림을 그린 노트의 그림 참조만 바꿔요. 네트워크 요청은 하지 않아요.
그림은 보관소의 첨부 파일이라 다른 파일처럼 동기화돼요.
