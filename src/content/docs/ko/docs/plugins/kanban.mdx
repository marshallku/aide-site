칸반은 노트를 보드로 보여 줘요. 레인이 나란히 있고, 그 안의 카드를 끌어서 옮겨요. 보드는 `boards/` 아래의
평범한 노트이고 Obsidian Kanban 플러그인과 같은 형식으로 쓰여서, 같은 보드를 두 앱에서 모두 열 수 있어요.

<PluginFacts id="kanban" kind="device" />

## 하는 일

**칸반** 탭이 생겨요. 탭에는 보드 목록(`boards/` 아래 노트)이 있고 새 보드를 만들 수 있어요. 새 보드에는
**To do**, **Doing**, **Done** 레인이 생겨요.

보드에서는 이렇게 할 수 있어요.

- 카드 추가: 레인 맨 아래 **카드 추가**에 입력하고 <kbd>Return</kbd>을 눌러요.
- 카드 옮기기: 마우스로, iPhone에서는 손가락으로 다른 자리나 레인에 끌어다 놓아요.
- 체크박스로 카드를 완료하거나 **×**로 지워요.
- 레인 추가: **레인 추가**에 이름을 입력하고 <kbd>Return</kbd>을 눌러요.

바꾼 내용은 바로 노트에 저장돼요. 그사이 다른 기기나 Obsidian에서 노트가 바뀌었다면 보드를 다시 읽어서 지금
노트의 내용을 보여 줘요.

## 노트 형식

보드는 이렇게 생겼어요.

```markdown
---

kanban-plugin: board

---

## To do

- [ ] Write the brief

## Done

- [x] Set up the repo
```

레인은 `##` 제목이고, 카드는 그 아래 목록 항목이에요. 완료한 카드는 `- [x]`예요. 카드 아래에 들여 쓴 줄은
그 카드에 속해서 함께 옮겨져요. 레인 안의 다른 내용과 끝에 있는 Obsidian의 `%% kanban:settings` 블록은
그대로 남아요.

## 설정하기

<Steps>

1. **플러그인 둘러보기**를 열고(**설정**의 **이 기기에 저장** 아래, Linux에서는 **설정 › 기기 플러그인**)
   **칸반**을 선택해요.
2. **boards의 노트 읽기, 변경 및 보관**을 허용하고 **설치**를 선택해요.
3. **칸반** 탭을 열고 첫 보드의 이름을 정해요.

</Steps>

설정은 없어요. 설치, 업데이트, 제거는 [기기 플러그인 설치하기](/ko/docs/plugins/device-plugins/)에 자세히
나와 있어요.

## 문제 해결

### Obsidian에서 만든 보드가 목록에 없어요

플러그인은 `boards/` 아래 노트만 읽을 수 있어요. 보드 파일을 보관소 맨 위의 `boards` 폴더로 옮겨요.

## 개인정보

플러그인은 `boards/` 아래 노트만 읽고 바꿔요. 네트워크 요청을 하지 않고 자체 데이터도 보관하지 않아요.
