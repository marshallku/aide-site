열린 이슈는 시작했지만 끝내지 못한 모든 일을 한 노트에 모아 둬요. 프로젝트, 볼일, 기다리고 있는 일 같은 것들이에요. 매일 저녁 AI가 그날의 데일리 노트를 읽고 목록을 갱신해 줘요.

<PluginFacts id="loops" />

## 하는 일

21:15(또는 정한 시간)가 되면 플러그인은 다음을 해요.

1. 열린 이슈 노트(기본값 `loops/open`)와 오늘 데일리 노트를 읽어요.
2. 닫히지 않은 항목과, 유일한 근거로 오늘 데일리 노트를 AI에 전달해요. AI는
    - 데일리 노트에 끝났다고 나오면 항목을 `closed`로 바꾸고,
    - 진행이 있었다면 다음 행동과 검토 날짜를 갱신하고,
    - 오늘 분명히 새로 시작한 일이 있으면 항목을 추가하고,
    - 나머지는 그대로 두며, 압박하는 말("N일째 방치")을 지어내지 않아요.
3. AI가 바꾸거나 추가한 항목만 받아서 노트 형식에 맞는지 확인하고, id를 기준으로 노트에 합쳐요. AI가 언급하지 않은 항목은 그대로 남아요. 그래서 노트가 길어도 한 번의 답에 다 담을 필요가 없고, 어떤 항목도 지워지지 않아요. 닫힌 항목도 자기 제목 아래에 남아요.
4. 노트가 바뀌었고, 그사이에 내가 노트를 고치지 않았을 때만 저장해요. 고쳤다면 노트를 다시 읽고 10분 뒤에 다시 시도해요. 그래서 내가 고친 내용을 덮어쓰지 않아요.

데일리 노트가 없거나 빈 날에는 목록을 그대로 둬요. 컴퓨터가 꺼져 있거나 잠자기 중이어서 놓친 저녁은 3시간 안에 깨어나면 다시 실행해요.

## 시작하기 전에

- [데스크톱 호스트](/ko/docs/self-hosting/desktop-host/)나 직접 운영하는 서버가 필요해요.
- **설정 › AI**에 AI(**Anthropic API 키** 또는 **내 게이트웨이**)가 필요해요.
- 열린 이슈 노트가 있어야 해요. 플러그인은 이 노트를 만들지 않아요. `loops/open`(또는 지정한 경로)에 노트가 생기기 전까지는 아무것도 하지 않아요.

## 설정하기

<Steps>

1. `loops/open`에 노트를 만들고 아래 형식으로 열린 이슈를 적어요. 제목 줄 하나(`# Open loops`)만 있어도 시작할 수 있어요. 데일리 노트에 새 일이 나오면 AI가 항목을 추가해요.
2. 플러그인을 켜요. 설정의 **서버에 저장** 아래에서 **열린 이슈**를 고르고 **활성화됨**을 켜요(Linux에서는 **설정 › 플러그인**에서 해당 행의 스위치). [플러그인 켜기](/ko/docs/plugins/overview/#플러그인-켜기)를 참고하세요.
3. 선택 사항: `plugins.json`에 `"recap": { "loopsNote": "loops/open" }`을 넣으면 [저녁 정리](/ko/docs/plugins/recap/)도 이 목록을 읽어요.

</Steps>

## 노트 형식

플러그인이 쓰기 전에 모든 답을 확인할 수 있도록 형식이 엄격해요.

```markdown
# Open loops

Anything above the first ## heading is yours and kept as it is.

## Home
- **Renew the passport** · in_progress · review 2026-11-01 · `passport`
  - Book the photo appointment
- **Fix the bathroom fan** · active · `bathroom-fan`
  - Ask the landlord which model it is

## Work
- **Quarterly report** · incubating · `q4-report`
- **Hire a designer** · closed · `hire-designer`
```

- `## ` 제목 하나가 영역 하나예요. 모든 항목은 영역 아래에 있어야 해요.
- 항목은 한 줄이에요: `- **제목** · 상태 · 백틱으로 감싼 id`. 검토 날짜를 두려면 id 앞에 ` · review YYYY-MM-DD`를 넣어요. 구분자는 공백, 가운뎃점(`·`), 공백이에요.
- 상태는 `active`, `in_progress`, `incubating`, `closed` 중 하나예요.
- id는 영문 소문자, 숫자, 하이픈으로 쓰고, 영문자나 숫자로 시작하며, 노트 안에서 겹치지 않아야 해요.
- 다음 행동은 항목 바로 아래 줄에 쓰고, 각 줄은 공백 두 칸과 `- `로 시작해요. 항목과 다음 행동 사이에 빈 줄을 두지 않아요.
- 제목에는 백틱, `**`, ` · `를 쓸 수 없어요.
- 항목과 영역 사이의 빈 줄은 괜찮아요.

<Aside>
가운뎃점은 마침표나 글머리표가 아닌 `·`(U+00B7) 문자예요. 키보드에 없으면 예시에서 복사하세요.
</Aside>

## 문제 해결

### 피드에 "⚠️ open loops 갱신 건너뜀" 이벤트가 있어요

그날 플러그인이 아무것도 쓰지 않았고, 이벤트에 이유가 나와요. 알림은 보내지 않아요. 이유는 다음과 같아요.

- **노트가 형식에 맞지 않아요**: 노트의 한 줄이 형식을 따르지 않아요. 이벤트에 줄 번호가 나오니 그 줄을 고치면 다음 날 저녁부터 다시 작동해요.
- **AI가 돌려준 변경이 형식에 맞지 않아요**: 답이 형식에 맞지 않았거나, 닫힌 항목의 id를 다시 쓰려고 했어요. 아무것도 바뀌지 않았고, 내일 다시 시도해요.
- **열린 이슈가 너무 길어요**: 닫히지 않은 항목이 AI 요청 한 번에 들어가지 않아요(지침을 합쳐 약 30 KB). 다음 행동을 줄이거나 끝난 항목을 닫아 주세요.
- **open loops를 쓰지 못했어요**: 합친 노트가 64 KiB를 넘어요.

### 노트가 바뀌지 않아요

AI는 오늘 데일리 노트에 근거가 있는 것만 바꿔요. 데일리 노트에 언급되지 않은 이슈는 그대로 두고, 데일리 노트가 없는 날도 마찬가지예요. **열린 이슈 노트**의 경로에 노트가 있는지도 확인하세요.

## 개인정보

오늘 데일리 노트(최대 8 KiB)와 열린 이슈 노트에서 닫히지 않은 항목이 **설정 › AI**에서 정한 AI로 전달돼요. 닫힌 항목은 보내지 않아요. 노트는 호스트나 서버에 남아요.
