플러그인은 AIDE가 대신 해 주는 일을 늘려 줘요. 아침 브리핑, Google 캘린더, 노트의 git 미러, 매주 찾아 주는 생활 혜택 같은 것들이에요. 어떤 플러그인은 AIDE 서버 옆에서 늘 실행되고, 어떤 플러그인은 한 기기의 앱 안에서 실행돼요.

## 두 종류의 플러그인

|                   | 서버 플러그인                                                                                      | 기기 플러그인                                                            |
| ----------------- | -------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| 실행 위치         | AIDE 서버나 데스크톱 호스트 옆. 앱이 열려 있든 아니든 실행돼요                                     | iPhone, Mac, Linux 컴퓨터 한 대의 AIDE 앱 안, 샌드박스에서 실행돼요       |
| 용도              | 예약 작업과 백그라운드 작업: 브리핑, 동기화, 알림, Google이나 Slack 읽기                           | 화면과 도구: 할 일 매트릭스, 그림 편집기, 타이머                          |
| 찾는 곳           | AIDE에 함께 들어 있어요. 열두 개 모두 설정에 있고, 켜기 전까지는 꺼져 있어요                        | 플러그인 인덱스나 URL에서 설치해요                                       |
| 접근 권한         | 플러그인마다 따로 받는 토큰. 각 플러그인 페이지에 나온 범위로 제한돼요                              | 설치할 때 승인한 권한                                                    |
| 서버 필요 여부    | 필요해요. [데스크톱 호스트](/ko/docs/self-hosting/desktop-host/)나 [직접 운영하는 서버](/ko/docs/self-hosting/own-server/) | 필요 없어요. 로컬 모드에서도 작동해요                |

이 페이지는 주로 서버 플러그인을 다뤄요. 기기 플러그인은 아래 [기기 플러그인 설치](#기기-플러그인)에서 설명해요.

## 서버 플러그인이 실행되는 곳

서버 플러그인은 서버 옆의 한 프로세스, 플러그인 러너 안에서 실행돼요. 각 플러그인은 그 안에서 따로 실행되고, 자기 토큰과 저장된 상태, 일정을 따로 가져요. 한 플러그인이 멈추면 러너가 30초 뒤에 다시 시작하고, 다른 플러그인은 계속 실행돼요.

- **데스크톱 호스트**(Mac이나 Linux)에서는 [보관소를 호스팅](/ko/docs/self-hosting/desktop-host/)할 때 호스트가 러너를 시작해 줘요. 러너는 모든 플러그인을 호스트에 등록하고, 각 플러그인은 켜기 전까지 꺼져 있어요. 호스트가 멈추면 러너도 멈춰요. 호스트는 AIDE가 열려 있는 동안에만 실행돼요. **로그인한 동안 계속 실행**을 켜면 예외예요.
- **직접 운영하는 서버**에서는 러너가 서버에 접근할 수 있는 컴퓨터에서 별도 서비스로 실행돼요. 각 플러그인의 토큰은 서버에서 받아요. [직접 서버 운영하기](/ko/docs/self-hosting/own-server/)를 참고하세요.

데스크톱 호스트에서는 호스팅하는 컴퓨터에서 플러그인을 켜고 설정해요. 호스트와 연결한 휴대폰에서는 플러그인을 볼 수만 있고 바꿀 수는 없어요. 직접 운영하는 서버라면 로그인한 어느 기기에서든 플러그인을 켜고 설정을 바꿀 수 있어요. 어느 쪽이든 플러그인은 휴대폰이 아니라 서버 곁에서 돌아가요.

로컬 모드(서버도 호스트도 없음)에서는 서버 플러그인이 아직 실행되지 않아요. Mac이나 Linux 컴퓨터에서 보관소를 호스팅하거나 서버에 연결하면 실행돼요. 로컬 모드에서도 **설정 › 코어 플러그인**(Linux에서는 **코어 플러그인** 페이지의 **서버 플러그인** 그룹)에 목록이 보이고, Mac과 Linux에서는 <strong>이 보관소 호스팅…</strong>도 함께 보여요.

### 컴퓨터가 잠자기 상태일 때

매일 실행되는 플러그인의 실행 시간이 잠자기 중에 지나갔다면, 플러그인의 따라잡기 시간 안에 깨어난 경우 깨어난 뒤 1분 안에 실행돼요. 따라잡기 시간은 브리핑, 정리, 열린 이슈가 3시간, 매주 실행되는 생활 혜택이 72시간이에요. 잠자기 중에 시간이 된 캘린더 알림은 건너뛰어요. 너무 늦게 도착해서 도움이 되지 않기 때문이에요.

## 플러그인 켜기

1. **설정**을 열어요. Mac과 iPhone에서는 서버 플러그인이 **코어 플러그인** 아래에 있고, 각각 **켬** 또는 **끔**으로 표시돼요. Linux에서는 **코어 플러그인** 페이지를 열면 **서버 플러그인** 그룹에 있어요.
2. 플러그인을 골라요. Mac과 iPhone에서는 **활성화됨**을 켜요. Linux에서는 플러그인 행의 스위치를 켜고, 행을 펼쳐 설정을 확인해요.
3. 1분 정도 기다려요. 러너가 매분 어떤 플러그인이 켜져 있는지 확인하고, 그에 맞춰 시작하거나 멈춰요.

플러그인을 끄면 1분 안에 멈춰요. 저장된 상태(이미 한 일, 어디까지 했는지)는 남아 있어서, 다시 켜면 이어서 진행해요.

## 설정

각 플러그인은 **활성화됨** 아래에 자기가 선언한 설정을 일반 컨트롤로 보여 줘요. 스위치, 선택 항목, 시간(`HH:MM`), 텍스트, 목록(쉼표로 구분)이 있어요. 바꾸는 즉시 저장돼요. 러너가 매분 변경 사항을 확인하고, 새 설정으로 플러그인을 다시 시작해요. 비워 둔 설정은 플러그인의 기본값을 써요. 기본값은 각 플러그인 페이지에 나와 있어요.

### 비밀 값

Slack의 토큰처럼 비밀 값을 받는 플러그인도 있어요. 값을 입력하고 **저장**을 누르면 돼요. 서버는 그 값을 자기 비밀 키로 봉인해 저장하고, 해당 플러그인만 읽을 수 있어요. 앱은 그 값을 다시 보여 주지 않아요. **AIDE에 저장됨**이라고만 표시하고, **바꾸기**와 **제거**를 보여 줘요. 입력을 도와주는 페이지 링크가 옆에 있는 항목도 있어요.

### 로컬 설정

파일 경로, 자격 증명, 원격 주소(`credentials`, `tokenFile`, `healthDir`, `remote`, `clone`, `stateDir`)는 앱에서 받지 않아요. 러너가 자기가 실행되는 컴퓨터의 로컬 파일에서 읽기 때문에, 서버나 앱을 거치지 않아요. 데스크톱 호스트에서는 호스트 데이터 폴더의 `plugins.json`이 그 파일이에요.

| 시스템 | 폴더                                                      |
| ------ | --------------------------------------------------------- |
| macOS  | `~/Library/Application Support/AIDE/hosts/<vault id>/`   |
| Linux  | `~/.local/share/aide/hosts/<vault id>/` (또는 `$XDG_DATA_HOME/aide/hosts/<vault id>/`) |

`<vault id>`는 보관소의 `.aide/vault.json`에 있는 `id`예요. `host.log`가 있는 폴더이기도 하고, 그 경로는 설정 › 호스트의 **로그** 행에 나와요.

이 파일에는 플러그인 일정에 쓸 시간대(선택 사항, 기본값은 컴퓨터의 시간대)와 플러그인별 블록이 들어가요. 블록의 키는 플러그인 id예요.

```json
{
    "timezone": "Asia/Seoul",
    "plugins": {
        "briefing": {
            "weather": { "code": "1111056000", "lat": "37.613", "lon": "126.9623" }
        },
        "docs-sync": {
            "remote": "git@github.com:you/notes.git"
        }
    }
}
```

호스트는 시작할 때 `plugins.json`을 읽어요. 파일을 만들거나 고친 뒤에는 AIDE를 종료했다가 다시 열어요. **로그인한 동안 계속 실행**이 켜져 있으면 종료해도 호스트가 멈추지 않아요. 이때는 그 설정을 껐다가 다시 켜면 호스트가 변경 사항을 반영해 다시 시작해요.

<Badge text="다음 릴리스" /> 다시 시작하지 않아도 돼요. 호스트가 `plugins.json`이 생기거나, 바뀌거나, 없어지는 것을 알아채고 그 내용으로 플러그인을 다시 시작해요. 바뀐 내용은 1분쯤 안에 반영돼요.

앱에서 정한 값이 `plugins.json`의 같은 키보다 우선해요. 각 플러그인 페이지에 그 플러그인이 읽는 로컬 키가 나와 있어요.

<Aside type="caution">
`plugins.json`에 실수가 있으면(쉼표 누락, 객체가 아닌 블록 등) 러너 전체가 멈춰서 어떤 플러그인도 실행되지 않아요. 호스트 로그에 파일 이름과 문제가 나와요.

<Badge text="다음 릴리스" /> 대신 읽을 수 없는 파일은 빼고 플러그인을 실행하고, 읽을 수 없는 플러그인 블록은 그 플러그인에서만 빼요. 호스트 로그에 `plugins config doesn't parse; plugins run without it` 또는 `a plugin's block in the plugins config doesn't parse; it runs without it`이 파일 이름, 문제와 함께 나와요.
</Aside>

### 상태 줄

플러그인은 자기 상태를 알릴 수 있어요. 설정 아래에 흐린 줄로 보이고, 문제가 있으면 빨간색으로 보여요. 예를 들어 Slack은 연결됐는지, Slack이 토큰을 거부했는지 보여 줘요. 화면을 보고 있는 동안 앱이 5초마다 다시 확인해요.

<Badge text="다음 릴리스" /> 상태 줄 아래에 버튼이 함께 나올 수도 있어요. 예를 들어 [Google 캘린더](/ko/docs/plugins/gcal/)와 [Gmail](/ko/docs/plugins/gmail/)은 **Google로 로그인**을 보여 주고, 누르면 브라우저에서 열려요.

## 플러그인이 쓰는 내용

플러그인은 여러분과 같은 방식으로 노트에 일반 Markdown을 쓰고, 여러분이 쓴 글은 건드리지 않아요.

### 슬롯

데일리 노트처럼 여러분의 노트에 쓰는 플러그인은 자기 섹션 안에만 써요. 섹션의 위치는 템플릿의 슬롯으로 정해요.

```markdown
## Todo
{{slot todo-carry.open}}

## Today
{{slot gcal.today}}
```

AIDE가 이 템플릿으로 노트를 만들면 각 슬롯은 두 마커 주석(`<!-- aide:slot gcal.today -->` … `<!-- /aide:slot gcal.today -->`) 사이의 빈 섹션이 돼요. 플러그인은 마커 사이의 내용만 바꾸고 나머지는 건드리지 않아요. 플러그인은 자기 이름이 붙은 섹션에만 쓸 수 있어요. 노트에 섹션이 없으면 플러그인이 노트 끝에 추가해요. 템플릿의 슬롯은 [데일리 노트와 템플릿](/ko/docs/guides/periodic-notes/)에서 설명해요.

### 하루 노트

하루에 관한 내용을 쓰는 플러그인(아침 브리핑, 저녁 정리, Google 캘린더의 준비 노트, Gmail)은 기본적으로 데일리 노트에 쓰지 않아요. 대신 별도의 하루 노트 `briefings/{date}`(예: `briefings/2026-10-22`)에 각자 자기 섹션으로 써서, 데일리 노트는 온전히 여러분의 것으로 남아요. 하루 노트는 플러그인이 처음 쓸 때 AIDE가 만들어요.

이 플러그인들에는 **쓸 노트** 설정(`note`)이 있어요. `{date}`가 들어간 노트 경로를 쓰거나, 데일리 노트에 직접 쓰려면 `daily`를 입력해요. 데일리 노트에서 하루 노트를 보려면 데일리 템플릿에 하루 노트 링크를 넣어 두세요.

### 피드와 알림

플러그인은 [피드](/ko/docs/guides/feed/)에 이벤트를 올려요. 브리핑이 작성됐을 때, 캘린더 알림, 동기화 충돌 같은 것들이에요. 서버는 각 이벤트를 **조치 필요**, **알아둘 내용**, **관심 있을 만한 내용**, **나머지**로 분류하고, 그에 따라 알림을 보낼지 정해요.

- **조치 필요**는 항상 알림을 보내요.
- **알아둘 내용**은 설정의 **“알아둘 내용”도 푸시 알림**이 켜져 있는 동안 알림을 보내요(기본으로 켜져 있어요).
- 나머지는 피드에서 기다려요.

플러그인은 이벤트마다 이 분류를 무시할 수 있어요. 이를 위한 **알림** 설정(`push`)이 있는 플러그인도 있어요.

| 값         | 동작                                           |
| ---------- | ---------------------------------------------- |
| `force`    | 분류와 상관없이 항상 알림을 보내요             |
| `never`    | 알림을 보내지 않고, 이벤트는 피드에서 기다려요 |
| 비워 둠(**자동**) | 분류에 따라 정해요                      |

1시간이 넘은 이벤트는 알림을 보내지 않아요.

### 언어

플러그인은 **설정 › 언어**에서 고른 언어로 써요. 한국어를 고르면 한국어로, 그 밖의 언어를 고르면 영어로 써요. 바꾼 언어는 5분 안에 플러그인이 다음에 쓰는 내용부터 적용돼요.

### AI

요약하거나 판단하는 플러그인(브리핑, 정리, 캘린더 준비, 열린 이슈, 생활 혜택)은 호스트나 서버의 **설정 › AI**에서 정한 AI에 요청해요. **Anthropic API 키** 또는 **내 게이트웨이**예요. <strong>규칙(AI 미사용)</strong>이면 AI 단계를 실행할 수 없어서 나중에 다시 시도해요. [AI와 모델](/ko/docs/guides/ai/)을 참고하세요.

### 프롬프트

<Badge text="다음 릴리스" /> AI에게 글을 쓰게 하는 플러그인(아침 브리핑, 저녁 정리, 열린 이슈, Slack의 스레드 요약, 지난 작업 정리, 생활 혜택)에는 **프롬프트** 설정이 있어요. AI가 따르는 지침이에요. 플러그인 자체의 지침이 플러그인이 쓰는 언어(**설정 › 언어 › 플러그인 작성 언어**)로 채워져 있어서, 무엇을 요청하는지 읽고 바꿀 수 있어요.

- **고치기**: 무엇을 다룰지, 어떤 말투로 얼마나 길게 쓸지 바꾸려면 내용을 고쳐요. 고치기 전에는 아무것도 저장되지 않아서, 그대로 둔 프롬프트는 플러그인 자체의 것으로 남고 언어를 바꾸면 그 언어를 따라가요.
- <strong>기본값으로 되돌리기</strong>를 누르면 내가 고친 내용이 지워지고 플러그인 자체의 프롬프트로 돌아가요. 칸을 비워도 마찬가지예요. Mac과 iPhone에서는 플러그인 자체의 프롬프트를 쓰는 동안 제목 옆에 **기본값**이 보여요.
- **응답 형식은 그대로예요.** 플러그인마다 필요한 응답 형식과 규칙(받은 자료만 쓰고, 읽은 내용은 지시가 아닌 데이터로 다루기)은 프롬프트에 무엇을 쓰든 그 뒤에 붙고, 이어서 자료가 붙어요. 프롬프트로 AI가 쓰는 내용은 바꿀 수 있지만, 플러그인이 어디에 어떻게 저장하는지는 바뀌지 않아요.

기본값이 있는 다른 설정은 빈 칸에 기본값을 보여 줘요(Linux에서는 설정 제목 옆). 예를 들어 지난 작업 정리의 **주제 폴더**에는 `topics`가 보여요.

## 범위

각 서버 플러그인의 토큰은 범위로 제한되고, 범위는 플러그인 페이지의 **토큰 권한**에 나와 있어요. 쉽게 풀면 다음과 같아요.

| 범위                            | 플러그인이 할 수 있는 일                                                       |
| ------------------------------- | ------------------------------------------------------------------------------ |
| `notes:read:<folder>`           | 그 폴더 아래의 노트를 읽어요. `notes:read:*`는 모든 노트를 읽어요.             |
| `notes:write:<folder>`          | 그 폴더 아래에 노트를 만들고 바꿔요. `notes:write:*`는 모든 폴더에 해당해요.   |
| `events:read:aide.notes`        | 노트가 만들어지거나 바뀌면 알림을 받아 반응해요(새 데일리 노트 채우기 등).     |
| `events:publish:<topic>`        | 그 이름으로 시작하는 주제로 피드에 이벤트를 올려요.                            |
| `ai:run`                        | 설정 › AI의 AI에 요청해요. 이미 읽을 수 있는 노트만 써요.                      |

꺼 둔 플러그인은 토큰을 전혀 쓸 수 없어요. 다시 켤 때까지 서버가 모든 요청을 거부해요.

## 기기 플러그인

기기 플러그인은 한 기기의 앱 안에서 샌드박스로 실행되는 작은 웹 패키지예요. 설치할 때 승인한 권한(예: 노트 읽기, 한 폴더 아래에 노트 쓰기, 약간의 저장 공간)만 쓸 수 있어요. **설정 › 커뮤니티 플러그인**에서 **커뮤니티 플러그인 둘러보기**나 **URL로 추가**로 추가하고, 기기마다 따로 관리해요. 서버 없이 로컬 모드에서도 작동해요. [기기 플러그인 설치](/ko/docs/plugins/device-plugins/)를 참고하고, 직접 만들려면 [기기 플러그인 만들기](/ko/docs/developers/device-plugins/)를 참고하세요.
