저녁 정리는 하루를 마무리해 줘요. AI가 오늘 쓴 내용을 읽고, 진척된 것과 그렇지 못한 것, 내일 이어서 할 것을 정리해요.

<PluginFacts id="recap" />

## 하는 일

21:30(또는 정한 시간)이 되면 플러그인은 다음을 해요.

1. 오늘 데일리 노트를 읽어요(아직 없으면 템플릿으로 만들어요).
2. `plugins.json`에 열린 이슈 노트를 지정했다면 그 노트도 읽어요([로컬 키](#로컬-키) 참고). 열린 이슈는 오래됐을 수 있는 힌트로 AI에 전달돼요. 오늘 노트와 어긋나면 오늘 노트가 우선해요.
3. AI에 짧은 글머리표 네 묶음으로 정리를 요청해요. 할 말이 없는 묶음은 빼요.
    - **진척된 것**
    - **밀린 것**
    - **내일로 넘길 것**
    - **새로 열린 이슈**

    AI는 근거 없이 압박하는 말("N일째 방치")을 쓰지 않도록 지시받아요.
4. 하루 노트 `briefings/{date}`의 자기 섹션에 `## 🌙 저녁 정리` 아래로 써요. [아침 브리핑](/ko/docs/plugins/briefing/)과 같은 노트예요.
5. 피드에 "🌙 저녁 정리 완료"를 올려요. 알림은 보내지 않아요.

AI 요청이 실패하면 다음 날 저녁까지 10분마다 다시 시도해요. 컴퓨터가 꺼져 있거나 잠자기 중이어서 놓친 저녁은 3시간 안에 깨어나면 다시 실행해요.

## 시작하기 전에

- [데스크톱 호스트](/ko/docs/self-hosting/desktop-host/)나 직접 운영하는 서버가 필요해요.
- **설정 › AI**에 AI(**Anthropic API 키** 또는 **내 게이트웨이**)가 필요해요.
- 내용이 들어 있는 그날의 데일리 노트가 필요해요. 저녁 정리는 오늘 데일리 노트에 적힌 것만 알아요.

## 설정하기

<Steps>

1. 플러그인을 켜요. 설정의 **서버에 저장** 아래에서 **저녁 정리**를 고르고 **활성화됨**을 켜요(Linux에서는 **설정 › 플러그인**에서 해당 행의 스위치). [플러그인 켜기](/ko/docs/plugins/overview/#플러그인-켜기)를 참고하세요.
2. 21:30이 맞지 않으면 **시간**을 바꿔요. [열린 이슈](/ko/docs/plugins/loops/)도 쓴다면 저녁 정리를 그보다 뒤에 두세요(열린 이슈는 21:15에 실행돼요). 그래야 저녁 정리가 갱신된 노트를 읽어요.
3. 선택 사항: 저녁 정리에 열린 이슈를 전달하려면 `plugins.json`에 `loopsNote`를 추가하고 호스트를 다시 시작해요(아래 참고).

</Steps>

## 설정

<PluginSettings id="recap" defaults={{ at: "21:30", push: "never (알림 안 함)", note: "briefings/{date}" }} />

**알림.** 따로 고르기 전까지는 선택 목록에 **자동**이 보여도 `never`처럼 알림을 보내지 않아요. 매일 저녁 알림을 받으려면 `force`(**항상 알림**)를, 피드의 분류에 맡기려면 **자동**을 골라요.

**쓸 노트.** `daily`로 정하면 오늘 데일리 노트 자체의 자기 섹션(끝, 또는 템플릿에서 `{{slot recap.evening}}`을 둔 곳)에 정리를 써요. 이때 저녁 정리는 자기가 전에 쓴 글을 읽는 내용에서 빼서, 자기 자신을 정리하지 않아요. 읽는 순간에 데일리 노트를 고치고 있었다면 10분 뒤에 다시 시도해요.

**프롬프트.** 직접 쓴 지침이 기본 지침을 대신해요. 그 뒤에는 여전히 날짜, 오늘 데일리 노트, 열린 이슈가 붙어요.

<Badge text="다음 릴리스" /> 칸에 기본 프롬프트가 플러그인이 쓰는 언어로 채워져 있어요. 프롬프트에 무엇을 쓰든 플러그인은 그 뒤에 응답 규칙을 붙여요. <strong>기본값으로 되돌리기</strong>를 누르거나 칸을 비우면 기본 프롬프트로 돌아가요. [프롬프트](/ko/docs/plugins/overview/#프롬프트)를 참고하세요.

### 로컬 키

데스크톱 호스트의 `plugins.json`([폴더 위치](/ko/docs/plugins/overview/#로컬-설정))에서 `"recap"` 아래에 적어요.

| 키          | 하는 일                                                                              |
| ----------- | ------------------------------------------------------------------------------------ |
| `loopsNote` | 열린 이슈로 읽을 노트의 경로. 예: `loops/open`. 읽기만 해요.                         |
| `openLoops` | `loopsNote` 대신 쓰는, 플러그인을 실행하는 컴퓨터의 파일. 읽기만 해요.               |

```json
{
    "plugins": {
        "recap": { "loopsNote": "loops/open" }
    }
}
```

두 키가 모두 없으면 저녁 정리는 오늘 데일리 노트만 읽어요.

## 문제 해결

### 저녁 정리가 오지 않았어요

- 플러그인이 켜져 있는지, **설정 › AI**가 <strong>규칙(AI 미사용)</strong>이 아닌지 확인하세요.
- 저녁 정리는 기본적으로 알림을 보내지 않아요. 피드나 하루 노트를 확인하세요.
- 21:30에 호스트가 실행 중이거나, 그 뒤 3시간 안에 깨어나야 해요.

### 저녁 정리에 열린 이슈가 나오지 않아요

`plugins.json`에 `loopsNote`(또는 `openLoops`)가 있을 때만 열린 이슈를 읽어요. 열린 이슈 플러그인을 켜는 것만으로는 부족해요.

## 개인정보

오늘 데일리 노트와, 지정했다면 열린 이슈 노트(각각 6 KiB까지)가 **설정 › AI**에서 정한 AI로 전달돼요. 저녁 정리는 호스트나 서버에 노트로 저장돼요. 그 밖에는 컴퓨터 밖으로 나가는 것이 없어요.
