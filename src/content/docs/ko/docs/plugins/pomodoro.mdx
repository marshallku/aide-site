뽀모도로는 자체 탭에 있는 집중 타이머예요. 25분 일하고 5분 쉬면, 끝낸 세션 수를 AIDE가 세어 줘요.

<PluginFacts id="pomodoro" kind="device" />

## 하는 일

앱 기본 컨트롤로 그린 **집중** 탭이 생겨요.

- 타이머에 **집중** 또는 **휴식**과 남은 시간이 보여요. **시작**, **일시정지**, **초기화**, **건너뛰기**로
  조작해요.
- 집중 세션이 끝나면 끝낸 세션으로 세고 휴식이 시작돼요. 휴식이 끝나면 다음 집중 세션이 준비돼요.
  **건너뛰기**는 지금 단계를 일찍 끝내요(건너뛴 집중 세션도 세요).
- **오늘 세션**에는 오늘 끝낸 집중 세션 수가 이 기기의 날짜 기준으로 보여요.

**저녁 기록.** 21:00에 플러그인이 그날의 횟수를 `pomodoro/log` 노트(없으면 만들어요)에 하루 한 줄씩 더해요.

```markdown
- 2026-10-21: 6 focus sessions
```

이 기록은 Mac과 Linux에서 AIDE가 열려 있을 때 실행돼요. 21:00에 AIDE가 닫혀 있었다면, 12시간 안에 AIDE를 다시
열 때 실행돼요. iPhone에서는 실행되지 않아요.

## 설정하기

<Steps>

1. **커뮤니티 플러그인 둘러보기**를 열고(**설정**의 **커뮤니티 플러그인** 아래, Linux에서는 설정의 **커뮤니티 플러그인** 페이지)
   **뽀모도로**를 선택해요.
2. **이 기기에 플러그인 데이터 보관**(횟수), **pomodoro의 노트 읽기, 변경 및 보관**(기록), **이 컴퓨터에서
   AIDE가 열려 있는 동안 정해진 시간에 실행**(21:00 기록)을 허용하고 **설치**를 선택해요.
3. **집중** 탭을 열고 **시작**을 선택해요.

</Steps>

설치, 업데이트, 제거는 [기기 플러그인 설치하기](/ko/docs/plugins/device-plugins/)에 자세히 나와 있어요.

## 설정

**설정 › 커뮤니티 플러그인 › 뽀모도로**(Linux에서는 **설정 › 커뮤니티 플러그인 › 뽀모도로**)에 있어요.

<PluginSettings id="pomodoro" kind="device" defaults={{ focusMinutes: "25", breakMinutes: "5" }} />

둘 다 1에서 240 사이의 분 단위 정수를 받아요.

## 제한

- 타이머는 앱에서 **집중** 탭의 페이지가 실행 중일 때 돌아가요.
- 횟수는 기기마다 따로 세요. 기록은 데스크톱 자체의 횟수로 쓰기 때문에 iPhone에서 끝낸 세션은 들어가지
  않아요.

<Aside>
공개 목록에는 여기서 설명한 것보다 오래된 뽀모도로가 올라와 있을 수 있어요. **이 기기에 플러그인 데이터
보관**만 요청하는 버전에는 저녁 기록이 없어요. 더 새 버전이 올라오면 **커뮤니티 플러그인 둘러보기**에 **업데이트**가
보여요.
</Aside>

## 개인정보

횟수는 이 기기의 플러그인 저장소에 남아요. 기록은 `pomodoro/` 아래의 노트라서 다른 노트처럼 동기화돼요.
플러그인은 네트워크 요청을 하지 않아요.
