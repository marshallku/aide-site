Linear 플러그인은 진행 중인 Linear 이슈를 한곳에 모아요. 나에게 할당된 이슈는 `work/now` 노트에 정리되고, 새
할당과 멘션, 댓글은 피드로 와요.

<PluginFacts id="linear" />

## 하는 일

**진행 중인 작업.** 5분마다 나에게 할당되고 완료나 취소되지 않은 이슈를 읽어서, `work/now` 노트("Work —
now")의 플러그인 전용 섹션에 최대 50개까지 써요. 마감일이 가까운 것이 먼저이고, 그다음 우선순위, 그다음 최근에
업데이트된 순이에요.

```markdown
Linear — 진행 중 2개
- [ENG-12](https://linear.app/acme/issue/ENG-12) Ship the export · 마감 2026-10-28 · P3 · assigned
- [ENG-9](https://linear.app/acme/issue/ENG-9) Clean up the logs · P1 · assigned
```

Linear의 우선순위는 `P4`(Urgent), `P3`(High), `P2`(Medium), `P1`(Low)로 보여요. 완료되거나 취소되거나 더 이상
내 이슈가 아닌 것은 목록에서 빠져요. 이 섹션은 플러그인 전용이라, 노트의 나머지와 옆에 있는
[GitHub](/ko/docs/plugins/github/), [Jira](/ko/docs/plugins/jira/) 섹션은 건드리지 않아요.

**멘션과 댓글.** 같은 때에 Linear 알림을 읽고 멘션, 댓글 속 멘션, 이슈의 댓글을 가져와요.

**피드에.** 바뀐 것마다 피드에 `linear` 주제로 항목을 하나씩 올리고, 이슈로 연결해요.

| 피드 제목                     | 언제                                     | 알림                 |
| ----------------------------- | ---------------------------------------- | -------------------- |
| "나에게 할당: &lt;제목&gt;"         | 이슈가 새로 나에게 할당됐을 때           | 항상                 |
| "나를 언급했어요: &lt;제목&gt;"     | 이슈나 댓글에서 누군가 나를 언급했을 때  | 피드의 분류가 정해요 |
| "새 댓글: &lt;제목&gt;"             | 내가 지켜보는 이슈에 새 댓글이 달렸을 때 | 피드의 분류가 정해요 |
| "마감이 2일 이내예요: &lt;제목&gt;" | 열린 이슈의 마감일이 2일 이내일 때       | 피드의 분류가 정해요 |
| "마감이 지났어요: &lt;제목&gt;"     | 마감일이 지났을 때                       | 피드의 분류가 정해요 |

항목은 한 번씩만 올려요. 마감일은 2일 이내가 될 때 한 번, 지났을 때 한 번 알리고, 내 시간대 기준으로 세요.
할당이 끝났다가 나중에 다시 생기면 다시 올려요. 키를 넣은 뒤나 다른 Linear 계정으로 바꾼 뒤의 첫 확인에서는
아무것도 올리지 않아요. 이미 열려 있던 이슈는 `work/now`에만 정리돼요.

플러그인은 읽기만 해요. Linear에 댓글을 달거나 무엇이든 바꾸지 않아요.

## 시작하기 전에

- [데스크톱 호스트](/ko/docs/self-hosting/desktop-host/)나 직접 운영하는 서버가 필요해요. 플러그인은 거기서
  실행되고, 그 컴퓨터에서 Linear를 읽어요.
- Linear 개인 API 키가 필요해요.

## 설정하기

<Steps>

1. **설정**을 열고 **코어 플러그인** 아래의 **Linear**를 선택해요(Linux에서는 설정의 **코어 플러그인** 페이지에
   있는 **Linear** 행).
2. **API 키** 옆의 **API 키 만들기**를 선택해요. Linear의 보안 설정이 열리면 개인 API 키를 만들고 복사해요.
3. **API 키**에 붙여 넣고 **저장**을 선택해요.
4. **활성화됨**을 켜요. 몇 분 안에 설정 아래 상태가 "&lt;내 이름&gt;로 연결됐어요 · 진행 중 N개 · HH:MM 확인"으로
   바뀌고, `work/now`에 진행 중인 이슈가 정리돼요.

</Steps>

## 설정

**팀**으로 일부 팀만 볼 수 있어요. 팀 키(`ENG`, `OPS`)로 적어요. 비우면 모든 팀이에요. 이슈와 알림 모두에

### 로컬 키

데스크톱 호스트의 `plugins.json`([폴더 위치](/ko/docs/plugins/overview/#로컬-설정))에서 `"linear"` 아래에 적어요.

| 키        | 하는 일                                                                                            |
| --------- | -------------------------------------------------------------------------------------------------- |
| `apiBase` | 플러그인이 통신할 API 주소. 기본값 `https://api.linear.app/graphql`. 보통은 정하지 않아요.         |

## 상태

플러그인 설정 아래의 상태에 지금 어떤지가 나와요.

- 확인에 성공할 때마다 "&lt;이름&gt;로 연결됐어요 · 진행 중 N개 · HH:MM 확인". 읽을 수 있는 것(이슈 300개)보다 많으면
  " · 처음 N개를 표시해요"가 붙어요.
- 키가 없으면 "API 토큰을 넣어 주세요". 키를 지우면 `work/now`의 플러그인 섹션도 "Linear — 연결이
  해제됐어요"로 바뀌어요.
- 확인에 실패하면 "토큰이 거부됐어요, HH:MM에 다시 시도해요", "요청 한도에 도달했어요, HH:MM에 다시
  시도해요", "Linear에 연결하지 못해 다시 시도해요, HH:MM에 다시 시도해요" 같은 문구가 나와요. `work/now`의
  목록은 그대로 두고, 첫 줄에 "&lt;시각&gt; 이후 갱신 안 됨: &lt;이유&gt;"를 표시해요.

## 문제 해결

### 토큰이 거부됐어요

Linear가 키를 받지 않았어요. 예를 들어 키가 취소됐을 때예요. 플러그인은 마지막 목록을 두고 30분마다 다시
시도해요. 새 키를 만들어 **API 키**에 저장하세요.

### 요청 한도에 도달했어요

Linear가 요청을 줄여 달라고 했어요. 플러그인은 Linear가 정한 만큼(최대 1시간) 기다렸다가 다시 확인해요.
네트워크가 없는 것 같은 다른 실패는 2분 뒤에 다시 시도하고, 점점 간격을 늘려 최대 30분마다 시도해요.

### work/now의 첫 줄과 상태가 하는 말

`work/now`의 플러그인 섹션 첫 줄은 "Linear — 진행 중 3개"처럼 보여요. 목록보다 작업이 많으면
" · 처음 50개를 표시해요"가, 확인에 실패한 뒤에는 " · &lt;날짜 시각&gt; 이후 갱신 안 됨: &lt;이유&gt;"가(아래 목록은 마지막으로
성공한 목록이에요), 첫 확인이 아직 성공하지 못했으면 " · 아직 동기화하지 못했어요: &lt;이유&gt;"가 붙어요. 섹션에는
시각이 없고, 마지막으로 확인한 시각은 플러그인 설정 아래의 상태에 나와요.

### 피드 항목이 늦게 와요

AIDE 서버가 플러그인의 피드 항목을 받지 못하면(서버가 다시 시작 중일 때 등) 항목은 기다렸다가 나중에 순서대로,
빠짐없이 한 번씩 보내져요. 그동안 상태에 " · 이벤트 N개가 AIDE 서버를 기다려요"가 붙어요.

## 개인정보

플러그인은 플러그인을 실행하는 컴퓨터에서 내 키로 Linear API와 통신하고, 읽기만 해요. 진행 중인 이슈마다
식별자, 제목(200자까지), 링크, 상태, 우선순위, 마감일, 마지막 업데이트만 보관하고, 설명이나 댓글은 보관하지
않아요. 키는 호스트나 서버에 봉인돼 저장되고, 이 플러그인만 읽을 수 있어요. `work/now` 노트와 피드 항목은 다른
노트처럼 기기에 동기화돼요. [어시스턴트](/ko/docs/guides/assistant/)와 [아침 브리핑](/ko/docs/plugins/briefing/)은
`work/now`를 지시가 아닌, 내 도구에서 온 데이터로 읽어요.
