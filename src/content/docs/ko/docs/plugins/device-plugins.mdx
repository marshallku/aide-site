기기 플러그인은 AIDE 앱 자체에 무언가를 더해요. 탭, 노트에서 여는 시트, 데스크톱 오른쪽 패널의 보기, 명령, 정해진 시간에 실행되는 작업 같은 것들이에요. 기기에서 샌드박스 안에 실행되고, 설치할 때 허용한 것만 건드릴 수 있어요. 앱 업데이트도, 서버도 필요 없어요.

## 찾는 곳

| 기기           | 위치                                                                         |
| -------------- | ---------------------------------------------------------------------------- |
| iPhone과 Mac   | **설정**의 **이 기기에 저장** 섹션                                           |
| Linux          | **설정 › 기기 플러그인**의 **이 기기에 저장** 그룹                           |

목록에는 설치한 플러그인과 상태가 나와요: **켬**, **끔**, **업데이트가 있어요**, **철회됨**, **재설치 필요**. 그 아래에 **플러그인 둘러보기**와 **URL로 추가**가 있어요.

Mac에서는 도구 막대나 명령 팔레트(<kbd>⇧</kbd><kbd>⌘</kbd><kbd>P</kbd>)에서도 **플러그인 둘러보기**를 열 수 있어요. Linux에서는 리본이나 <kbd>Ctrl</kbd><kbd>Shift</kbd><kbd>P</kbd>로 열 수 있어요.

### 코어 플러그인과 커뮤니티 플러그인 <Badge text="다음 릴리스" />

설정은 Obsidian처럼 플러그인을 둘로 나눠요.

- **코어 플러그인**은 AIDE와 함께 제공되고 함께 업데이트돼요. [서버 플러그인](/ko/docs/plugins/overview/)과
  iPhone의 SSH예요. Linux에서는 **코어 플러그인** 페이지예요.
- **커뮤니티 플러그인**은 플러그인 목록이나 링크에서 직접 설치하는 플러그인으로, 이 페이지에서 다루는 것들이에요.
  Linux에서는 **커뮤니티 플러그인** 페이지예요. 둘러보기 명령의 이름은 **커뮤니티 플러그인 둘러보기**예요.

**커뮤니티 플러그인** 섹션에는 이런 것들이 있어요.

- **제한 모드**: 켜 두는 동안 이 워크스페이스에서는 커뮤니티 플러그인이 실행되지 않아요(탭, 패널, 명령, 정해진
  시간의 실행이 멈춰요). 설치한 플러그인과 설정은 그대로 남고, 끄면 다시 돌아와요.
- 설치한 플러그인들. 제한 모드가 켜져 있으면 각각 **제한됨**으로 표시돼요.
- **커뮤니티에서**: 인덱스에 있지만 설치하지 않은 플러그인을 세 개까지 보여 주고, 누르면 설치 화면이 열려요.

**커뮤니티 플러그인 둘러보기**에는 플러그인마다 제작자, 버전, 그 버전이 게시된 날짜도 나오고, 설치 화면에는 소스 코드
링크가 있어요. 인덱스는 웹([marshallku.github.io/aide-plugins](https://marshallku.github.io/aide-plugins/))에서도
볼 수 있어요.

## 인덱스에서 설치하기

<Steps>

1. **플러그인 둘러보기**를 열어요. 인덱스에 있는 플러그인과 각 플러그인이 요청하는 권한이 나와요. 이미 있는 플러그인은 **설치됨**으로, 인덱스에 더 새로운 버전이 있으면 **업데이트**로 표시돼요.
2. 플러그인을 골라요. AIDE가 플러그인을 내려받고, 보여 주기 전에 모든 파일을 인덱스와 대조해요.
3. **요청하는 작업** 아래에서 동의하는 권한을 하나씩 켜요. 켠 권한만 허용돼요.
4. **설치**를 눌러요. 플러그인이 바로 켜져요.

</Steps>

## URL로 설치하기

플러그인은 웹 서버에 있는 폴더로, `manifest.json`과 `main.js`(대부분은 `index.html`과 `styles.css`도)가 들어 있어요.

<Steps>

1. **URL로 추가**를 열어요.
2. 폴더 주소(예: `https://example.com/my-plugin/`)를 입력하고 **가져오기**를 눌러요. 주소는 `https://`여야 해요(`http://`는 이 컴퓨터 자신을 가리킬 때만 돼요).
3. 이름, 버전, 제작자를 확인해요. 화면에 **인덱스 외부: 검증되지 않음**이 나와요. 아무도 이 파일을 대신 확인해 주지 않았으니, 믿을 수 있는 것만 설치하세요.
4. 동의하는 권한을 켜고 **설치**를 눌러요.

</Steps>

## 플러그인이 요청할 수 있는 권한

설치 화면은 각 권한을 쉬운 말로 보여 줘요. 승인하지 않은 범위의 호출은 `not allowed: …`로 실패해요.

| 권한               | 화면에 보이는 문구                                        | 허용하는 것                                                          |
| ------------------ | --------------------------------------------------------- | -------------------------------------------------------------------- |
| `notes:read:*`     | 모든 노트 읽기 및 검색                                    | 모든 노트 읽기, 검색, 변경 감지                                      |
| `notes:read:cards` | cards의 노트 읽기 및 검색                                 | 같은 일을 `cards` 또는 `cards/` 아래의 노트에 대해                   |
| `notes:write:…`    | 모든 노트 읽기, 변경 및 보관(또는 한 폴더의 노트)         | 그 노트를 만들고, 바꾸고, 덧붙이고, 보관하기                         |
| `todos:read`       | 모든 노트에서 미완료 및 완료된 할 일 읽기                 | 할 일의 텍스트와 필드. 노트의 나머지 내용은 아니에요                 |
| `todos:write`      | 모든 노트에서 할 일 완료 및 추가                          | 할 일 줄만 바꾸기                                                    |
| `storage`          | 이 기기에 플러그인 데이터 보관                            | 이 기기에만, 자체 데이터 512 KB                                      |
| `net:<host>`       | `<host>`에 연결                                           | 그 호스트 하나로 보내는 HTTPS 요청                                   |
| `schedule`         | 이 컴퓨터에서 AIDE가 열려 있는 동안 정해진 시간에 실행    | Mac과 Linux에서 예약 작업 실행                                       |
| `attachments:read` | 노트에 표시되는 이미지와 문서 읽기                        | 노트에 넣은 이미지와 문서 읽기                                       |
| `attachments:write`| 노트에 이미지와 문서 추가                                 | 새 첨부 파일 추가. 기존 첨부 파일은 절대 바꾸지 않아요               |

플러그인이 절대 할 수 없는 일:

- **혼자 인터넷에 접속하기.** 플러그인 페이지는 네트워크에서 아무것도 불러올 수 없어요. 밖으로 나가는 유일한 길은 `net:<host>`로 선언하고 내가 승인한 호스트로 보내는 요청이에요.
- **샌드박스 벗어나기.** 내 파일, 다른 앱, 다른 플러그인의 데이터를 읽을 수 없고, 자기 페이지에서 다른 곳으로 이동할 수 없어요.
- **허용된 폴더 밖에 쓰기.** 예를 들어 `notes:write:recall`이 있으면 `recall/` 아래의 노트만 바꿀 수 있어요.

## 플러그인이 실행되는 곳

- **iPhone, Mac, Linux**에서 기기 플러그인은 같은 방식으로 실행돼요. 한 기기에 설치한 플러그인은 다른 기기에 설치되지 않으니, 기기마다 추가하세요.
- **작업 공간별.** 설치하고, 승인하고, 켠 것은 지금 쓰는 서버 계정이나 보관소에 저장돼요. 다른 보관소로 바꾸면 플러그인의 접근 권한이 따라가지 않아요.
- **예약 작업**은 Mac과 Linux에서만, 그곳에서 AIDE가 열려 있는 동안만 실행돼요. 앱은 1분마다, 시작할 때, 컴퓨터가 깨어날 때 확인해요. 앱이 닫혀 있는 동안 놓친 작업은 건너뛰어요. 단, 플러그인이 따라잡기를 요청했다면 늦어진 시간이 12시간 이하일 때 시작하거나 깨어날 때 한 번 실행해요. iPhone은 플러그인의 예약 작업을 보여 주기만 하고 실행하지 않아요. 앱이 열려 있든 아니든 해야 하는 일은 [서버 플러그인](/ko/docs/plugins/overview/)의 몫이에요.
- **명령**은 명령 팔레트에 나와요(Mac은 <kbd>⌘</kbd><kbd>P</kbd>, Linux는 <kbd>Ctrl</kbd><kbd>P</kbd>, iPhone은 스크래치의 명령 버튼).
- **시트**는 편집기 도구 막대에 있는 노트의 **플러그인** 메뉴에 나와요(iPhone에서는 더 보기 메뉴 아래).
- **패널**은 데스크톱 오른쪽 패널의 보기예요. iPhone에는 없어요.

## 플러그인 화면

목록에서 설치한 플러그인을 고르면 다음이 보여요.

- 제거하지 않고 끌 수 있는 **활성화됨**, 탭이 있는 플러그인이라면 **탭으로 표시**.
- 설명, **버전**, **제작자**.
- 설정. 바꾸는 즉시 저장되고, 바꾸면 플러그인의 열린 페이지가 다시 시작돼요.
- **예약 작업**. 각 작업의 다음 실행과 마지막 실행, **지금 실행**이 있어요. Mac과 Linux에서는 **예약 실행**으로 모든 작업을 한꺼번에 끄고 켤 수 있어요. 다시 켜도 건너뛴 작업을 따라잡지는 않아요.
- **승인한 접근 권한**과, 플러그인을 가져온 주소인 **출처**.
- **이전 버전으로 돌아가기**와 **제거**.

## 업데이트, 되돌리기, 제거

- **업데이트.** 인덱스에 더 새로운 버전이 있으면 플러그인 행에 **업데이트가 있어요**가, **플러그인 둘러보기**에 **업데이트**가 나와요. 같은 방식으로 설치하고, 권한을 다시 승인해요. 설치된 플러그인과 id가 같은 패키지는 항상 기존 플러그인을 대신해요.
- **이전 버전으로 돌아가기.** 업데이트하면 이전 버전과 그 버전이 가졌던 데이터의 사본을 남겨 둬요. 되돌리면 둘 다 복원되고, 그때 승인했던 권한도 돌아와요.
- **제거**하면 이 기기에서 플러그인과 설정, 예약 작업, 데이터가 지워져요. 플러그인이 쓴 노트는 남아요. 내 노트니까요.

한 기기의 모든 플러그인은 합쳐서 최대 50 MB까지 쓸 수 있어요.

## 플러그인 인덱스

공개 인덱스는 `https://marshallku.github.io/aide-plugins/plugins.json`에 있고, 다른 인덱스를 정하지 않으면 **플러그인 둘러보기**가 이 인덱스를 써요. 인덱스의 모든 버전은 검토를 거치고, 인덱스에 각 파일의 해시가 기록돼 있어서 설치되는 것은 승인된 것과 정확히 같아요.

인덱스는 버전을 철회할 수도 있어요. 철회된 플러그인은 꺼지고, 이유와 함께 **철회됨**으로 표시돼요. **무시하고 켜기**를 누르기 전까지 꺼진 채로 있어요. 믿을 수 없다면 제거하세요.

<Aside>
인덱스에 이 문서가 설명하는 것보다 오래된 버전이 올라가 있을 수 있어요. **플러그인 둘러보기**에는 제공되는 버전이 나오고, 더 새로운 버전이 올라오면 **업데이트**가 나타나요.
</Aside>

### 비공개 인덱스

이 기기의 노트 폴더에서는 **플러그인 둘러보기** 맨 위에 **인덱스** 항목이 있어요. 직접 만든 인덱스 주소(`https://…/plugins.json`)를 입력하면 그 인덱스를 둘러봐요. 비워 두면 공개 인덱스를 써요. 서버를 쓰고 있다면 **플러그인 둘러보기**는 서버에 설정된 인덱스의 서버 사본을 보여 줘요. 내 플러그인용 인덱스를 만들려면 [기기 플러그인 만들기](/ko/docs/developers/device-plugins/)를 참고하세요.

## 문제 해결

### 플러그인에 재설치 필요가 표시돼요

설치한 뒤에 이 기기에 있는 플러그인 파일 하나가 바뀌어서, AIDE가 실행하지 않아요. **플러그인 둘러보기**나 해당 URL에서 다시 설치하세요.

### 플러그인이 멈추고 다시 시작이 보여요

5초 동안 응답하지 않는 플러그인은 멈춰요. **다시 시작**을 누르세요. 계속 그러면 플러그인을 끄고 제작자에게 알려 주세요.

### 이 기기의 플러그인 용량이 50 MB를 초과하게 된다고 나와요

더 이상 쓰지 않는 플러그인을 제거한 뒤 다시 설치하세요.

### 플러그인 목록에 연결할 수 없어요

연결 상태나 **인덱스**의 주소를 확인하세요. 인덱스를 새로 가져올 수 없을 때는 마지막으로 가져온 사본을 보여 주고, 그렇다고 알려 줘요.

### 예약 작업이 실행되지 않았어요

예약 작업은 Mac이나 Linux 컴퓨터에서 AIDE가 열려 있는 동안만 실행돼요. 플러그인의 **예약 작업**을 확인하세요. 예약 실행을 허용하지 않았다고 나오면 다시 설치하면서 **이 컴퓨터에서 AIDE가 열려 있는 동안 정해진 시간에 실행**을 켜세요. **지금 실행**은 어느 경우든 쓸 수 있어요.
