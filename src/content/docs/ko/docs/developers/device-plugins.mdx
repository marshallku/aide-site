기기 플러그인은 파일 최대 네 개로 된 폴더예요. AIDE는 이 폴더를 iPhone, Mac, Linux 앱의 샌드박스 웹 뷰에
불러와요. 플러그인은 탭, 데스크톱 오른쪽 패널의 뷰, 노트 위에 뜨는 시트, 팔레트 명령, 예약 실행을 추가할 수
있어요. 노트에는 `aide.call(…)`로만 접근하고, 그것도 소유자가 설치할 때 켠 권한 안에서만 가능해요. 앱 업데이트도
서버도 필요 없어요. 폴더를 아무 정적 HTTPS 서버에 올리고 URL로 설치하면 돼요.

사용자로서 플러그인을 설치하고 관리하는 방법은 [기기 플러그인 설치하기](/ko/docs/plugins/device-plugins/)에서
다뤄요. 앱이 열려 있든 아니든 돌아가야 하는 작업이라면 [서버 플러그인](/ko/docs/developers/server-plugins/)을
만드세요.

## 패키지

패키지는 아래 파일들이 든 폴더예요. 파일마다 최대 2 MB이고, 그 밖의 파일이 있으면 거부돼요.

| 파일            | 필수   | 내용                                                                                          |
| --------------- | ------ | --------------------------------------------------------------------------------------------- |
| `manifest.json` | 예     | 플러그인이 무엇인지, 어디에 보이는지, 무엇을 요청하는지                                       |
| `main.js`       | 예     | 플러그인 코드                                                                                 |
| `index.html`    | 아니요 | 페이지(`web` 플러그인). 없으면 AIDE가 `main.js`를 불러오는 빈 페이지를 써요                    |
| `styles.css`    | 아니요 | 페이지 스타일                                                                                 |

패키지는 모든 파일의 SHA-256 해시로 식별돼요. 설치한 뒤 기기에서 파일이 하나라도 바뀌면, AIDE는 다시 설치할
때까지 플러그인을 꺼 둬요.

페이지는 네트워크에서 아무것도 불러올 수 없어요. `http(s)`, `ws`, `file`, `blob` 로드는 모두 막히고, 탐색은
플러그인 자체 출처인 `aide-plugin://<id>/`를 벗어나지 않아요. 네트워크 접근은 소유자가 승인한 호스트에 한해
`net.fetch`로 해요.

## 매니페스트

```json
{
    "id": "eisenhower",
    "name": "Eisenhower matrix",
    "version": "1.0.0",
    "description": "Open todos in a do / schedule / delegate / later grid.",
    "author": "you",
    "render": "web",
    "tabs": [{ "id": "matrix", "title": "Matrix", "icon": "square.grid.2x2" }],
    "capabilities": ["todos:read", "todos:write"]
}
```

| 필드           | 필수   | 값                                                                                                                           |
| -------------- | ------ | ---------------------------------------------------------------------------------------------------------------------------- |
| `id`           | 예     | 소문자로 시작하고 소문자, 숫자, `-`로 이어지는 2–40자. 같은 id의 패키지를 설치하면 업데이트돼요                              |
| `name`         | 예     | 최대 60자                                                                                                                    |
| `version`      | 예     | 문자열. 공개 인덱스에 올리려면 `1.2.3`이나 `1.2.3-beta.1` 형태여야 해요(최대 32자)                                           |
| `description`  | 예     | 설정과 인덱스에 보여요                                                                                                       |
| `author`       | 아니요 | 인덱스에 보여요                                                                                                              |
| `render`       | 예     | `web`(플러그인이 HTML을 그려요) 또는 `native`(`main.js`가 앱 자체 컨트롤 트리를 보내요)                                       |
| `capabilities` | 예     | 요청하는 권한 목록([권한](#권한) 참고). 최대 32개. `[]`는 아무것도 요청하지 않아요                                           |
| `tabs`         | 예     | 메인 영역의 섹션 최대 3개, `{id, title, icon}`. 없으면 `[]`                                                                  |
| `panels`       | 아니요 | 데스크톱 오른쪽 패널의 뷰 최대 3개. 형태는 tabs와 같아요                                                                     |
| `sheets`       | 아니요 | 노트 편집기 플러그인 메뉴의 항목 최대 3개. 형태는 tabs와 같아요                                                              |
| `settingsPage` | 아니요 | `{"title": "…"}`(최대 30자). 플러그인 상세 화면에서 연결되는 플러그인 자체 페이지                                            |
| `settings`     | 아니요 | 소유자가 플러그인 상세 화면에서 편집하는 필드 최대 64개([설정](#설정) 참고)                                                  |
| `schedules`    | 아니요 | 예약 실행 최대 10개. `schedule` 권한이 필요해요([예약](#예약) 참고)                                                          |
| `commands`     | 아니요 | 명령 팔레트 항목 최대 10개([명령](#명령) 참고)                                                                               |
| `embeds`       | 아니요 | 이 플러그인이 편집하는 첨부 파일 종류 최대 4개([임베드](#임베드) 참고)                                                       |
| `locales`      | 아니요 | 앱이 매니페스트에서 가져와 보여 주는 내용의 번역([언어](#언어) 참고)                                                         |
| `strings`      | 아니요 | `aide.t`가 쓰는 플러그인 자체 문자열 카탈로그([언어](#언어) 참고)                                                            |

`tabs`, `panels`, `sheets`에서 각 `id`는 플러그인 id와 같은 규칙을 따르고 목록 안에서 고유해야 해요. `title`은
1–20자이고 `icon`은 필수예요. 아이콘은 SF Symbols 방식의 이름이에요(`square.grid.2x2`, `checklist`,
`textformat.size`). 앱이 아는 이름이면 앱 자체 아이콘을, 그 밖의 이름이면 플러그인 아이콘을 그려요. 키는
대소문자를 구분하고, 값의 타입이 맞지 않으면(텍스트 자리에 숫자, 목록 안의 `null`) 패키지가 유효하지 않아요.

### 플러그인이 보이는 곳

- **탭**은 메인 영역에서 스크래치, 위키 등과 나란히 놓이는 섹션이에요. 탭마다 자기 페이지가 실행되고,
  `aide.tab`에 지금 그리는 탭의 id가 들어 있어요.
- **패널**은 Mac과 Linux의 오른쪽 패널 뷰예요. 패널 페이지는 그 뷰가 보이는 동안 실행되고, 다음에 열면 새로
  시작해요. iPhone에는 사이드 패널이 없어서, 패널만 있는 플러그인은 거기서 아무것도 보이지 않아요.
- **시트**는 노트 편집기의 플러그인 메뉴에서 열리고, 열기 전에 노트가 먼저 저장돼요. `aide.close()`로 닫아요.
- **설정 페이지**는 플러그인 상세 화면에서 열려요. `aide.close()`로 돌아가요.

플러그인은 이 중 어떤 조합이든 가질 수 있고, 하나도 없을 수도 있어요(명령과 예약만). 시트와 설정 페이지는 매번
새로 시작하고 닫으면 끝나요. 열려 있는 동안 플러그인을 끄거나 업데이트하면 그 자리에서 멈추고 **다시 시작**이
보여요.

`aide.surface`는 페이지가 어디서 실행 중인지 알려 줘요.

| `aide.surface.kind` | 다른 필드                | 실행 형태                                        |
| ------------------- | ------------------------ | ------------------------------------------------ |
| `tab`               | `id`                     | 탭                                               |
| `panel`             | `id`                     | 오른쪽 패널 뷰                                   |
| `sheet`             | `id`, `noteId`, `embed`? | 노트 `noteId` 위의 시트                          |
| `settings`          | —                        | 설정 페이지                                      |
| `schedule`          | `id`                     | 보이지 않는 곳에서 도는 예약 실행                |
| `command`           | `id`, `noteId`?          | 보이지 않는 곳에서 도는 팔레트 명령              |

`noteId`만으로는 아무 권한도 생기지 않아요. 노트를 읽으려면 여전히 `notes:read` 권한이 필요해요.

## 권한

설치 화면에는 플러그인이 요청하는 권한이 하나씩 나오고, 소유자는 동의하는 것만 켜요. 승인되지 않은 호출은
`not allowed: …`로 실패해요.

| 권한                   | 허용하는 것                                                                                                                    |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| `notes:read:<prefix>`  | `<prefix>` 또는 `<prefix>/` 아래 노트를 읽고, 검색하고, 지켜보기. `*`는 모든 노트예요                                          |
| `notes:write:<prefix>` | 그 노트를 만들고, 바꾸고, 덧붙이고, 보관하고, 노트 안에 플러그인 자체 섹션 쓰기. 읽기를 포함해요                               |
| `todos:read`           | 모든 노트의 열린 할 일과 완료한 할 일(할 일마다 텍스트와 필드만, 노트 본문은 아님)                                             |
| `todos:write`          | 할 일 체크와 추가(할 일 줄만 바뀌어요)                                                                                         |
| `storage`              | 이 기기에 플러그인 자체 JSON 512 KB                                                                                            |
| `net:<host>`           | `net.fetch`로 그 호스트에 HTTPS 요청(리디렉션 포함)                                                                            |
| `schedule`             | 이 컴퓨터(Mac, Linux)에서 AIDE가 열려 있는 동안 정해진 시각에 `schedules` 실행                                                 |
| `attachments:read`     | 노트에 임베드된 이미지와 문서 읽기                                                                                             |
| `attachments:write`    | 새 첨부 파일 추가(생성만). 읽기를 포함해요                                                                                     |

접두사는 경로 단위 전체로 맞춰요. `notes:read:daily`는 `daily`와 `daily/2026-10-22`는 포함하지만 `daily-log`는
포함하지 않아요. 필요한 만큼 가장 좁은 접두사를 요청하세요. 공개 인덱스 심사도 그걸 요구해요.

## 런타임 API

`window.aide.call(method, params)`는 프로미스를 반환해요. 노트가 기기의 폴더에 있든 서버에 있든 모든 호출이
똑같이 동작해요. 앱이 노트를 가진 쪽으로 호출을 보내요.

| 메서드                  | 파라미터                                                                       | 반환                                                                                             |
| ----------------------- | ------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------ |
| `notes.list`            | `{prefix?}`                                                                    | 노트 요약(최대 500개)                                                                            |
| `notes.get`             | `{id}`                                                                         | `body`와 `todos`를 포함한 노트                                                                   |
| `notes.create`          | `{path, body?}`                                                                | 노트                                                                                             |
| `notes.update`          | `{id, version, body?, path?}`                                                  | 노트. `version`이 오래되면 실패해요                                                              |
| `notes.append`          | `{id, text, heading?}`                                                         | 노트                                                                                             |
| `notes.search`          | `{query, limit?}`(query ≤ 200바이트, limit 1–50, 기본값 20)                    | 결과 `{id, path, kind, title, summary?, snippet?}`. 플러그인이 읽을 수 있는 노트만               |
| `notes.section.get`     | `{id, name}`                                                                   | `{name, content, todos, version, openLine, closeLine}` 또는 `null`                               |
| `notes.section.replace` | `{id, name, content, version?}`(`name`은 `<plugin id>.<name>`이어야 해요)      | 노트                                                                                             |
| `notes.archive`         | `{id, version}`                                                                | `true`. 노트는 **최근 삭제된 항목**으로 가고, 소유자가 되돌릴 수 있어요                          |
| `periodic.get`          | `{period, date?}`                                                              | 노트. 없으면 만들어요(만들려면 `notes:write:*`가 필요해요)                                       |
| `periodic.find`         | `{period, date?}`                                                              | 노트 또는 `null`                                                                                 |
| `todos.list`            | —                                                                              | 필드를 파싱한 열린 할 일                                                                         |
| `todos.done`            | `{from, to}`(날짜, 양 끝 포함)                                                 | 완료한 할 일 `{noteId, notePath, noteTitle, line, text, title, date, stamped}`                   |
| `todos.setStatus`       | `{noteId, line, version, status, text}`                                        | `{noteId, version}`                                                                              |
| `todos.add`             | `{text, target?: "today" \| "inbox"}`                                          | `{noteId, path, version}`                                                                        |
| `settings.get`          | —                                                                              | 소유자의 설정(선언한 키만)                                                                       |
| `storage.get`           | —                                                                              | 저장된 값 또는 `null`                                                                            |
| `storage.set`           | `{value}`                                                                      | `true`                                                                                           |
| `net.fetch`             | `{url, method?, headers?, body?}`                                              | `{status, body, contentType}`                                                                    |
| `events.subscribe`      | `{events: [...]}`(`aide.on`이 호출해요)                                        | `true`                                                                                           |
| `attachments.get`       | `{path}`                                                                       | `{path, mime, data}`(`data`는 base64) 또는 `null`                                                |
| `attachments.put`       | `{path, data}`(`data`는 base64, ≤ 20 MB)                                       | `{path, mime}`                                                                                   |
| `panel.open`            | `{id}`                                                                         | 오른쪽 패널에 플러그인의 패널 하나를 보여 줘요                                                   |

세부 사항이에요.

- **id와 날짜.** 노트 id는 UUID이고, 그 밖의 값은 거부돼요. `period`는 `daily`, `weekly`, `monthly`,
  `quarterly`, `yearly` 중 하나이고, 날짜는 `YYYY-MM-DD`예요.
- **할 일.** `todos.list`는 열린 할 일마다 `noteId`, `notePath`, `noteTitle`, `line`, `text`, `title`,
  `status`, `version`, `priority`, `tags`를 주고, 있으면 `due`, `scheduled`, `noteDate`도 줘요. `noteId`,
  `line`, `version`, `text`를 상태 문자와 함께 `todos.setStatus`에 다시 넘기세요(`x` 완료, `/` 진행 중,
  `-` 취소, 나머지는 [할 일](/ko/docs/guides/todos/) 참고). `todos.add`는 최대 1,000자의 한 줄을 받아요.
  `todos.done`에는 `todos:read`나 `todos:write`가 필요해요.
- **검색, 섹션, 노트 이벤트**에는 `notes:` 권한이 하나라도 있어야 하고, 플러그인이 읽을 수 있는 노트만
  돌려줘요. 그래서 검색 결과가 `limit`보다 적을 수 있어요.
- **섹션**은 `<!-- aide:slot <name> -->` 표시 사이의 블록이에요. 템플릿의 `{{slot <name>}}` 줄이 만들고 서버
  플러그인이 쓰는 것과 같은 표시예요. 플러그인은 쓸 수 있는 노트에서 `<its id>.<name>` 이름의 섹션만 써요.
  섹션이 없으면 끝에 추가돼요. `version`을 주면 그 사이에 바뀐 노트는 거부돼요(`the note changed; reload it`).
  주지 않으면 앱이 그 시점의 노트 내용 위에 쓰고, 다른 편집과 경합하면 최대 3번까지 다시 읽어요.
- **첨부 파일**은 편집기가 임베드하는 종류(이미지, SVG, HTML)의 보관함 경로이고, 내용으로 종류를 확인해요.
  `attachments.put`은 생성만 해요. 이미 있는 경로에 같은 바이트를 쓰면 성공하고, 다른 바이트면
  `that path already holds another attachment`로 실패해요. 바뀐 그림은 새 경로가 되고, 노트의 참조도 그 경로로
  바뀌어요.
- <strong><code>net.fetch</code></strong>는 승인된 호스트의 `https` URL을 받아요. 응답이 1 MB를 넘으면 실패해요.
- <strong><code>panel.open</code></strong>은 탭, 시트, 패널, 설정 페이지, 소유자가 실행한 명령에서는 되지만 예약 실행에서는 안 돼요.
  오른쪽 패널이 없는 기기에서는 실패해요(`this device has no side panel`).

### 이벤트

`aide.on(event, handler)`는 구독하고 `events.subscribe`의 프로미스를 반환해요.

| 이벤트         | 핸들러가 받는 것                                    | 언제                                                                                       |
| -------------- | --------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| `note.created` | `notes.list`가 주는 형태의 노트 요약                | 플러그인이 읽을 수 있는 노트가 생겼을 때                                                   |
| `note.changed` | 노트 요약                                           | 플러그인이 읽을 수 있는 노트가 바뀌었을 때(범위 안으로 옮겨진 노트도)                      |
| `note.active`  | 화면에 있는 노트의 요약 또는 `null`                 | 구독 직후, 다른 노트가 화면에 올라올 때, 화면의 노트가 저장될 때                           |

- `note.created`와 `note.changed`는 앱에서의 편집, 다른 플러그인(이 플러그인 포함)의 편집, 다른 기기에서의
  편집, 그리고 노트 폴더라면 다른 앱의 편집까지 포함해요. 앱은 노트 폴더는 2초마다, 서버는 10초마다 확인해요.
  이벤트는 페이지가 실행 중일 때만 와요. 첫 `aide.on` 이전의 일은 다시 보내지 않고, 두 번 확인하는 사이의
  변경은 노트마다 이벤트 하나로 와요(오래된 것부터, 한 번에 최대 200개, 그보다 많으면 버려요). 보관해도 아무것도
  보내지 않아요. 본문이 필요하면 `notes.get`으로 가져오세요.
- `note.active`에는 권한이 필요 없어요. 화면에 무엇이 있는지는 앱 자체의 상태이기 때문이에요. 화면에 노트가
  없거나 플러그인이 그 노트를 읽을 수 없으면 `null`이에요.

### 브리지의 다른 멤버

| 멤버                                  | 내용                                                                                               |
| ------------------------------------- | -------------------------------------------------------------------------------------------------- |
| `aide.surface`, `aide.tab`            | 페이지가 실행되는 곳(위 참고)                                                                      |
| `aide.close()`                        | 시트나 설정 페이지를 닫아요                                                                        |
| `aide.instance`                       | 이 기기의 이 설치본. 업데이트와 롤백을 거쳐도 유지되는 UUID예요                                    |
| `aide.locale`                         | 앱 언어, `en` 또는 `ko`                                                                            |
| `aide.t(key, …args)`                  | 앱 언어로 된 플러그인 자체 `strings`                                                               |
| `aide.onSchedule(id, handler)`        | 예약 실행 핸들러                                                                                   |
| `aide.onCommand(id, handler)`         | 팔레트 명령 핸들러                                                                                 |
| `aide.render(tree)`, `aide.onAction`  | 네이티브 컨트롤로 그리기(`render: "native"`)                                                       |

`aide.instance`가 있으면 여러 기기에서 쓰는 플러그인이 기기마다 자기 노트를 둘 수 있어요. Recall이 복습 기록을
이렇게 남겨요.

## 예약

Mac과 Linux에서는 서버 없이도 플러그인을 정해진 시각에 실행할 수 있어요. 앱이 보이지 않는 곳에서 페이지를
불러오고, 때가 된 예약의 핸들러를 호출해요.

```json
"capabilities": ["notes:write:pomodoro", "schedule"],
"schedules": [
    { "id": "evening-log", "at": "21:00", "catchUp": true },
    { "id": "sync", "every": "15m", "days": ["mon", "tue", "wed", "thu", "fri"] }
]
```

```js
aide.onSchedule("evening-log", async ({ id, scheduledFor, firedAt, catchUp, manual }) => {
    // 일반 API를 쓸 수 있어요. 끝나면 resolve하고, 실패하려면 throw하세요.
});
```

- 예약마다 `id`(`a-z`, `0-9`, `-`, 1–40자, 고유)와 `at`(`HH:MM`, 24시간제, 소유자의 시간대) 또는
  `every`(`5m`부터 `24h`까지, 분은 `m`, 시간은 `h`) 중 정확히 하나가 있어요. `days`로 `mon tue wed thu fri sat
  sun` 중 일부 요일로 제한해요. `catchUp`은 `at`에만 써요.
- **그 컴퓨터에서 앱이 열려 있을 때만 돌아요.** 1분마다, 실행할 때, 컴퓨터가 깨어날 때 확인해요. 10분까지 늦은
  실행은 제시간으로 쳐요. 놓친 `at` 실행은 건너뛰어요. 다만 `catchUp: true`이면 12시간 이내로 놓친 경우 실행하거나
  깨어날 때 한 번 실행해요. `every`는 마지막 실행 시작부터 세고, 쌓이지 않아요. 밤새 꺼져 있었다면 한 번만
  실행해요.
- 핸들러는 `{id, scheduledFor, firedAt, catchUp, manual}`를 받아요(ISO 시각, **지금 실행**이면 `manual`이
  true). `main.js`가 불러와지자마자 등록하세요. 앱은 5초 동안 기다려요.
- 플러그인마다 한 번에 하나씩, 실행마다 최대 60초예요. 꺼지거나, 바뀌거나, 삭제된 플러그인의 실행은 멈춰요.
- 플러그인 상세 화면에는 예약이 다음 실행과 마지막 실행과 함께 나오고, 예약마다 **지금 실행** 버튼이 있으며,
  **예약 실행**으로 전부 멈출 수 있어요.
- iPhone은 예약을 실행하지 않아요(iOS는 플러그인을 백그라운드에서 계속 실행할 수 없어요). 목록만 보여 주고,
  Mac이나 Linux용 AIDE가 열려 있는 동안 실행된다고 알려 줘요.

## 명령

명령은 명령 팔레트의 항목이에요(Mac은 <kbd>⌘</kbd><kbd>P</kbd>, Linux는 <kbd>Ctrl</kbd><kbd>P</kbd>, iPhone은
스크래치 메뉴의 **명령**). 하나를 고르면 예약 실행처럼 보이지 않는 곳에서 페이지를 불러오고 핸들러를 호출해요.

```json
"commands": [
    { "id": "stamp", "title": "Stamp the run log", "icon": "clock" },
    { "id": "count", "title": "Count this note's words", "when": "note" }
]
```

```js
aide.onCommand("count", async () => {
    const note = await aide.call("notes.get", { id: aide.surface.noteId });
    // …
});
```

`title`은 1–40자예요. `"when": "note"`이면 노트가 화면에 있을 때만 팔레트가 명령을 보여 주고(Mac과 Linux.
iPhone의 스크래치에서는 보이지 않아요), 실행은 `aide.surface.noteId`를 받아요. 실행은 핸들러의 프로미스가
끝나거나(오류는 소유자에게 보여요), 60초가 지나거나, 페이지가 응답하지 않으면 끝나요. 명령 자체에는 권한이
필요 없지만, 명령이 호출하는 것에는 평소의 권한이 필요해요.

## 임베드

플러그인은 이름 끝부분으로 구분되는 일부 첨부 파일의 편집기가 될 수 있어요.

```json
"capabilities": ["notes:write:*", "attachments:write"],
"sheets": [{ "id": "draw", "title": "Drawing", "icon": "scribble" }],
"embeds": [{ "suffix": ".excalidraw.svg", "sheet": "draw" }]
```

`suffix`는 소문자이고, `.`으로 시작하며, `a-z 0-9 . -`로 된 2–40자이고, 첨부 파일 확장자(`.svg .png .jpg .jpeg
.gif .webp .html .htm`)로 끝나요. `sheet`는 플러그인의 시트 중 하나예요. 노트가 경로가 이 접미사로 끝나는 첨부
파일을 임베드하면, 그 위에 **편집** 버튼이 생겨요. 버튼은 `aide.surface.embed = {src, path}`로 그 시트를 열어요.
`src`는 노트에 적힌 그대로이고, `path`는 그게 가리키는 첨부 파일이에요. 대신 플러그인 메뉴에서 열면 시트에
`embed`가 없고, 새로 만드는 거라는 뜻이에요.

첨부 파일 자체가 형식이에요. 편집기는 새 첨부 파일을 저장하고 노트의 참조를 그쪽으로 바꿔요. 그래서 노트는
플러그인이 있든 없든 그 파일을 보여 줘요. Excalidraw 플러그인은 그림 데이터를 자기가 쓰는 SVG 안에 담아 둬요.

## 설정

`settings`는 소유자가 플러그인 상세 화면에서 편집하는 필드를 선언해요. 페이지는 `settings.get`으로 읽어요.

```json
"settings": [
    { "key": "minutes", "title": "Minutes", "type": "number", "help": "How long a session lasts" },
    { "key": "mode", "title": "Mode", "type": "enum", "options": ["short", "long"] }
]
```

| 필드      | 값                                                                                                  |
| --------- | --------------------------------------------------------------------------------------------------- |
| `key`     | 글자로 시작하고 글자, 숫자, `_`, `-`로 이어지는 최대 40자. `token`은 안 돼요                        |
| `title`   | 최대 80바이트                                                                                       |
| `type`    | `string`, `text`(여러 줄), `number`, `bool`, `enum`, `time`(`HH:MM`), `list`(문자열 목록)           |
| `options` | `enum`용 옵션 1–32개                                                                                |
| `help`    | 선택, 최대 300바이트                                                                                |

기기 플러그인에는 `secret` 타입이 없어요. 설정을 바꾸면 플러그인의 열린 페이지가 다시 시작돼요.

## 언어

앱은 영어나 한국어로 표시되고, 플러그인도 따라갈 수 있어요.

- `locales`는 앱이 매니페스트에서 가져와 보여 주는 내용을 언어별로 번역해요. `name`, `description`,
  `settingsTitle`, `tabs.<id>.title`, `sheets.<id>.title`, `panels.<id>.title`, `commands.<id>.title`,
  `settings.<key>.title`, `settings.<key>.help`, `settings.<key>.options`(옵션마다 라벨 하나, 같은 순서로. 저장되는
  값은 여전히 원래 옵션이에요)를 번역할 수 있어요.
- `strings`는 플러그인 자체 카탈로그예요. 키는 적힌 그대로의 영어이고, 텍스트는 `%@`, 정수는 `%lld`로 표시해요.
  값은 한국어이거나, 영어 복수형이 필요하면 `{"en": {"one": "…", "other": "…"}, "ko": "…"}`예요.

```json
"locales": { "ko": { "name": "단어 수", "sheets.count.title": "단어 수" } },
"strings": {
    "%lld words": { "en": { "one": "%lld word", "other": "%lld words" }, "ko": "%lld단어" },
    "No note on screen": "화면에 노트가 없어요"
}
```

페이지가 `aide.t("%lld words", 3)`를 호출하면 `3 words`나 `3단어`를 받아요. 언어 기능 이전의 앱에는
`aide.locale`도 `aide.t`도 없으니, 키의 영어를 채워 넣는 대체 함수를 두세요.

```js
const t = (key, ...args) => {
    if (typeof aide.t === "function") return aide.t(key, ...args);
    let next = 0;
    return key.replace(/%(?:(\d+)\$)?(?:@|lld)|%%/g, (spec, position) =>
        spec === "%%" ? "%" : String(args[position ? position - 1 : next++]),
    );
};
```

화면에 보이는 것만 번역하세요. 플러그인이 노트에 쓰는 내용과 나중에 다시 읽는 내용은 그대로 두세요. 매니페스트에
없는 경로, 키와 자리표시자가 다른 번역, 500개(64 KB)가 넘는 문자열이 있으면 패키지가 유효하지 않아요.

## 플러그인 키트

모든 페이지는 앱 자체 구성 요소를 불러올 수 있어요. 앱 디자인대로 라이트·다크 모드와 플랫폼별로 그려져요.
플러그인 자체 출처 아래에서 제공되므로 패키지에 아무것도 복사하지 않아도 돼요(그리고 패키지 파일은 이 이름을 쓸
수 없어요).

```html
<link rel="stylesheet" href="aide-kit.css" />
<script src="aide-kit.js"></script>
```

`aideKit.mount(root)`는 요소를 키트 표면으로 만들고 비워요. 그다음 아래 함수로 요소를 만들어요. 모두 텍스트만
받고 HTML은 받지 않아요.

| 함수                                       | 만드는 것                                                                     |
| ------------------------------------------ | ----------------------------------------------------------------------------- |
| `header({title?, meta?, actions?})`        | 페이지 제목과 메타 줄. 탭은 위에 이미 제목이 있으니 `meta`만 넘기세요          |
| `section({label?, children})`              | 라벨이 붙은 그룹                                                              |
| `list(rows)`                               | `{title, meta?, trailing?, onSelect?}` 행 목록. `onSelect`가 있는 행은 버튼이에요 |
| `button({title, style?, onClick, disabled?})` | 버튼. `style`은 `prominent` 또는 `destructive`                             |
| `stats(items)`                             | 나란히 놓인 수치 `{value, label}`                                             |
| `progress({value, total})`                 | 진행 막대                                                                     |
| `banner({text, tone?, action?})`           | 상태 줄. `tone: "danger"`면 경고가 돼요                                       |
| `empty({title, message?, action?})`        | 빈 상태                                                                       |
| `field({label, help?, control})`, `input({…})`, `check({…})`, `select({…})` | 폼 컨트롤                         |
| `card(…)`, `grades(…)`, `review(root, …)`  | Recall이 쓰는 플래시카드와 복습 화면 전체                                     |

앱은 직접 CSS를 쓸 수 있도록 `<html>`에 `data-aide-platform`(`ios`, `mac`, `linux`)과
`data-aide-scheme`(`light`, `dark`, 앱을 따라요)도 붙여요. `aideKit.version`은 `1`이고, 추가로만 늘어나요.

## 네이티브 플러그인

`"render": "native"`이면 `main.js`가 앱 자체 컨트롤로 그려요. `aide.render(tree)`가 화면을 교체하고,
`aide.onAction = (action, value) => …`가 컨트롤 이벤트를 받아요. 노드는 `{type, key?, children?, …}`예요.

| 타입                                  | 필드                                                                   |
| ------------------------------------- | ---------------------------------------------------------------------- |
| `VStack`, `HStack`, `List`, `Section` | `children`. `Section`은 `title`을 받아요                               |
| `Text`                                | `text`, `style`: `largeTitle`, `title`, `headline`, `caption`, `mono`  |
| `Markdown`                            | `text`(인라인 Markdown)                                                |
| `Button`                              | `title`, `action`, `style`: `prominent`, `destructive`                 |
| `Toggle`                              | `title`, `value`(bool), `action`: 값은 새 bool                         |
| `TextField`                           | `placeholder`, `action`: 값은 제출된 텍스트                            |
| `Progress`                            | `title?`, `value`, `total`                                             |
| `Image`                               | `text`: 아이콘 이름                                                    |
| `Divider`, `Spacer`                   | —                                                                      |

트리는 깊이 32, 노드 2,000개로 제한돼요. Pomodoro 플러그인이 네이티브 플러그인이에요.

## 제한

- 5초 동안 응답하지 않는 페이지는 멈추고, 탭에 **다시 시작**이 나와요.
- 예약 실행이나 명령은 60초 뒤에 끝나요.
- 동시에 진행 중인 호출은 최대 8개, `net.fetch` 응답은 1 MB까지예요.
- `storage`는 기기마다 플러그인당 512 KB이고, 기기 사이에 동기화되지 않아요.
- 플러그인을 끄거나, 업데이트하거나, 삭제하면 아직 실행 중인 부분의 호출이 끊겨요.
- 플러그인 페이지는 웹 인스펙터로 열 수 없어요. 개발하는 동안에는 오류를 페이지 자체에 표시하세요(아래 예제는
  상태 줄에 써요).

## 전체 예제

이 플러그인은 열린 할 일이 몇 개인지 보여 주고 오늘의 데일리 노트에 할 일을 추가하는 탭을 더해요. 플러그인 키트,
권한 두 개, 한국어 번역을 써요.

`manifest.json`:

```json
{
    "id": "quick-todo",
    "name": "Quick todo",
    "version": "1.0.0",
    "description": "Shows how many todos are open and adds one to today's note.",
    "author": "you",
    "render": "web",
    "tabs": [{ "id": "main", "title": "Quick todo", "icon": "checklist" }],
    "capabilities": ["todos:read", "todos:write"],
    "locales": {
        "ko": { "name": "빠른 할 일", "description": "열린 할 일 수를 보여 주고 오늘 노트에 할 일을 추가해요.", "tabs.main.title": "빠른 할 일" }
    },
    "strings": {
        "%lld open": "%lld개 열림",
        "Open todos": "열린 할 일",
        "Add to today": "오늘에 추가",
        "Something to do": "할 일",
        "Added to %@": "%@에 추가했어요"
    }
}
```

`index.html`:

```html
<!doctype html>
<html>
    <head>
        <meta charset="utf-8" />
        <meta name="viewport" content="width=device-width, initial-scale=1" />
        <link rel="stylesheet" href="aide-kit.css" />
    </head>
    <body>
        <div id="root"></div>
        <script src="aide-kit.js"></script>
        <script src="main.js"></script>
    </body>
</html>
```

`main.js`:

```js
const t = (key, ...args) => {
    if (typeof aide.t === "function") return aide.t(key, ...args);
    let next = 0;
    return key.replace(/%(?:(\d+)\$)?(?:@|lld)|%%/g, (spec, position) =>
        spec === "%%" ? "%" : String(args[position ? position - 1 : next++]),
    );
};

const root = aideKit.mount(document.getElementById("root"));
const meta = document.createElement("p");
const text = aideKit.input({ placeholder: t("Something to do") });
const status = document.createElement("p");
status.setAttribute("role", "status");

const refresh = async () => {
    try {
        const todos = await aide.call("todos.list");
        meta.textContent = t("%lld open", todos.length);
    } catch (error) {
        status.textContent = String(error);
    }
};

const add = async () => {
    const value = text.value.trim();
    if (!value) return;
    try {
        const added = await aide.call("todos.add", { text: value, target: "today" });
        text.value = "";
        status.textContent = t("Added to %@", added.path);
        await refresh();
    } catch (error) {
        status.textContent = String(error);
    }
};

root.append(
    aideKit.section({
        label: t("Open todos"),
        children: [meta, text, aideKit.button({ title: t("Add to today"), style: "prominent", onClick: add }), status],
    }),
);
text.addEventListener("keydown", (event) => {
    if (event.key === "Enter") add();
});
// 다른 곳에서 노트를 편집하고 탭으로 돌아오면 다시 세요.
document.addEventListener("visibilitychange", () => {
    if (!document.hidden) refresh();
});
refresh();
```

## 로컬에서 테스트하기

**URL로 추가**는 이 컴퓨터(`localhost`, `127.0.0.1`, `::1`)에 한해 `http://`를 받아요. 그래서 Mac이나 Linux에서는
로컬 웹 서버에서 바로 설치할 수 있어요. 그 밖의 곳에서는 패키지를 HTTPS로 제공해야 해요.

<Steps>

1. 플러그인 폴더를 서버로 띄워요.

    ```sh
    cd quick-todo
    python3 -m http.server 8000 --bind 127.0.0.1
    ```

2. AIDE에서 **설정 › 커뮤니티 플러그인 › URL로 추가**를 열어요.

3. `http://127.0.0.1:8000/`(`manifest.json`과 `main.js`가 든 폴더)을 입력하고 **가져오기**를 선택해요.

4. 무엇을 요청하는지 확인하고, 권한을 켠 다음 **설치**를 선택해요. 사이드바에 탭이 나타나요.

5. 파일을 바꾼 뒤에는 같은 URL로 다시 추가해요. 같은 id면 설치된 플러그인이 업데이트되고, 이전 버전은 플러그인
   상세 화면의 **이전 버전으로 돌아가기**로 남아 있어요.

</Steps>

URL로 설치한 플러그인은 어떤 인덱스와도 대조하지 않아요. 그래서 설치 화면이 믿을 수 있는 것만 설치하라고 알려
줘요. iPhone에서 써 보려면 휴대폰이 접근할 수 있는 HTTPS 서버에 폴더를 올리세요.

## 배포하기

### 직접 호스팅하기

폴더를 아무 정적 HTTPS 호스트(GitHub Pages, 버킷, 직접 운영하는 서버)에 올리고 폴더 URL을 공유하세요. 누구나
**URL로 추가**로 설치할 수 있어요.

### 비공개 인덱스

인덱스는 패키지와 그 모든 파일의 SHA-256을 나열한 JSON 파일이에요. 그래서 설치되는 것은 나열된 것과 정확히
같아요. 앱은 인덱스의 플러그인을 **커뮤니티 플러그인 둘러보기**에 보여 주고, 설치 전에 모든 파일을 인덱스와 대조해요.
형태는 이래요.

```json
{
    "plugins": [
        {
            "id": "quick-todo",
            "name": "Quick todo",
            "description": "Shows how many todos are open and adds one to today's note.",
            "version": "1.0.0",
            "author": "you",
            "url": "https://example.com/aide-plugins/quick-todo/",
            "files": { "main.js": "<sha256>", "index.html": "<sha256>", "manifest.json": "<sha256>" },
            "hash": "<bundle hash>",
            "capabilities": ["todos:read", "todos:write"]
        }
    ],
    "revoked": []
}
```

- `url`은 패키지 폴더예요. 상대 URL은 인덱스 자체 URL을 기준으로 풀어요. `https`만 되고, `localhost`라면 `http`도
  돼요.
- `files`는 각 파일의 SHA-256을 16진수로 나열해요. 항목은 폴더가 제공하는 파일을 정확히 나열해야 해요.
- `hash`는 번들 해시예요. 파일 이름을 정렬한 순서로, 각 이름 뒤에 그 파일의 16진수 해시를 붙여 계산한 SHA-256이에요.
- `revoked`는 철회하는 버전(`hash`가 없으면 모든 버전)의 `{id, hash?, reason}` 항목을 나열해요. 앱은 다음에
  인덱스를 읽을 때 그 버전을 꺼요. 비어 있더라도 목록은 남겨 두세요.

이 스크립트는 옆에 있는 모든 패키지 폴더로 그런 인덱스를 써요.

```python
#!/usr/bin/env python3
# 사용법: build-index.py https://example.com/aide-plugins/   (plugins.json을 써요)
import hashlib, json, sys
from pathlib import Path

base = sys.argv[1].rstrip("/") + "/"
names = ["manifest.json", "main.js", "index.html", "styles.css"]
plugins = []
for folder in sorted(p for p in Path(".").iterdir() if (p / "manifest.json").is_file()):
    files = {n: (folder / n).read_bytes() for n in names if (folder / n).is_file()}
    hashes = {n: hashlib.sha256(d).hexdigest() for n, d in files.items()}
    bundle = hashlib.sha256()
    for n in sorted(files):
        bundle.update(n.encode())
        bundle.update(hashes[n].encode())
    m = json.loads(files["manifest.json"])
    entry = {"id": m["id"], "name": m["name"], "description": m.get("description", ""),
             "version": m["version"], "url": f"{base}{folder.name}/", "files": hashes,
             "hash": bundle.hexdigest(), "capabilities": m.get("capabilities", [])}
    if m.get("author"):
        entry["author"] = m["author"]
    plugins.append(entry)
Path("plugins.json").write_text(json.dumps({"plugins": plugins, "revoked": []}, indent=2, ensure_ascii=False) + "\n")
```

`plugins.json`을 폴더와 함께 올린 다음, AIDE가 그걸 보게 하세요.

- **서버 없이**: **설정 › 커뮤니티 플러그인 › 커뮤니티 플러그인 둘러보기 › 인덱스**에 인덱스 URL을 입력해요. 비워 두면 공개
  인덱스로 돌아가요.
- **서버와 함께**: 서버가 `plugins.indexURL` 설정에 있는 인덱스를 모든 기기를 대신해 가져와요.

### 공개 인덱스

공개 인덱스는 [github.com/marshallku/aide-plugins](https://github.com/marshallku/aide-plugins)이고,
앱의 기본값인 `https://marshallku.github.io/aide-plugins/plugins.json`에서 제공돼요. 누구나 플러그인을 제출할 수
있고, 모든 버전은 목록에 오르기 전에 심사를 거쳐요.

<Steps>

1. GitHub에 패키지를 릴리스해요. `manifest.json`, `main.js`, 그리고 있다면 `index.html`과 `styles.css`를
   릴리스의 에셋으로 올려요. 버전은 `1.2.3`이나 `1.2.3-beta.1` 형태여야 해요.

2. 인덱스 저장소의 검사 도구로 번들 해시를 구해요. 앱과 같은 규칙을 적용해요.

    ```sh
    git clone https://github.com/marshallku/aide-plugins
    cd aide-plugins/tools/check
    go build -o aide-plugin-check .
    ./aide-plugin-check --publish <folder with the release assets>
    ```

3. `submissions/<id>/<version>.json`을 추가하는 풀 리퀘스트를 열어요.

    ```json
    { "repo": "you/your-plugin", "tag": "v1.0.0", "hash": "<hash from step 2>" }
    ```

</Steps>

인덱스의 CI가 릴리스를 내려받아 검사하고, 배포된 그대로의 파일과 지난 버전 이후 바뀐 권한을 담은 보고서를
써요. 그걸 메인테이너가 심사해요. 병합되면 파일이 인덱스 저장소로 복사되고 목록에 올라요. 심사에서는 읽을 수
있는 코드(압축하거나 난독화하지 않은 코드), 일에 필요한 최소한의 권한, `net:` 호스트마다의 이유, 설명대로
동작하는지를 봐요. id는 처음 배포한 저장소의 것이고, 배포된 버전은 절대 바뀌지 않아요. 잘못된 릴리스는 새 버전으로
고치세요.

<Aside>
해로운 것으로 밝혀진 플러그인은 인덱스의 철회 목록에 추가되고, 앱은 다음에 인덱스를 읽을 때 그 플러그인을 꺼요.
인덱스 저장소에 이슈를 열어 신고하세요.
</Aside>
