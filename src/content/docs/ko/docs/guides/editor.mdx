AIDE의 노트는 모두 Markdown 파일이고, iPhone, Mac, Linux에서 똑같은 실시간 미리보기 편집기 하나로 편집해요. 입력한 내용은 평범한 Markdown 그대로 남아요. 편집기는 스타일만 입히고, 커서가 없는 줄의 문법 기호를 숨길 뿐이에요.

## 쓰기

따로 읽기 모드가 없어요. 노트는 항상 편집기로 열려요. 제목, 굵은 글씨, 링크, 이미지는 렌더링된 모습으로 보이고, 커서가 있는 줄은 원래 Markdown을 보여 줘서 바로 고칠 수 있어요. 체크박스를 클릭하면 그 자리에서 할 일이 체크되거나 풀려요.

입력하는 동안 편집기 아래에 도구 막대가 있어요. **Indent**, **Outdent**, **To-do**, **Commands**(슬래시 메뉴), **Link to note**, **Heading**(없음 → `#` → `##` → `###` 순서로 바뀌어요), **Table**, **Photo**, **Undo**, **Redo**가 있어요. 표 안에서는 표 작업으로 바뀌어요.

### 슬래시 명령

줄 맨 앞이나 공백 뒤에서 `/`를 입력하면 명령 메뉴가 열리고, 이어서 입력하면 걸러져요.

| 명령 | 넣는 내용 |
| --- | --- |
| Heading 1 · 제목1, Heading 2 · 제목2, Heading 3 · 제목3 | `#`, `##`, `###` |
| To-do · 할 일 | `- [ ] ` |
| Bullet list · 목록, Numbered list · 번호 | `- `, `1. ` |
| Quote · 인용 | `> ` |
| Callout note · 노트, Callout tip · 팁, Callout warning · 주의 | `> [!note]`, `> [!tip]`, `> [!warning]` |
| Code block · 코드 | 펜스 코드 블록 |
| Table · 표 | 크기 선택기, 그다음 표 |
| Divider · 구분선 | `---` |
| Today · 오늘 | 오늘 날짜, `YYYY-MM-DD` |
| Link to note · 노트 링크 | 노트 목록이 열린 `[[]]` |

메뉴에는 항목마다 한국어 이름도 함께 있어서, `/할 일`로 **To-do**를 찾을 수 있어요.

### 콜아웃

첫 줄이 `> [!kind]`인 인용은 아이콘이 있는 콜아웃으로 그려져요. AIDE는 `note`, `info`, `tip`, `success`, `warning`, `caution`, `danger`, `error`, `question`, `quote`, `todo`, `example`, `bug`에 각각 다른 아이콘을 그리고, 그 밖의 종류에는 info 아이콘을 써요. 첫 줄에서 `[!kind]` 뒤의 텍스트가 콜아웃의 제목이에요.

```markdown
> [!warning] Before you deploy
> Run the migrations first.
```

### 프런트매터 속성

노트 맨 위의 YAML 블록은 키와 값 줄로 된 **Properties** 패널로 보여요. 클릭하면 YAML 원문을 편집할 수 있어요. AIDE가 직접 읽는 키는 몇 가지예요.

- `title`: 노트 제목. 없으면 첫 번째 제목, 그다음 첫 번째 텍스트 줄, 그다음 파일 이름이 제목이 돼요.
- `aliases`(또는 `alias`): `[[link]]`가 노트를 찾을 때 쓸 수 있는 다른 이름.
- `tags`: 본문의 `#tags`와 함께 쓰이는 노트의 태그.
- `summary`: 위키 목록에서 노트 제목 아래에 보이는 한 줄.
- `stage`: `seedling`, `budding`, `evergreen` 중 하나면 위키 목록에서 제목 옆에 성장 단계 아이콘이 붙어요.

### 표

표는 바로 입력하는 격자예요. 칸마다 자기 입력란이 있고 Markdown 행에서 자기 부분만 고치므로, 표의 나머지는 원래 텍스트 그대로 남아요. 오른쪽과 아래 가장자리의 <strong>+</strong>로 열이나 행을 추가해요. 선택한 칸의 **⋯** 메뉴에는 **Insert row above**, **Insert row below**, **Insert column left**, **Insert column right**, **Delete row**, **Delete column**, **Align left**, **Align center**, **Align right**, **Edit as markdown**이 있어요. **Edit as markdown**은 커서가 떠날 때까지 그 표 하나를 텍스트로 보여 줘요.

표를 만들려면 `/table`을 입력하거나 도구 막대의 표 버튼을 누른 뒤, 크기 격자(최대 8 × 8) 위로 움직여 클릭하세요. 화살표 키와 <kbd>Return</kbd>도 돼요. 첫 행이 머리글이에요. <kbd>Tab</kbd>은 다음 칸으로 이동해요.

인용이나 목록 안의 표는 평범한 텍스트로 남아요.

## 링크

AIDE는 Obsidian이 쓰는 두 가지 링크를 모두 읽어요.

- `[[Note]]`는 파일 이름, 그다음 제목, 그다음 프런트매터 별칭으로 노트를 찾아요. `[[folder/Note]]`는 경로를 지정해요.
- `[[Note|shown text]]`는 `|` 뒤의 텍스트를 보여 줘요.
- `[[Note#Heading]]`은 그 제목까지 스크롤한 노트를, `[[Note#^block-id]]`는 그 블록까지 스크롤한 노트를 열고, `[[#Heading]]`은 지금 노트 안에서 이동해요.
- `[text](other-note.md)`는 노트 폴더를 기준으로 한 일반 Markdown 링크예요. 뒤에 붙는 `#Some%20Heading`도 같은 식으로 동작해요.
- `[[2026-10-22]]`나 일일 노트 형식이 만드는 경로로 가는 링크는 그날의 일일 노트를 열고, 아직 없으면 템플릿으로 만들어요.

`[[`를 입력하면 입력한 내용에 맞춰 순위가 매겨진 노트 목록이 열려요. 하나를 고르면 링크가 들어가요. `[text](`를 입력하면 같은 목록이 나오고 노트의 상대 경로가 들어가요. 목록에는 노트만 나와요. `#Heading`이나 `#^block` 부분은 직접 입력하세요.

렌더링된 링크를 클릭하면 따라가요. 데스크톱에서는 <kbd>⌘</kbd>-클릭(Linux에서는 <kbd>Ctrl</kbd>-클릭)이나 가운데 버튼 클릭으로 새 탭에서 열어요. 커서가 있는 줄에서는 링크가 원래 텍스트로 보이고, 클릭하면 커서만 놓여요.

링크를 바로 따라갈 수 없으면 AIDE가 물어봐요.

- <strong>어떤 노트인가요?</strong>는 이름이 같은 노트가 여럿일 때, 링크와 맞는 모든 노트의 경로를 보여 줘요.
- 맞는 노트가 없으면 **`<file>`에 노트가 없어요**가 나와요. **노트 만들기**는 Obsidian이 만들 위치(보관소 최상위나 링크에 적힌 경로)에 링크 이름을 제목으로 노트를 만들고 열어요.

웹 링크(`https://…`)는 브라우저에서 열려요. 다른 스킴(`mailto:`, `file:`)은 아무 일도 하지 않아요.

## 이미지와 임베드

임베드는 노트 안에 파일을 보여 주는 것으로, `![alt](path)`나 Obsidian의 `![[name]]`으로 써요. `![[name|300]]`에서 `|` 뒤의 내용은 무시돼요. 이미지는 항상 텍스트 너비와 창 높이의 60%를 넘지 않게 그려져요.

| 파일 | 보이는 방식 |
| --- | --- |
| `jpg` `jpeg` `png` `gif` `webp` `heic` `heif` | 이미지 |
| `svg` | 이미지. 안의 스크립트는 실행되지 않고 아무것도 불러오지 않아요 |
| `html` `htm` | 줄 아래의 샌드박스 프레임 |

첨부 파일은 하나에 최대 20MB이고, 내용이 확장자와 맞아야 해요. `.jpg`로 이름만 바꾼 PNG는 보이지 않아요. 이미지는 `https://` URL이어도 돼요.

`![[name]]`은 그 경로, 그다음 `attachments/` 아래, 그다음 보관소 어디든 그 이름의 파일을 찾아요. `![](path)`는 노트 폴더 기준, 그다음 보관소 최상위 기준이에요. 파일이 아니라 노트를 가리키는 `![[Some note]]`는 그 노트로 가는 링크로 보여요. AIDE는 노트 안에 다른 노트를 그리지 않아요.

### 사진 추가하기

편집기 도구 막대의 **Photo**를 누르고 이미지를 고르세요. AIDE는 긴 변이 최대 2560픽셀인 JPEG로 다시 인코딩하고(이때 위치 같은 카메라 메타데이터도 빠져요), 새 이름으로 `attachments/` 아래에 저장한 뒤 커서 위치에 `![](attachments/…)`를 넣어요. GIF는 계속 움직이도록 그대로 둬요.

SVG와 HTML 파일은 사진 선택기로 추가하지 않아요. 보관소 폴더에 직접 넣고 링크하세요.

### 그림

[Excalidraw 플러그인](/ko/docs/plugins/excalidraw/)으로 만든 그림은 `.excalidraw.svg`로 끝나는 SVG 파일이고, 그림 데이터가 파일 안에 들어 있어요. 그래서 플러그인을 설치했든 안 했든 모든 기기에서 이미지로 보여요. 플러그인이 있으면 임베드된 그림에 **편집** 버튼이 생겨 다시 열 수 있어요.

### HTML 문서

임베드된 HTML 파일은 텍스트 너비의 자기 프레임 안에서 실행돼요.

- 스크립트는 실행되지만, 노트나 앱, 다른 임베드에 접근할 수 없는 샌드박스 안에서예요. 네트워크에 닿거나, 다른 페이지를 열거나, 폼을 제출하거나, 팝업을 열 수 없어요.
- 보관소에서 옆에 있는 이미지, 스타일, 스크립트, 글꼴은 상대 URL로 불러올 수 있어요.
- 프레임은 문서에 맞춰 높이가 40픽셀에서 6000픽셀 사이로 늘어나요.
- 긴 노트를 가볍게 유지하려고, 프레임은 보고 있는 곳 가까이에 있을 때만 실행되고 한 번에 최대 세 개까지 실행돼요. 멀리 스크롤된 프레임은 문서 이름이 적힌 상자로 바뀌고, 돌아오면 상태를 잃고 다시 시작해요.
- 찾을 수 없는 파일은 이름과 **Not found**를 보여 줘요.

<Aside type="caution" title="Linux">
Linux에서 HTML 임베드는 문서가 안에 직접 담은 것만 보여 줘요. 자체 스타일과 스크립트, `data:` 이미지요. 옆에 있는 파일을 가리켜도 불러오지 않는데, WebKitGTK가 샌드박스 프레임에서 그런 불러오기를 거부하기 때문이에요. Mac과 iPhone에서는 불러와요.
</Aside>

## 탭, 패널, 노트 찾기

<Tabs>
<TabItem label="Mac과 Linux">

노트는 Obsidian처럼 주 영역 위의 탭에서 열려요. 탭마다 노트 제목이 보이고, 노트 하나는 탭 하나에만 있어요. 이미 열린 노트를 열면 그 탭으로 바뀌어요.

- 탭 줄 끝의 <strong>+</strong>는 빈 탭을 열어요. 빈 탭도 이미 편집기예요. "입력하면 스크래치 노트가 돼요."라는 안내가 보이고, 처음 입력한 텍스트가 새 [스크래치 노트](/ko/docs/guides/scratch/)가 돼요.
- 스크래치, 위키, 검색 결과, 할 일, 저널 타일, 캘린더 날짜, 그래프 점, 링크에서 노트를 <kbd>⌘</kbd>-클릭하거나 가운데 버튼으로 클릭하면 새 탭에서 열려요. 위키 줄의 메뉴에도 **새 탭에서 열기**가 있어요.
- **새 탭에서 노트 열기**(Mac은 **설정 › 화면 스타일 › 창**, Linux는 **설정 › 일반 › 창**, 기본값은 꺼짐)를 켜면 그 줄들, 캘린더, 그래프를 그냥 클릭해도 새 탭이 열려요. 노트 안의 링크는 항상 그 탭에서 열려요.
- <kbd>⌃</kbd><kbd>Tab</kbd>과 <kbd>⌃</kbd><kbd>⇧</kbd><kbd>Tab</kbd>으로 탭을 차례로 옮기고, <kbd>⌘</kbd><kbd>W</kbd>(<kbd>Ctrl</kbd><kbd>W</kbd>)로 탭을 닫아요. 마지막 탭을 닫으면 빈 탭이 남아요.
- 뒤로와 앞으로(<kbd>⌘</kbd><kbd>[</kbd>와 <kbd>⌘</kbd><kbd>]</kbd>, Linux에서는 <kbd>Alt</kbd><kbd>←</kbd>와 <kbd>Alt</kbd><kbd>→</kbd>, 또는 마우스의 뒤로·앞으로 버튼)는 창이 보여 준 모든 것을 하나의 기록으로 오가요. 어느 탭의 노트든, 할 일, 그래프, 회고, 플러그인 탭이든요.

오른쪽 패널(Mac은 <kbd>⌥</kbd><kbd>⌘</kbd><kbd>\\</kbd>, Linux는 <kbd>Ctrl</kbd><kbd>Alt</kbd><kbd>\\</kbd>)에는 열린 노트 제목들의 **개요**가 있어요. 하나를 클릭하면 그곳으로 이동해요.

</TabItem>
<TabItem label="iPhone">

iPhone은 한 번에 노트 하나를 보여 주고, 노트를 연 목록 위로 쌓여요. 위키에는 열었던 노트의 **최근 항목** 목록이 있어요. 줄을 쓸어 넘겨 **최근 항목에서 제거**할 수 있어요. 노트 막대의 **Find**는 찾기 막대를 열어요.

</TabItem>

명령 팔레트에는 **새 페이지…**, **스크래치 노트 정리…**, 켜 둔 주기마다 이번 주·이번 달·이번 분기·올해의 노트, **이 노트 링크 복사**(`aide://note/…` 링크), **이 노트 고정**이나 **이 노트 고정 해제**, **다른 탭 닫기**, 각 섹션, **설정**, 기기 플러그인의 명령도 있어요. 전체 목록은 [키보드 단축키](/ko/docs/guides/shortcuts/)를 보세요.

## 저장과 충돌

AIDE는 입력하는 대로 저장해요. 노트 막대의 상태는 **저장됨**, **저장 중**, **오프라인**, **충돌**, **오류** 중 하나예요. 저장될 때까지 텍스트는 기기의 임시 저장본에도 남아 있어서, 앱을 종료하거나 연결이 끊겨도 잃지 않아요. 빈 탭에 입력했는데 아직 노트가 되지 못한 텍스트는 스크래치의 **미전송** 아래에서 기다려요.

저장할 때마다 어느 버전을 바탕으로 했는지 함께 알려요. 그사이 노트가 다른 곳(다른 기기, 어시스턴트, 플러그인)에서 바뀌었다면, 그 변경을 덮어쓰지 않고 저장을 거부하며 노트 위에 배너가 나타나요.

> 이 노트가 다른 곳에서 변경됐어요. 작성한 내용은 이 기기에 보관했어요.

- **내 내용 유지**는 내 텍스트를 최신 버전으로 저장하고 다른 변경을 대신해요.
- **저장된 버전 사용**은 내 텍스트를 버리고 지금 상태의 노트를 보여 줘요.

다른 탭에 저장하지 않은 내용 없이 열려 있는 노트가 다른 곳에서 바뀌면, 편집기는 그냥 새 텍스트를 받아들여요.

다른 앱도 편집하는 폴더(예를 들어 Obsidian 보관소)에서 AIDE는 자기가 만들지 않은 변경을 절대 덮어쓰지 않아요. AIDE가 저장하는 순간 다른 앱이 파일을 쓰면, 다른 앱의 텍스트는 `conflicts/` 아래에 노트 이름에 `-external-`가 붙은 별도 노트로 보관돼요. [보관소와 파일](/ko/docs/guides/vaults/)을 보세요.
