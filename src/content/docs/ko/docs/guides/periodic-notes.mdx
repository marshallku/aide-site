주기 노트는 하루, 한 주, 한 달, 한 분기, 한 해마다 하나씩 있는 노트로, 처음 열 때 템플릿으로 만들어져요. AIDE는 그날의 할 일, 캘린더 일정, 플러그인이 그날에 대해 쓴 내용을 여기에 넣어요.

## 열기

- **오늘**은 오늘의 일일 노트를 열어요. Mac에서는 <kbd>⌘</kbd><kbd>T</kbd>, Linux에서는 <kbd>Ctrl</kbd><kbd>T</kbd>, 또는 위키의 **오늘** 타일이에요.
- 위키의 **저널** 섹션에는 켜 둔 주기마다 타일이 있어요. **오늘**, **이번 주**, **이번 달**, **분기**, **올해**예요. 제목 옆의 **캘린더**는 주 번호가 있는 월 달력을 보여 줘요. 날짜, 주, 달을 클릭하면 그 노트가 열려요.
- 명령 팔레트에는 이번 주, 이번 달, 이번 분기, 올해의 노트가 있어요.
- `[[2026-10-23]]`처럼 아직 없는 주기 노트로 가는 링크를 따라가면 노트가 만들어져요.
- `aide://today`는 앱 밖에서 오늘의 노트를 열고, `aidectl daily`는 명령줄에서 노트를 출력하거나 만들어요([aidectl](/ko/docs/developers/aidectl/) 참고).

노트는 열 때만 만들어져요(또는 아침 브리핑 같은 플러그인이 오늘 노트를 만들 때). 저녁 정리는 노트를 만들지 않아요.

## 설정 › 위키

**설정 › 위키**에서 주기마다 노트가 있을 곳과 이름을 정해요. 주기마다 **활성화됨**, **폴더**, **형식**, **템플릿**이 있고, **지금**은 그 형식으로 오늘 만들어질 경로를 보여 줘서 저장하기 전에 형식을 확인할 수 있어요.

| 주기 | 기본으로 켜짐 | 폴더 | 형식 | 예시 경로 | 템플릿 |
| --- | --- | --- | --- | --- | --- |
| 일간 | 예 | `daily` | `YYYY-MM-DD` | `daily/2026-10-22.md` | `templates/daily` |
| 주간 | 예 | `weekly` | `GGGG-[W]WW` | `weekly/2026-W43.md` | `templates/weekly` |
| 월간 | 예 | `monthly` | `YYYY-MM` | `monthly/2026-10.md` | `templates/monthly` |
| 분기 | 아니요 | `quarterly` | `YYYY-[Q]Q` | `quarterly/2026-Q4.md` | `templates/quarterly` |
| 연간 | 아니요 | `yearly` | `YYYY` | `yearly/2026.md` | `templates/yearly` |

형식은 Obsidian처럼 moment.js 토큰을 써요.

| 토큰 | 뜻 |
| --- | --- |
| `YYYY` | 연도 |
| `Q` | 분기 |
| `MM` `M` | 월, 앞자리 0이 있거나 없음 |
| `MMM` `MMMM` | `Oct`, `October` |
| `DD` `D` `Do` | 날짜(`Do`는 `1st`, `2nd` …) |
| `dddd` `ddd` | 요일 이름, 표시용으로만 |
| `GGGG` `WW` `W` | ISO 주 기준 연도와 주 |
| `gggg` `ww` `w` | 한 주의 시작 설정에 따른 주 기준 연도와 주 |
| `[text]` | 글자 그대로의 텍스트 |

형식 안의 `/`는 폴더를 만들어요. 형식에는 공백과 문장 부호를 써도 되지만(`YYYY-MM-DD dddd`, `dddd, MMMM Do YYYY`), `\ : * ? " < > |`는 쓸 수 없어요. 폴더에는 `Daily Notes`처럼 공백과 대문자를 써도 돼요.

**캘린더**에는 모든 주기가 함께 쓰는 설정이 두 가지 있어요.

- **한 주의 시작**: 기본값인 **월요일(ISO 주)** 또는 **일요일**(1월 1일이 있는 주가 첫 주예요).
- **시간대**: `Asia/Seoul` 같은 IANA 이름. 노트와 완료 표시에서 "오늘"이 언제인지 정해요. 비워 두면 서버의 시간대, 로컬 보관소에서는 기기의 시간대를 써요.

형식을 바꿔도 기존 노트는 그 자리에 있고, 계속 그 주기의 노트로 남아요. 이름을 바꾸려면 새 형식을 먼저 저장한 뒤 <strong>기존 노트를 이 형식으로 이동…</strong>을 누르세요. 옮겨질 목록과 링크가 바뀔 노트 수를 보여 주고, **이동**을 누르기 전에는 아무것도 옮기지 않아요. 새 경로가 이미 쓰이고 있는 노트는 그대로 있어요.

로컬 보관소에서는 이 설정이 보관소 폴더 안에 저장돼서 폴더와 함께 다녀요. 서버를 쓰면 서버에 저장되고 모든 기기가 같은 설정을 써요.

## 템플릿

템플릿은 평범한 노트로, 기본값은 `templates/daily`예요. 주기의 템플릿 노트가 없으면 AIDE에 들어 있는 템플릿을 써요. 기본 일일 템플릿은 이래요.

```markdown
# {{date}}

## Todo

## Notes
```

기본 주간 템플릿은 그 달과 그 주의 날마다 링크를 걸고, 월간·분기·연간 템플릿은 안에 든 더 짧은 주기의 노트를 나열해요. 각각에는 [회고](/ko/docs/guides/search-graph-review/)가 보여 주는 `## Summary` 제목이 있어요.

### 변수

변수 이름은 대소문자를 가리지 않고, 중괄호 안에 공백이 있어도 돼요(`{{ Date }}`). 모르는 변수는 적힌 그대로 남아요.

| 변수 | 결과 |
| --- | --- |
| `{{date}}` | 그 주기의 첫날, `2026-10-22` |
| `{{title}}` | 새 노트의 파일 이름 |
| `{{time}}` | 노트를 만든 시각, `HH:mm` |
| `{{date:FORMAT}}`, `{{time:FORMAT}}` | moment.js 형식으로 쓴 노트의 날짜. 예: `{{date:dddd, MMMM Do}}` |
| `{{date+1d}}`, `{{date-2w:YYYY-MM-DD}}`, `{{time+30m:HH:mm}}` | `y` 년, `Q` 분기, `M` 월, `w` 주, `d` 일, `h` 시간, `m` 분, `s` 초만큼 옮긴 날짜나 시각 |
| `{{yesterday}}`, `{{tomorrow}}` | 일일 노트에서, 일일 형식으로 쓴 전날과 다음 날의 노트 이름. 그래서 `[[{{yesterday}}]]`로 링크할 수 있어요 |
| `{{monday:FORMAT}}` … `{{sunday:FORMAT}}` | 주간 노트에서, 그 주의 해당 요일 |
| `{{week}}` | ISO 주, `2026-W43` |
| `{{month}}` | `2026-10` |
| `{{quarter}}` | `2026-Q4` |
| `{{year}}` | `2026` |
| `{{mon}}` … `{{sun}}` | 그 ISO 주의 날짜들 |
| `{{prev}}`, `{{next}}` | 같은 주기의 이전·다음 노트로 가는 상대 링크 |
| `{{parent}}` | 이 노트를 포함하는 더 긴 주기의 노트로 가는 상대 링크(날의 주, 주의 달) |
| `{{mon-link}}` … `{{sun-link}}` | 그 주의 일일 노트로 가는 상대 링크 |
| `{{children}}` | 이 노트 안에 든 더 짧은 주기 노트의 링크 목록 |
| `{{day}}` | 한 글자짜리 한국어 요일(`월`, `화` …) |

링크 변수는 경로만 줘서, `[Last week]({{prev}})` 같은 Markdown 링크에 써요. 가리키는 주기가 꺼져 있으면 링크 변수는 비어 있어요.

<Aside type="tip">
영어 요일 이름이 필요하면 `{{day}}` 대신 `{{date:dddd}}`를 쓰세요.
</Aside>

월, 분기, 연도를 옮길 때는 날짜가 그 달 안에 머물러요(1월 31일에 한 달을 더하면 2월 28일). 템플릿 전체는 내 시간대의 한 시점을 기준으로 해요.

## 슬롯

템플릿의 `{{slot plugin.name}}` 줄은 새 노트에서 플러그인이 관리하고 나중에 채우는 빈 블록이 돼요. 플러그인은 자기 블록 안의 줄만 다시 쓰고, 그 주변은 모두 내 것이에요. 편집기에서는 블록에 플러그인 이름이 표시돼요.

일일 템플릿에 넣는 슬롯은 두 가지예요.

| 슬롯 | 채우는 내용 |
| --- | --- |
| `{{slot todo-carry.open}}` | **설정 › 할 일**의 **미완료 할 일 이월**이 **끔**이 아닐 때, 어제의 열린 할 일([할 일](/ko/docs/guides/todos/)과 [할 일 이월](/ko/docs/plugins/todo-carry/) 참고) |
| `{{slot gcal.today}}` | 계속 최신으로 유지되는 오늘의 일정 |

로컬 보관소에서는 앱이 열려 있는 동안 AIDE가 둘 다 직접 채워요. 일정은 이 기기의 캘린더에서 가져와요(Mac과 iPhone에서는 캘린더 탭에서 접근을 허용한 시스템 캘린더, Linux에서는 설정에서 추가한 캘린더). 서버나 [데스크톱 호스트](/ko/docs/self-hosting/desktop-host/)에서는 [할 일 이월](/ko/docs/plugins/todo-carry/)과 [Google 캘린더](/ko/docs/plugins/gcal/) 플러그인이 채우고, 두 플러그인을 켜야 해요.

둘 다 쓰는 일일 템플릿:

```markdown
# {{date:dddd, MMMM Do}}

[[{{yesterday}}]] · [[{{tomorrow}}]]

## Todo
{{slot todo-carry.open}}

## Today
{{slot gcal.today}}

## Notes
```

## 그날의 노트

하루에 대해 쓰는 플러그인([아침 브리핑](/ko/docs/plugins/briefing/), [저녁 정리](/ko/docs/plugins/recap/), [Gmail](/ko/docs/plugins/gmail/)의 메일 요약과 일정 준비)은 `briefings/` 뒤에 날짜가 붙은 별도 노트(`briefings/2026-10-22`)에 써서, 일일 노트는 내 것으로 남아요. 이 플러그인들에는 각각 **note** 설정이 있어요. `{date}`가 들어간 다른 경로를 쓰거나, `daily`로 정해 일일 노트 자체에 관리 블록으로 쓰게 할 수 있어요.

일일 노트에서 그날의 노트로 가려면 일일 템플릿에 링크를 넣으세요. 기본 `daily/` 폴더라면 이렇게요.

```markdown
[Briefing](../briefings/{{date}}.md)
```

## Obsidian에서 옮겨 올 때

Obsidian 보관소를 AIDE에서 처음 열면, AIDE는 Obsidian의 일일 노트 설정(`.obsidian/daily-notes.json`)을 읽고 그 폴더, 형식, 템플릿을 AIDE의 일일 노트에 써요. 그래서 기존 일일 노트를 그대로 알아봐요. Obsidian의 템플릿 변수(`{{title}}`, `{{date:FORMAT}}`, `{{time}}`, 오프셋)와 Periodic Notes의 `{{monday:FORMAT}}`도 AIDE 템플릿에서 동작해요.

이 과정은 AIDE에 그 보관소의 설정이 생기기 전에 한 번만 일어나요. 그 뒤로는 **설정 › 위키**에서만 바꿀 수 있어요. 다른 주기는 AIDE의 기본값을 그대로 써요. Obsidian의 템플릿은 그 경로의 노트가 정확히 하나일 때만 쓰이고, 아니면 일일 노트는 템플릿 없이 만들어져요. Obsidian의 폴더나 형식을 쓸 수 없으면 AIDE는 기본값을 유지하고, 설정의 **확인이 필요한 파일**에서 이유를 알려 줘요. [보관소와 파일](/ko/docs/guides/vaults/)을 보세요.
