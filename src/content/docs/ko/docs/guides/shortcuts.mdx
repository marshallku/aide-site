Mac과 Linux의 AIDE는 같은 단축키를 써요. Linux에서 <kbd>Ctrl</kbd>을 쓰는 자리에 Mac에서는 <kbd>⌘</kbd>를 써요.
Mac에서는 모든 단축키가 메뉴 막대에도 있고, 모든 명령은 단축키와 함께 명령 팔레트에 있어요.

## 창과 이동

| 동작 | Mac | Linux |
|---|---|---|
| 설정 | <kbd>⌘</kbd><kbd>,</kbd> | <kbd>Ctrl</kbd><kbd>,</kbd> |
| 명령 팔레트 | <kbd>⌘</kbd><kbd>P</kbd> | <kbd>Ctrl</kbd><kbd>P</kbd> |
| 빠르게 열기(제목으로, 그다음 본문으로 노트 찾기) | <kbd>⌘</kbd><kbd>O</kbd> | <kbd>Ctrl</kbd><kbd>O</kbd> |
| 노트 검색 | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>F</kbd> | <kbd>Ctrl</kbd><kbd>Shift</kbd><kbd>F</kbd> |
| 노트에서 찾기 | <kbd>⌘</kbd><kbd>F</kbd> | <kbd>Ctrl</kbd><kbd>F</kbd> |
| 새 스크래치 노트 | <kbd>⌘</kbd><kbd>N</kbd> | <kbd>Ctrl</kbd><kbd>N</kbd> |
| 오늘의 데일리 노트 | <kbd>⌘</kbd><kbd>T</kbd> | <kbd>Ctrl</kbd><kbd>T</kbd> |
| 새 창 | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>N</kbd> | — |
| 탭 닫기(마지막 탭이면 빈 탭으로, 빈 마지막 탭이면 Mac에서는 창을 닫아요) | <kbd>⌘</kbd><kbd>W</kbd> | <kbd>Ctrl</kbd><kbd>W</kbd> |
| 다음 탭 | <kbd>⌃</kbd><kbd>Tab</kbd> | <kbd>Ctrl</kbd><kbd>Tab</kbd> 또는 <kbd>Ctrl</kbd><kbd>Page Down</kbd> |
| 이전 탭 | <kbd>⌃</kbd><kbd>⇧</kbd><kbd>Tab</kbd> | <kbd>Ctrl</kbd><kbd>Shift</kbd><kbd>Tab</kbd> 또는 <kbd>Ctrl</kbd><kbd>Page Up</kbd> |
| 뒤로 | <kbd>⌘</kbd><kbd>[</kbd> | <kbd>Alt</kbd><kbd>←</kbd> 또는 <kbd>Ctrl</kbd><kbd>[</kbd> |
| 앞으로 | <kbd>⌘</kbd><kbd>]</kbd> | <kbd>Alt</kbd><kbd>→</kbd> 또는 <kbd>Ctrl</kbd><kbd>]</kbd> |
| 사이드바의 섹션으로 이동 | <kbd>⌘</kbd><kbd>1</kbd>부터 <kbd>⌘</kbd><kbd>9</kbd>까지 | <kbd>Alt</kbd><kbd>1</kbd>부터 <kbd>Alt</kbd><kbd>7</kbd>까지 |
| 패널 보이기/숨기기 | <kbd>⌘</kbd><kbd>\\</kbd> | <kbd>Ctrl</kbd><kbd>\\</kbd> |
| 오른쪽 패널 보이기/숨기기 | <kbd>⌥</kbd><kbd>⌘</kbd><kbd>\\</kbd> | <kbd>Ctrl</kbd><kbd>Alt</kbd><kbd>\\</kbd> |
| 커뮤니티 플러그인 둘러보기 | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>P</kbd> | <kbd>Ctrl</kbd><kbd>Shift</kbd><kbd>P</kbd> |
| 데스크톱의 어시스턴트 보이기/숨기기 | <kbd>⌥</kbd><kbd>⌘</kbd><kbd>A</kbd> | <kbd>Ctrl</kbd><kbd>Alt</kbd><kbd>A</kbd> |
| 새 회의(녹음 시작) | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>R</kbd> | —(명령 팔레트) |

섹션 번호는 사이드바 위에서부터 차례로 매겨져요. Mac에서는 <kbd>⌘</kbd><kbd>1</kbd> 스크래치,
<kbd>⌘</kbd><kbd>2</kbd> 위키, <kbd>⌘</kbd><kbd>3</kbd> 할 일, <kbd>⌘</kbd><kbd>4</kbd> 그래프, 그다음 터미널과
플러그인 탭이 순서대로 이어져요. Linux에서는 <kbd>Alt</kbd><kbd>1</kbd> 스크래치, <kbd>Alt</kbd><kbd>2</kbd> 위키,
<kbd>Alt</kbd><kbd>3</kbd> 할 일, <kbd>Alt</kbd><kbd>4</kbd> 그래프, <kbd>Alt</kbd><kbd>5</kbd> 터미널,
<kbd>Alt</kbd><kbd>6</kbd> 피드, <kbd>Alt</kbd><kbd>7</kbd> 캘린더예요.

마우스의 뒤로/앞으로 버튼으로도 뒤로, 앞으로 이동해요. <kbd>⌘</kbd>-클릭(Linux에서는 <kbd>Ctrl</kbd>-클릭)이나
가운데 버튼으로 연 노트는 새 탭에서 열려요.

## 빠르게 열기와 명령 팔레트

| 동작 | Mac | Linux |
|---|---|---|
| 결과 사이를 이동 | <kbd>↑</kbd> <kbd>↓</kbd> | <kbd>↑</kbd> <kbd>↓</kbd> |
| 고른 노트나 명령 열기 | <kbd>Return</kbd> | <kbd>Enter</kbd> |
| 고른 노트를 새 탭에서 열기 | <kbd>⌘</kbd><kbd>Return</kbd> | <kbd>Ctrl</kbd><kbd>Enter</kbd> |

## 편집기

편집기는 Mac, Linux, iPhone에서 같아요.

| 동작 | 키 |
|---|---|
| 실행 취소 / 다시 실행 | <kbd>⌘</kbd><kbd>Z</kbd> / <kbd>⇧</kbd><kbd>⌘</kbd><kbd>Z</kbd>(Linux: <kbd>Ctrl</kbd><kbd>Z</kbd> / <kbd>Ctrl</kbd><kbd>Shift</kbd><kbd>Z</kbd>) |
| 줄이나 목록 항목 들여쓰기 / 내어쓰기 | <kbd>Tab</kbd> / <kbd>Shift</kbd><kbd>Tab</kbd> |
| 다음 줄에서 목록이나 할 일 이어 쓰기 | <kbd>Return</kbd> |

격자로 편집하는 표에서는:

| 동작 | 키 |
|---|---|
| 다음 셀(마지막 셀 다음에는 새 행) | <kbd>Tab</kbd> |
| 이전 셀 | <kbd>Shift</kbd><kbd>Tab</kbd> |
| 아래 셀(마지막 행 다음에는 새 행) | <kbd>Return</kbd> |
| 위 / 아래 셀, 가장자리에서는 표 밖으로 | <kbd>↑</kbd> / <kbd>↓</kbd> |
| 표에서 나가기 | <kbd>Esc</kbd> |

## 어시스턴트

| 동작 | Mac | Linux |
|---|---|---|
| 보내기 | <kbd>Return</kbd> 또는 <kbd>⌘</kbd><kbd>Return</kbd> | <kbd>Enter</kbd> |
| 줄 바꿈 | <Badge text="다음 릴리스" /> <kbd>⇧</kbd><kbd>Return</kbd> | <kbd>Shift</kbd><kbd>Enter</kbd> |
| 말하기 시작 또는 멈추기 | **설정 › 어시스턴트 › 음성**에서 정한 **길게 눌러 말하기** 단축키(어느 앱에서든 동작해요) | AIDE 안에서 <kbd>Ctrl</kbd><kbd>Shift</kbd><kbd>Space</kbd> |
| 녹음 버리기 | <kbd>Esc</kbd> | <kbd>Esc</kbd> |

Linux에서 데스크톱 어디서나 쓰는 음성 단축키를 원하면, 데스크톱 키보드 설정에서 `aide-desktop --voice` 명령에
단축키를 지정하세요.

## 빠른 메모

Mac에서는 전역 단축키로 어느 앱 위에서든 작은 창을 열어 스크래치에 메모할 수 있어요. 기본값은
<kbd>⌥</kbd><kbd>Space</kbd>예요. **설정 › 빠른 메모**(**빠른 메모 단축키**, **단축키**)에서 바꾸거나 끌 수 있어요.
창 안에서는:

| 동작 | 키 |
|---|---|
| 스크래치에 저장 | <kbd>Return</kbd> |
| 줄 바꿈 | <kbd>⇧</kbd><kbd>Return</kbd> |
| 닫기 | <kbd>Esc</kbd> |
| 명령어 목록에서 이동(<kbd>/</kbd> 입력 후) <Badge text="다음 릴리스" /> | <kbd>↑</kbd> <kbd>↓</kbd> |
| 명령어 고르기 | <kbd>Tab</kbd> 또는 <kbd>Return</kbd> |

메뉴 막대 아이콘(**메뉴 막대에 AIDE 표시**)에도 <strong>빠른 메모…</strong>가 있어요.

Linux에서는 데스크톱이나 컴포지터에서 `aidectl capture`에 단축키를 지정하세요. 이 명령은 텍스트(인수, 또는 `-`를
주면 표준 입력)를 스크래치 노트로 추가해요. [aidectl](/ko/docs/developers/aidectl/)을 참고하세요.

## 터미널

터미널에 키보드 포커스가 있을 때는 이 키가 터미널 탭에 동작해요.

| 동작 | Mac | Linux |
|---|---|---|
| 새 탭 | <kbd>⌘</kbd><kbd>T</kbd> | <kbd>Ctrl</kbd><kbd>Shift</kbd><kbd>T</kbd> |
| 탭 닫기 | <kbd>⌘</kbd><kbd>W</kbd> | <kbd>Ctrl</kbd><kbd>Shift</kbd><kbd>W</kbd> |
| 이전 / 다음 탭 | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>[</kbd> / <kbd>⇧</kbd><kbd>⌘</kbd><kbd>]</kbd> | <kbd>Ctrl</kbd><kbd>Page Up</kbd> / <kbd>Ctrl</kbd><kbd>Page Down</kbd> |
| 1–9번 탭으로 이동 | <kbd>⌘</kbd><kbd>1</kbd>–<kbd>9</kbd> | <kbd>Alt</kbd><kbd>1</kbd>–<kbd>9</kbd> |
| 터미널에서 찾기 | <kbd>⌘</kbd><kbd>F</kbd> | <kbd>Ctrl</kbd><kbd>Shift</kbd><kbd>F</kbd> |
| 복사 / 붙여넣기 | <kbd>⌘</kbd><kbd>C</kbd> / <kbd>⌘</kbd><kbd>V</kbd>(편집 메뉴) | <kbd>Ctrl</kbd><kbd>Shift</kbd><kbd>C</kbd> / <kbd>Ctrl</kbd><kbd>Shift</kbd><kbd>V</kbd> |
| 글자 크게 / 작게 | <kbd>⌘</kbd><kbd>=</kbd> / <kbd>⌘</kbd><kbd>-</kbd> | <kbd>Ctrl</kbd><kbd>=</kbd> / <kbd>Ctrl</kbd><kbd>-</kbd> |
| 글자 크기를 설정값으로 되돌리기 | <kbd>⌘</kbd><kbd>0</kbd> | <kbd>Ctrl</kbd><kbd>0</kbd> |

Mac에서 터미널에 키보드 포커스가 있으면 <kbd>⌘</kbd><kbd>T</kbd>, <kbd>⌘</kbd><kbd>W</kbd>,
<kbd>⌘</kbd><kbd>1</kbd>–<kbd>9</kbd>, <kbd>⇧</kbd><kbd>⌘</kbd><kbd>[</kbd> <kbd>⇧</kbd><kbd>⌘</kbd><kbd>]</kbd>,
<kbd>⌘</kbd><kbd>F</kbd>는 터미널 탭에 동작해요. 그 밖의 곳에서는 첫 번째 표에 적힌 대로 동작해요.

<Aside type="note" title="Linux 터미널에서 양보하는 단축키">
이 앱 단축키는 셸도 쓰는 키라서, 키보드 포커스가 터미널에 있는 동안에는 꺼지고 셸로 전달돼요:
<kbd>Ctrl</kbd><kbd>P</kbd>, <kbd>Ctrl</kbd><kbd>\\</kbd>, <kbd>Alt</kbd><kbd>←</kbd> <kbd>Alt</kbd><kbd>→</kbd>,
<kbd>Ctrl</kbd><kbd>[</kbd> <kbd>Ctrl</kbd><kbd>]</kbd>, <kbd>Ctrl</kbd><kbd>N</kbd>, <kbd>Ctrl</kbd><kbd>T</kbd>,
<kbd>Ctrl</kbd><kbd>O</kbd>, <kbd>Ctrl</kbd><kbd>F</kbd>, <kbd>Ctrl</kbd><kbd>Shift</kbd><kbd>F</kbd>,
<kbd>Ctrl</kbd><kbd>W</kbd>, 그리고 탭 전환 키예요. <kbd>Ctrl</kbd><kbd>,</kbd>를 비롯한 나머지는 계속 동작해요.
다시 쓰려면 터미널 바깥을 클릭하세요.
</Aside>
