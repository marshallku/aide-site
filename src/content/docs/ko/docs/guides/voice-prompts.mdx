음성 프롬프트로는 [코딩 에이전트](/ko/docs/guides/terminal/#코딩-에이전트-)에게 사람에게 말하듯 말을 고쳐
가며 말해도, 에이전트가 바로 일할 수 있는 프롬프트가 들어가요. 말하면 AIDE가 기기에서 받아쓰고, 취소한 말을
빼고, 남은 내용을 모델로 다듬어 에이전트의 페인에 넣어요. 따로 설정하지 않으면 Enter는 누르지 않으니, 보내기 전에
프롬프트를 읽어 볼 수 있어요.

음성 프롬프트는 Mac, Linux, iPhone에서 쓸 수 있고, AIDE의 터미널 페인에서 실행 중인 에이전트에게만 보내요
(iPhone에서는 호스트의 [AIDE 세션](/ko/docs/guides/terminal/#호스트의-aide-세션-)).

## 프롬프트 말하기

1. 아래 [시작하는 방법](#음성-프롬프트-시작하기) 중 하나로 시작하세요. 화면 아래에 필이 나타나고, 받을 에이전트를
   **→ Claude · aide**처럼 보여 줘요.
2. 말하세요. 필에 **듣는 중…**, 음량 표시, 받아쓴 말이 차례로 보여요. 원하는 만큼 쉬어도 돼요. 음성 프롬프트는
   쉬었다고 끝나지 않아요.
3. 멈추세요. 누르고 있던 단축키에서 손을 떼거나, 한 번 눌러 시작했다면 단축키(또는 마이크)를 다시 누르세요. 필에
   **…(으)로 다듬는 중…**이 보이고, 이어서 **Claude · aide에 보냈어요**와 프롬프트가 보여요.
4. 이제 프롬프트가 에이전트 입력창에 들어가 있어요. 읽어 보고, 원하면 고친 뒤 Enter를 누르세요.

음성 프롬프트는 최대 5분까지 녹음해요. 처음 8초 동안 아무 소리도 들리지 않으면 아무것도 보내지 않고 끝나요. 녹음,
받아쓰기, 다듬기 중에 필의 ✕를 누르거나 AIDE가 앞에 있을 때 <kbd>Esc</kbd>를 누르면 프롬프트를 버려요. 아무것도
입력되지 않아요.

녹음은 한 번에 하나만 돼요. [어시스턴트에게 말하는 중](/ko/docs/guides/assistant/#음성)이거나
[회의](/ko/docs/guides/meetings/)를 녹음하는 중에는 음성 프롬프트가 시작되지 않아요.

## 어느 페인으로 가나요

에이전트는 시작할 때 정해져요. 말하는 동안 다른 곳을 클릭해도 프롬프트는 그 에이전트로 가요.

- 마지막으로 앞에 있던 AIDE 창의 포커스된 페인에서 에이전트가 실행 중이면 그 페인,
- 아니면 그 창에서 가장 최근에 포커스된, 에이전트가 있는 페인,
- 둘 다 없으면 보낼 곳이 없어요. 그래도 받아쓰고 다듬은 뒤, 필에서 **복사**로 쓸 수 있게 보여 줘요(**보낼
  에이전트가 없어요.**).

필은 받을 곳을 에이전트와 페인의 폴더 이름으로 보여 줘요(**Claude · aide**). 페인에 폴더가 없으면 에이전트와 탭
이름이에요(**Codex · build**). 에이전트가 종료되거나, 다른 프로그램이 그 자리를 차지하거나, 터미널 서버가 다시
시작되거나 연결이 끊기면 받을 곳이 사라진 것으로 보고 아무것도 입력하지 않아요.

## 음성 프롬프트 시작하기

<Tabs>
<TabItem label="Mac">

- **설정 › 음성 프롬프트 › 길게 눌러 말하기**에서 어느 앱에서든 동작하는 단축키를 정할 수 있어요(기본값 없음).
  누른 채 말하고 손을 떼면 멈춰요. 한 번 눌러 시작하고 다시 눌러 멈춰도 돼요. 어시스턴트의 **길게 눌러 말하기**
  단축키와 같을 수는 없어요("어시스턴트의 길게 눌러 말하기가 이미 쓰고 있어요.").
- **프롬프트 말하기**와 **마지막 음성 프롬프트 보기**는 명령 팔레트와 메뉴 막대에 있어요. **프롬프트 말하기**는
  [설정 › 키보드](/ko/docs/guides/shortcuts/#단축키-바꾸기)에서 정하기 전까지 단축키가 없어요.

</TabItem>
<TabItem label="Linux">

- AIDE 안에서 <kbd>Ctrl</kbd><kbd>Shift</kbd><kbd>M</kbd>을 누르면 음성 프롬프트를 시작하고, 진행 중이면
  멈춰요. 명령 팔레트에 **프롬프트 말하기**, **음성 프롬프트 시작**, **음성 프롬프트 멈추기**, **마지막 음성
  프롬프트 보기**가 있고, **설정 › 키보드**에서 각각 단축키를 정할 수 있어요.
- AIDE 밖에서는 컴포지터에서 [`aidectl action run`](/ko/docs/developers/aidectl/#action)으로 동작을
  연결하세요. `voice-prompt`(시작 또는 멈춤), `voice-prompt/start`, `voice-prompt/stop`,
  `voice-prompt/last`가 있어요. Hyprland에서는 `bind`로 시작하고 `bindr`(키를 뗄 때)로 멈추면 어디서나 길게
  눌러 말할 수 있어요.

```ini
# ~/.config/hypr/hyprland.conf
bind = SUPER, M, exec, aidectl action run voice-prompt/start
bindr = SUPER, M, exec, aidectl action run voice-prompt/stop
bind = SUPER SHIFT, M, exec, aidectl action run voice-prompt/last
```

`aidectl action`은 이 컴퓨터의 AIDE 앱과 통신하니, AIDE가 그 보관소를 연 채로 실행 중이어야 해요.

</TabItem>
<TabItem label="iPhone">

- AIDE 세션 페인의 바에 있는 마이크: 탭해서 시작하고 다시 탭해서 멈추거나, 말하는 동안 누르고 있으세요.
- 단축어 동작 **에이전트에게 프롬프트 말하기**는 마지막으로 쓴 AIDE 세션 페인을 열고 바로 들어요.

</TabItem>
</Tabs>

## AIDE가 말한 내용으로 하는 일

### 기기에서 받아써요

음성은 기기에서 글로 옮겨요. Mac과 iPhone에서는 Apple의 기기 내 음성 인식을, Linux에서는 whisper.cpp와 컴퓨터에
있는 음성 모델을 써요([음성 모델](#음성-모델linux) 참고). 오디오는 말하는 동안 메모리에만 있고, 저장하거나 보내지
않아요.

받아쓰기가 중간에 멈추거나 실패하면 AIDE가 새로 시작해서 보관해 둔 오디오를 다시 듣게 해요. 그래서 그때까지 받아쓴
말은 순서대로, 겹치지 않고 남아요. Linux에서는 밀려 있는 동안 필에 **따라잡는 중…**이, 멈춘 뒤에는 **받아쓰는
중… N / M**이 보여요. 1분 넘게 걸리면 그때까지 받아쓴 것으로 끝나요. 말한 내용 일부를 받아쓰지 못하면 프롬프트에
**말한 내용 일부가 받아써지지 않았어요**가 붙고, 저절로 보내지 않아요.

### 취소한 말을 빼요

모든 기기에서 같은 규칙이 말하는 동안 취소한 부분을 찾아요.

- "음", "어", "um", "uh" 같은 군말은 숨겨요.
- "아니 아니", "아니다", "no wait", "scratch that"은 바로 앞부분에 줄을 그어요. "빨간색으로 해 줘, 아니 아니
  파란색"이면 "파란색"이 남아요.
- "말고", "그게 아니라", "I mean"은 흐리게 보여요. 앞말을 취소하는지 아닌지는 모델이 정해요.
- "처음부터 다시", "다 지워", "start over", "scratch all that"은 그 앞의 모든 것에 줄을 그어요.

말하는 동안 줄 그은 말이 필에 보여요. 규칙은 조심스럽게 동작해서, 생각보다 덜 지울 때가 있어요.

### 다듬어요

이어서 모델을 한 번 불러, 말한 내용을 에이전트에게 줄 짧은 프롬프트로 바꿔요. 말한 언어 그대로, 요청한 것만
남기고 군말, 말 고침, 딴 이야기는 빼요. 요청이 여럿이면 말한 순서대로 번호 목록이 돼요. 파일, 경로, 이름, 숫자,
명령은 말한 그대로 두고, 말하지 않은 것은 더하지 않아요. 어떤 모델을 쓸지는 **설정 › 음성 프롬프트 › 다듬기**에서
정해요([설정](#설정) 참고). 모델에는 도구가 주어지지 않아요. **화면 내용 포함**이 켜져 있으면 페인의 마지막 줄들도
최대 6KiB까지 함께 가요. 무슨 뜻인지 이해하는 데만 쓰고, 그 내용은 프롬프트에 넣지 말라고 모델에 알려 줘요.

AIDE는 답을 쓰기 전에 확인해요. 쓸 수 없으면 규칙으로 만든 내용을 대신 쓰고, 이유를 필에 보여 줘요.

| 필에 보이는 말 | 이유 |
|---|---|
| **다듬지 않음: 다듬기가 꺼져 있어요** | **다듬기**가 **끔**이에요. |
| **다듬지 않음: 설정된 모델이 없어요** | 설정된 모델이 없거나 연결할 수 있는 모델이 없어요. |
| **다듬지 않음: 이 기기의 모델은 이 언어를 지원하지 않아요** | **이 기기에서만**인데, 기기의 모델이 이 언어를 다듬을 수 없어요. |
| **다듬지 않음: 이 기기의 모델에는 너무 길어요** | **이 기기에서만**인데, 말한 내용이 기기의 모델에는 너무 길어요. |
| **다듬지 않음: 다듬기에는 너무 길어요** | 말한 내용이 보내기에는 너무 길어요. |
| **다듬지 않음: 명령처럼 들려요** | 말한 내용에 명령 같은 것(`rm`, `git push`, `--force`, `/`가 있는 경로)이 있어서 모델에 묻지 않았어요. |
| **다듬지 않음: 답에 말하지 않은 명령이 들어 있었어요** | 모델의 프롬프트에 명령이 있거나, 말하지 않은 파일이나 이름이 있었어요. |
| **다듬지 않음: 모델의 답을 쓸 수 없었어요** | 답이 정해진 형식이 아니었어요. |
| **다듬지 않음: 모델이 아무것도 돌려주지 않았어요** | 답이 비어 있었어요. |
| **다듬지 않음: 모델의 답이 너무 길었어요** | 답이 말한 내용보다 훨씬 길었어요. |
| **다듬지 않음: 너무 오래 걸렸어요** | 15초 안에 답이 오지 않았어요. |
| **다듬지 않음: 모델에 연결하지 못했어요** | 호출이 실패했어요. |

다듬은 프롬프트에도 표시가 붙을 수 있어요.

- **확인해 주세요: 말하지 않은 이름이 들어 있어요**: 말한 내용에도 화면에도 없는 `parseConfig`, `v2-beta` 같은
  이름이 들어 있어요.
- **불분명: …**: 모델이 무슨 뜻인지 확실하지 않아서, 무엇이 불분명한지 알려 줘요.

### 페인에 넣어요

AIDE가 프롬프트를 터미널 서버에 넘기면, 서버가 에이전트 입력창에 한 번에 붙여 넣어요. 서버는 먼저 같은
에이전트가 아직 있는지, 에이전트가 무언가 묻고 있지 않은지 확인해요. 붙여 넣기를 일찍 끝내거나 키를 누를 수 있는
것은 빼고, 다시 시도해도 같은 프롬프트는 한 번만 넣어요.

**말을 멈추면 전송**을 켜지 않으면 Enter를 누르지 않아요. 켜도 모델이 다듬었고 표시가 하나도 없는 프롬프트에만
눌러요. 다듬지 않았거나, 표시가 있거나, 불분명하거나, 일부만 받아쓴 프롬프트는 언제나 입력창에서 기다려요.

## 필

필은 입력 중인 페인의 키보드를 빼앗지 않고 프롬프트가 어떻게 되고 있는지 보여 줘요. Mac에서는 받을 창이 있는
화면의 아래쪽 가운데에, 다른 앱 위에도 떠 있어요. Linux에서는 gtk4-layer-shell이 설치되어 있으면(Hyprland,
KDE와 다른 wlroots 데스크톱) 화면 아래쪽에 뜨고, 그 밖에는 AIDE 창 아래쪽의 띠로 보여요. iPhone에서는 AIDE 세션
페인의 키 바 위에 있는 바예요.

| 필에 보이는 말 | 무슨 일인가요 | 할 수 있는 것 |
|---|---|---|
| **Claude · aide에 보냈어요** | 프롬프트가 에이전트 입력창에 들어갔어요. | **복사**, **말한 그대로 복사**. 8초 뒤에 사라져요(포인터가 위에 있으면 더 오래). 표시가 붙은 필은 닫을 때까지 남아요. |
| **Claude이(가) 무언가 묻고 있어요. 먼저 답해 주세요.** | 에이전트가 질문이나 권한을 묻고 있어서 아무것도 넣지 않았어요. | 에이전트에 답한 뒤 **그래도 넣기**. 아직 묻고 있으면 필이 남아서 그렇다고 알려 줘요. **복사**. |
| **그 페인의 에이전트가 사라졌어요.** | 에이전트가 종료됐거나 그 자리에서 다른 것이 실행 중이에요. | **복사**. |
| **보낼 에이전트가 없어요.** | 시작할 때 에이전트가 있는 페인이 없었어요. | **복사**. |
| **프롬프트를 넣으려면 …의 AIDE를 업데이트하세요** | 그 페인을 실행하는 컴퓨터의 AIDE가 예전 버전이에요. 아무것도 넣지 않았어요. | 그 컴퓨터의 AIDE를 업데이트하세요. **복사**. |
| **들어갔는지 확실하지 않아요. 페인을 확인해 주세요.** | 프롬프트를 보내는 중에 연결이 끊겼어요. | 페인을 확인하세요. 5분 동안은 **다시 시도**해도 많아야 한 번만 들어가요. 그 뒤에는 **다시 넣기**가 새로 보내요. **복사**. |
| **넣지 못했어요: …** | 서버가 거절했어요. 예를 들어 "프롬프트가 너무 길어요", "그 페인의 프로그램은 붙여 넣은 프롬프트를 받을 수 없어요". | **다시 시도**, **복사**. |
| **보낼 내용이 없어요** | 모두 취소한 경우처럼 보낼 요청이 남지 않았어요. | **말한 그대로 쓰기**는 규칙으로 만든 내용을, 없으면 받아쓴 말 그대로를 넣어요. |
| **받아쓰기가 멈췄어요: …** 같은 이유 | 녹음이 실패했어요. | **무시**. |

어떤 상태에서든 ✕를 누르면 필이 닫혀요.

### 마지막 프롬프트

AIDE는 마지막으로 보낸 프롬프트, 말한 내용, 받을 곳을 30분 동안 메모리에만 보관하고 디스크에는 쓰지 않아요.
**마지막 음성 프롬프트 보기**를 실행하면 **넣기**(지금 고르면 정해질 페인으로), **복사**, **말한 그대로 복사**와
함께 필이 다시 나타나요. 그래서 필을 닫아도 프롬프트를 잃지 않아요.

## 설정

**설정 › 음성 프롬프트**, **어시스턴트** 다음에 있어요.

| 설정 | 기본값 | 하는 일 |
|---|---|---|
| **길게 눌러 말하기** (Mac) | 없음 | 어느 앱에서든 동작하는 단축키예요. 누른 채 말하거나, 눌러서 시작하고 멈춰요. |
| **다듬기** | 자동 | 말한 내용을 다듬을 모델: **자동**, **이 기기에서만**(Mac과 iPhone), **어시스턴트 모델**, **끔**. |
| **말을 멈추면 전송** | 꺼짐 | 프롬프트를 넣은 뒤 Enter를 눌러요. 모델이 다듬었고 표시가 없을 때만이에요. |
| **화면 내용 포함** | 켜짐 | 페인의 마지막 줄들을 최대 6KiB까지 말한 내용과 함께 보내, 무엇을 가리키는지 모델이 이해하게 해요. |
| **언어** | 자동 | **설정 › 어시스턴트 › 음성 › 언어**와 같은 설정이에요. **자동**, **English**, **한국어**. 어느 쪽에서 바꿔도 둘 다 바뀌어요. |
| **음성 모델** (Linux) | 표준 | **표준** 또는 **더 나은 한국어**(아래 참고). |

### 다듬기

- **자동**: Mac과 iPhone에서는 먼저 Apple의 기기 내 모델을 써요. Apple Intelligence가 켜져 있고, 그 언어를
  다룰 수 있고, 말한 내용이 들어갈 때요. 다음은 이 기기에 저장한 Anthropic 키와 `haiku`, 그다음은
  [어시스턴트](/ko/docs/guides/assistant/#모델-가져오는-곳)의 Claude Code(`haiku`), Codex, Grok, 마지막은
  서버와 `haiku`예요. Linux는 키부터 시작해요. 아래 설명에 지금 **자동**이 무엇을 쓰는지 보여요.
- **이 기기에서만**(Mac과 iPhone): Apple의 기기 내 모델만 써요. 쓸 수 없으면 다듬지 않아요.
- **어시스턴트 모델**: **설정 › 어시스턴트 › 모델 제공처**가 쓰는 것을 그 모델로 써요.
- **끔**: 규칙만 써요. 아무것도 보내지 않아요.

Claude Code나 Codex 같은 프로그램은 이때 도구를 끄고 빈 폴더에서 실행돼요. **내 Claude Code 설정 사용**은
적용되지 않아요. 도구를 모두 끌 수 없는 프로그램은 쓰지 않아요. Antigravity는 항상 그래서, 어시스턴트가
Antigravity를 쓰면 음성 프롬프트는 다른 것을 쓰고, 설명에 그 이름이 나와요.

### 음성 모델(Linux)

- **표준**: 어시스턴트가 이미 쓰는 음성 모델이에요.
- **더 나은 한국어**: 한국어를 더 잘 받아쓰는 큰 모델(약 574MB)이에요. 고른 뒤 **다운로드**를 누르면
  AIDE가 파일을 확인한 뒤에 보관해요. 내려받기 전에는 프롬프트를 시작할 수 없어요. 어떤 컴퓨터에서는 말하는 속도보다 느리게 받아써서 **이 컴퓨터에서는 말하는 속도보다 느려요**라고
  알려 줘요. 그러면 말을 멈춘 뒤 더 오래 기다려야 해요.

## 기기 밖으로 나가는 것

- **오디오는 나가지 않아요.** 저장하지도 보내지도 않아요.
- **말한 내용**과, **화면 내용 포함**이 켜져 있으면 페인 화면 최대 6KiB는 **다듬기**가 고른 모델에만 가요.
  AIDE는 이것을 디스크에 쓰지 않아요.

| 다듬는 곳 | 가는 곳과 남는 것 |
|---|---|
| 이 기기, 또는 **끔** | 기기 밖으로 나가는 것이 없어요. |
| Anthropic API 키 | Anthropic으로 가요. Anthropic의 보존 정책이 적용돼요. |
| 서버 | 서버를 거쳐 Anthropic으로 가요. Anthropic의 보존 정책이 적용돼요. |
| Claude Code | 세션을 저장하지 않고 실행되는 Claude Code로 가요. |
| Codex | 임시 세션으로 실행되는 Codex로 가요. |
| Grok | Grok으로 가요. Grok은 세션을 `~/.grok/sessions`에 보관해요. 프롬프트는 실행이 끝날 때까지 비공개 임시 폴더의 파일에 쓰이고, 비정상 종료 시에는 시스템이 지울 때까지 남을 수 있어요. |
| Antigravity | 음성 프롬프트에는 쓰지 않아요. |

**다듬기** 아래 설명에도 지금 고른 것에 대해 같은 내용이 나와요.

## 한계

<Aside type="caution">
터미널 서버는 에이전트가 아직 있고 무언가 묻고 있지 않은지 확인하지만, 앞일은 알 수 없어요. 붙여 넣은 글을
에이전트가 읽기 직전에 질문이나 권한 대화상자가 열리면, 그 대화상자가 글을 받을 수 있어요. 그래서 기본으로
Enter를 누르지 않고, **말을 멈추면 전송**도 깔끔하게 다듬은 프롬프트만 보내요.
</Aside>

- 음성 프롬프트는 AIDE의 페인에 있는 에이전트에게만 가요. 다른 터미널 앱으로는 가지 않아요.
- 규칙은 덜 지우거나 엉뚱한 몇 단어를 지울 수 있어요. 모델은 줄 그은 말도 보고 정해요. Enter를 누르기 전에
  프롬프트를 확인하세요.
- 명령을 말한 프롬프트는 모델이 다듬지 않으니, 규칙이 남긴 대로의 말이 들어가요.
