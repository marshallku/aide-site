AIDE에는 자체 모델이 없어요. 모델이 어디서 실행될지는 직접 골라요. 컴퓨터에서 이미 쓰고 있는 Claude Code나
Codex, 내 Anthropic API 키, 또는 서버에 설정한 AI 중에서요. AI 없이 AIDE를 써도 돼요. AI가 필요한 기능은 그렇다고
알려 주고, 나머지는 규칙으로 동작해요.

모델의 출력은 그대로 믿지 않아요. AIDE는 모든 답을 엄격한 형식에 맞는지 확인한 뒤에야 반영해요. 노트에 대한
변경은 내가 적용하는 제안이거나, 노트 안의 해당 플러그인 섹션으로만 제한돼요.

## 모델을 쓰는 기능과 가져오는 곳

설정이 두 개 있어요. AI 중 일부는 기기의 앱에서, 일부는 서버에서 실행되기 때문이에요.

| 기능 | 모델을 가져오는 곳 | 모델이 없으면 |
|---|---|---|
| [어시스턴트](/ko/docs/guides/assistant/)(대화, 먼저 말하기) | **설정 › 어시스턴트 › 모델 제공처**(이 기기) | 쓸 수 없어요. |
| [회의](/ko/docs/guides/meetings/) 요약과 실행 항목 | **설정 › 어시스턴트 › 모델 제공처**(녹음한 기기) | 녹음하고 받아쓰지만 요약하지 않아요. |
| 서버가 있을 때의 [정리](/ko/docs/guides/scratch/) | **설정 › AI**(서버) | 규칙으로 분류해요. |
| 서버가 없을 때의 정리 | 기기의 **설정 › AI**에 넣은 내 Anthropic 키 | 규칙으로 분류해요. |
| [피드](/ko/docs/guides/feed/) 분류 | **설정 › AI**(서버) | 규칙으로 분류해요. |
| 대신 글을 써 주는 서버 플러그인: [브리핑](/ko/docs/plugins/briefing/), [저녁 정리](/ko/docs/plugins/recap/), [열린 이슈](/ko/docs/plugins/loops/), [캘린더 준비](/ko/docs/plugins/gcal/), [Gmail](/ko/docs/plugins/gmail/), [Slack](/ko/docs/plugins/slack/) 요약, [복습](/ko/docs/plugins/recall/) 카드, [혜택](/ko/docs/plugins/benefits/) | **설정 › AI**(서버), 허용한 플러그인마다 | 플러그인 페이지마다 적혀 있어요. Gmail은 확인할 메일 목록을 계속 보여 주고, 브리핑과 회고는 모델이 필요해요. |
| [레이더](/ko/docs/plugins/radar/) | 자체 **모델** 설정: Claude Code, 그다음 Codex, 없으면 서버(<Badge text="다음 릴리스" /> Codex 다음에 Grok, Antigravity) | 모델이 필요해요. |
| [지난 작업 정리](/ko/docs/plugins/catchup/) | 플러그인을 실행하는 컴퓨터의 Claude Code나 Codex | 모델이 필요해요. |

음성 입력과 회의 받아쓰기는 모델 서비스를 전혀 쓰지 않아요. 기기에서 글로 옮겨요.

## 설정 › 어시스턴트 › 모델 제공처

이 기기의 어시스턴트와 회의 요약에 쓸 모델을 골라요. 기기마다 따로 선택해요.

| 선택 | 실행 위치 | 기본 모델 |
|---|---|---|
| **자동** | 처음 동작하는 것: Claude Code, Codex, 내 Anthropic 키, 그다음 서버. | — |
| **Claude Code** | 이 Mac이나 Linux 컴퓨터의 `claude` 프로그램, 내 로그인으로. | `sonnet` |
| **Codex** | 이 Mac이나 Linux 컴퓨터의 `codex` 프로그램, 내 로그인으로. | Codex 자체 기본값 |
| **Anthropic API 키** | 이 기기에 저장한 키로 Anthropic API를 써요. | `sonnet` |
| **서버** | 서버의 AI(아래 참고). 서버의 일일 한도에 포함돼요. | `sonnet` |

- **모델** 칸에는 등급(`sonnet`, `opus`, `haiku`)이나 전체 모델 ID를 넣어요.
- **테스트**는 아주 작은 요청을 보내고 **정상 작동**과 걸린 시간, 또는 실패한 이유를 보여 줘요.
- AIDE는 `PATH`와 흔한 설치 폴더(`~/.local/bin`, `/opt/homebrew/bin`, `/usr/local/bin`, `~/.bun/bin`,
  `~/.npm-global/bin`, `~/.cargo/bin` 등)에서 `claude`와 `codex`를 찾고, 그다음 로그인 셸에 물어봐요. 찾지 못하면
  해당 칸에 프로그램 경로를 입력하세요.
- Claude Code와 Codex는 도구 없이, 빈 임시 폴더에서, 몇 가지 환경 변수만 넘겨받아 실행돼요. 프롬프트가 들어가고
  답이 나올 뿐이에요. 실행은 2분이 지나면 중지돼요. Mac과 Linux에서는 **내 Claude Code 설정 사용**으로 Claude
  Code를 내 도구와 함께 실행할 수도 있어요. [어시스턴트](/ko/docs/guides/assistant/#내-claude-code-설정-사용)를
  참고하세요.
- iPhone에서는 **자동**, **Anthropic API 키**, **서버** 중에서 골라요.
- **서버**는 서버를 쓸 때만 보여요.

<Badge text="다음 릴리스" /> Mac과 Linux에서는 **Grok**과 **Antigravity**도 고를 수 있어요.

| 선택 | 실행 위치 | 기본 모델 |
|---|---|---|
| **Grok** | 이 Mac이나 Linux 컴퓨터의 `grok` 프로그램, 내 로그인으로. | Grok 자체 기본값 |
| **Antigravity** | 이 Mac이나 Linux 컴퓨터의 `agy` 프로그램, 내 로그인으로. | Antigravity 자체 기본값 |

- **자동**은 Claude Code, Codex, Grok, Antigravity, 내 Anthropic 키, 서버 순으로 시도해요.
- AIDE는 먼저 로그인 셸의 `PATH`에서 찾아서 터미널이 쓰는 것과 같은 프로그램을 써요. 그다음 AIDE 자신의 `PATH`와 흔한 설치
  폴더를 봐요. 여러 개를 찾으면 경로 옆 메뉴(**2개 찾음**)에 버전과 함께 모두 나와요. 하나를 고르거나 **자동**을 골라 처음 찾은
  것을 쓰면 돼요.
- 각 프로그램은 끌 수 있는 도구를 모두 끄고 실행돼요. Grok은 내장 도구를 이름으로 모두 빼고, 내 Claude Code나 Cursor 설정을
  불러오지 않아요. Antigravity는 도구를 끌 방법이 없어서, 물어봐야 하는 도구는 거절하지만 Antigravity가 묻지 않고 쓰도록 허용된
  도구는 모두 써요. 도구를 모두 끌 수 없는 프로그램도 그대로 쓰고, 경로 아래와 **테스트** 결과에 그렇다고 알려 줘요("… 내 도구를
  함께 써요.").
- 어시스턴트가 보내는 내용은 내 로그인으로 그 프로그램의 제공자에게 가요. Grok은 xAI, Antigravity는 Google이에요.

서버 없이 노트를 둘 때는 기기의 Anthropic 키를 **설정 › AI**에 저장해요. 키는 기기의 키체인에 저장돼요(Linux에서는
응답하는 시스템 키링이 있으면 거기에, 없으면 나만 읽을 수 있는 파일에). 정리에 쓸 모델도 거기서 바꿀 수 있어요.

<Badge text="다음 릴리스" /> 서버나 데스크톱 호스트를 쓸 때는 **설정 › AI**가 서버의 설정이라(아래 참고), 기기의 키를
따로 둬요. Mac과 iPhone에서는 **모델 제공처**가 **Anthropic API 키**일 때 **설정 › 어시스턴트**에 나오는 **이 기기의
Anthropic 키**에서, Linux에서는 설정의 **이 기기의 Anthropic 키** 페이지에서 저장해요. 키는 이 기기에만 있어요.

## 서버의 설정 › AI

데스크톱 호스트나 내 서버를 쓸 때는 **설정 › AI**에서 내 계정에 쓸 서버 AI를 설정해요. 피드 분류, 정리,
플러그인의 요청, 어시스턴트의 **서버** 선택에 쓰여요.

| 백엔드 | 설명 |
|---|---|
| **규칙(AI 미사용)** | 모델을 호출하지 않아요: `#tag` → `topics/tag`, 할 일 → 오늘 데일리 노트, 이벤트는 키워드로 분류해요. |
| **Anthropic API 키** | 내 키를 써요. 요금은 내 Anthropic 계정으로 청구돼요. |
| **내 게이트웨이** | 내 컴퓨터에서 내 Claude 로그인으로 직접 운영하는 `aide-gateway`예요. URL과 게이트웨이 토큰으로 연결해요. AIDE 릴리스 다운로드에는 들어 있지 않고, 구독을 공유하는 용도가 아니에요. |

키와 게이트웨이에는 **모델**도 설정할 수 있어요(비워 두면 서버 기본값).

- **사용 중**은 지금 적용 중인 설정과, 그게 내 설정인지 서버 기본값인지 보여 줘요. **서버 기본값 사용**을 누르면
  내 선택을 지워요.
- **오늘 통화**는 오늘 한 호출 수를 일일 한도와 함께 보여 줘요. 예: `12 / 200`. 한도는 기본값으로 하루 200회이고,
  UTC 기준으로 하루를 세요. 한도를 넘으면 다음 날까지 요청이 실패해요.
- **테스트**는 한 번 호출해 보고 **정상**과 제공자, 걸린 시간, 또는 실패한 이유를 보여 줘요.

<Aside type="note" title="키는 쓰기 전용이에요">
키와 게이트웨이 토큰은 서버에 암호화(AES-256-GCM)해 저장하고 다시 보여 주지 않아요. 칸에는 **저장됨 — 입력하여
교체**라고만 표시돼요. 저장된 값을 유지하려면 비워 두고, 지우려면 **저장된 키 제거**를 선택하세요. 데스크톱
호스트는 항상 암호화 키를 설정해요. 암호화 키가 없는 서버에는 **이 서버는 키를 저장할 수 없어요**라고 표시돼요.
</Aside>

플러그인은 그 권한을 받았을 때만 서버의 AI를 쓸 수 있어요. 서버는 플러그인의 요청에 일반 텍스트로 답하고,
플러그인은 그 답을 노트 안의 자기 섹션에만 써요.

## AI를 전혀 쓰지 않을 때

모델이 하나도 없어도 AIDE는 그 자체로 완전한 노트와 할 일 앱이에요.

- **정리**는 규칙으로 스크래치 노트를 분류해요. 첫 번째 `#tag`가 있으면 `topics/<tag>`로, 할 일이 있는 노트는 오늘
  데일리 노트로, 나머지는 인박스로 보내요. **적용** 전에 제안을 하나씩 확인하는 건 마찬가지예요.
- **피드**는 키워드, 게시자가 정한 심각도, 위키의 단어로 분류해요([피드가 정렬되는 방식](/ko/docs/guides/feed/#누가-분류하나요)
  참고).
- 캘린더 리마인더, 할 일 넘기기, 문서 동기화, 회의 녹음과 받아쓰기, 음성 입력은 모두 동작해요.
- 어시스턴트, 회의 요약, 레이더, 지난 작업 정리, 모델로 글을 쓰는 플러그인은 동작하지 않아요.

## 모델에 전송되는 내용

각 기능은 필요한 것만 보내고, 모델이 그 안의 지시를 따르지 않도록 데이터로 감싸서 보내요.

- **어시스턴트:** 미완료 할 일(최대 120개)과 날짜, 블록, 예상 소요 시간. 오늘의 일정과 빈 시간. 메모리 노트와
  목표 노트(각각 2KB). 최근 메시지 12개. 읽은 노트(4KB로 잘라서). **읽지 않을 폴더**의 내용은 절대 보내지 않아요.
  요청 하나에 최대 48KB예요.
- **회의 요약:** 제목, 시작 시각, 참석자, 단어 목록, 링크된 노트마다 앞부분(각각 4KB, 모두 합쳐 16KB), 캘린더의
  맥락, 대화록.
- **정리:** 선택한 스크래치 노트와 위키의 페이지 이름.
- **피드 분류:** 이벤트마다 제목과 본문 앞부분 2KB, 그리고 위키 제목과 폴더 이름에서 뽑은 단어 최대 200개.
- **플러그인:** 플러그인 자체의 프롬프트, 그리고 플러그인이 지정하거나 검색으로 찾은 노트(각각 최대 16KB).

어디로 가는지는 선택에 따라 달라요. API 키라면 Anthropic으로, Claude Code나 Codex라면 내 로그인의 제공자로,
게이트웨이라면 게이트웨이가 돌아가는 컴퓨터로 가요. 전체 내용은 [개인정보와 보안](/ko/docs/self-hosting/privacy/)을
참고하세요.
